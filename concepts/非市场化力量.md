# 非市场化力量

> 价格之外的手 — 行政、政治与制度性力量如何塑造本应由市场决定的价格与配置

## 一、概述

### 1.1 定义

**非市场化力量**指在资源配置与价格形成过程中，**独立于、甚至凌驾于市场供求之上**的行政、政治、制度与地缘力量。它们使价格或交易偏离纯粹市场均衡，是理解"市场结果为何不总是市场逻辑的结果"的关键变量。

### 1.2 主要表现

| 类别 | 具体形式 |
|------|----------|
| **行政管制** | 价格管制、准入审批、投资审查（见 [[外汇管制]]、[[资本管制]]） |
| **政策引导** | 窗口指导、定向调控、产业政策（见 [[窗口指导]]、[[定向调控]]） |
| **国有与计划因素** | 国企主导、计划色彩遗留（见 [[计划经济转型]]、[[国企改革]]） |
| **地缘与政治** | 制裁、关税、安全审查对交易的重塑（见 [[地缘政治对抗]]、[[金融制裁]]） |
| **制度与文化** | 隐性刚兑、行政文化、稳定偏好（见 [[隐性刚兑]]、[[稳定文化]]） |

### 1.3 为什么重要

- 非市场化力量决定**市场机制的边界**：在哪些领域价格失灵、在哪些领域行政主导；
- 它是理解新兴市场"股牛汇弱"、汇率稳定、资产价格"政策市"等现象的核心线索（见 [[股牛汇弱]]、[[为何日韩会股牛汇弱]]）。

## 二、理论机制

### 2.1 市场机制与非市场化力量的对照

```
市场机制：价格 ← 供求 ← 成本/偏好/预期（分散决策）
非市场化力量：价格 ← 政策目标 ← 行政命令/制度约束（集中决策）
```

两者并非截然对立，而是一个**光谱**：从纯市场定价（极少数）到纯计划定价（极少数），中间大量交易是"市场 + 干预"的混合结果（见 [[价格机制]]）。

### 2.2 行政干预的合理性来源

| 理由 | 逻辑 |
|------|------|
| **市场失灵** | 外部性、公共物品、信息不对称需要矫正（见 [[市场失灵]]） |
| **战略安全** | 粮食、能源、金融、数据涉及国家安全（见 [[粮食安全]]、[[数据安全]]） |
| **金融稳定** | 资本大进大出威胁汇率与资产价格稳定（见 [[金融安全]]、[[系统性风险]]） |
| **发展赶超** | 后发国家以产业政策集中资源（见 [[产业升级]]、[[新质生产力]]） |

### 2.3 非市场化力量的作用途径

```
制度约束（法律、准入、所有制）
        ↓
政策工具（利率汇率管制、信贷额度、储备干预）
        ↓
行为塑造（预期引导、窗口指导、隐性担保）
        ↓
价格与配置偏离市场均衡
```

非市场化力量既可以直接**钉住价格**（如汇率中间价管理），也可以通过**预期与担保**间接扭曲风险定价（见 [[汇率非市场化]]、[[隐性刚兑]]）。

## 三、典型场景

### 3.1 汇率与非市场化

- **管理浮动**：汇率形成机制中，中间价设定、逆周期因子与外汇储备干预体现明显的非市场化成分（见 [[汇率非市场化]]、[[人民币汇率形成机制]]、[[外汇干预有效性]]）；
- **外储干预**：央行通过买卖外汇影响汇率，本币稳定优先于价格信号（见 [[外汇储备]]、[[冲销式干预]]）；
- **资本管制**：对跨境资本流动的限制，抑制了利率平价与汇率的市场化联动（见 [[资本管制]]、[[外汇管理]]）。

### 3.2 资产市场与非市场化

- **"政策市"**：重要会议、政策文件与监管表态显著影响市场方向，机构行为与预期围绕政策节奏展开；
- **窗口指导**：监管部门通过非强制方式引导信贷投放、股市情绪与机构行为（见 [[窗口指导]]）；
- **稳定资金**：中投（汇金）等主权/国有主体在市场波动时的干预（见 [[中投]]）。

### 3.3 实体经济与非市场化

- **国企的角色**：国企承担稳增长、保就业等社会职能，其投资与定价不纯以利润最大化为目标（见 [[国企改革]]、[[中国特色企业治理]]）；
- **产业政策**：补贴、目录、准入等方式引导资源流向特定产业（见 [[结构性工具]]、[[定向调控]]）；
- **价格管制**：民生领域（能源、粮食、医药）的价格管控以稳定优先（见 [[价格机制]]、[[中储粮]]）。

## 四、应用与局限

### 4.1 分析应用

- **识别"市场 vs 政策"**：区分价格变动中政策与市场各自的贡献，是宏观与策略分析的基本功；
- **前瞻政策变量**：非市场化力量使政策文本、表态与事件成为重要交易变量；
- **跨国比较**：市场化程度（尤其要素价格）是评估经济体制度差异的重要维度（见 [[利率市场化]]、[[汇率制度]]）。

### 4.2 局限与成本

| 成本 | 说明 |
|------|------|
| 价格信号扭曲 | 资源配置偏离真实稀缺 |
| 道德风险 | 隐性担保弱化市场约束 |
| 资源错配 | 行政偏好未必等于社会最优 |
| 路径依赖 | 干预退出困难，改革受制（见 [[制度变迁]]） |
| 地缘摩擦 | 非市场化做法易招致外部批评与反制 |

### 4.3 边界与趋势

- 非市场化力量在**短期稳定**与**长期效率**之间存在权衡：稳定优先的代价是市场信号延迟调整；
- 改革方向通常是**在监管与安全框架内扩大市场决定范围**——从价格双轨并轨到要素市场化（见 [[价格双轨制]]、[[中国改革]]、[[利率市场化]]）；
- 判断标准：**看价格是否反映稀缺、配置是否响应价格信号**。非市场化力量越强，这两条越弱。
