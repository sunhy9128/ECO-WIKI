# 亚洲金融危机

> 从泰铢失守到横扫东亚 — 高增长奇迹背后的资本账户与汇率失衡

## 一、定义

**亚洲金融危机**（Asian Financial Crisis）指 1997-1998 年从泰国开始、迅速蔓延至马来西亚、印度尼西亚、韩国、菲律宾等东亚经济体的金融危机。危机以**货币大幅贬值、股市暴跌、企业与银行大面积倒闭、经济深度衰退**为特征，终结了东亚"经济奇迹"的惯性叙事。

危机根源在于**金融自由化过快、短期外债高企、盯住美元汇率与货币错配**的组合。其影响延及俄罗斯（[[1998 俄罗斯卢布危机]]）与巴西，并引发关于国际货币基金组织救助条件与资本账户自由化次序的持久争论。

---

## 二、历史背景与起因

### 2.1 东亚高增长的资金逻辑

| 背景 | 说明 |
|------|------|
| **出口导向高增长** | 东亚经济体以出口为引擎实现多年高增长 |
| **外资大量流入** | 全球低利率环境下，国际资本涌入东亚 |
| **金融自由化提速** | 资本账户开放与国内金融自由化推进过快 |
| **盯住美元汇率** | 各国货币盯住美元，提供汇率稳定预期 |
| **企业高杠杆** | 企业与银行大量举借短期外债，期限与币种双错配 |

### 2.2 内在脆弱性

- **经常账户赤字**：资本流入推高本币与资产价格，进口扩张、逆差积累
- **短期外债过多**：借短投长，依赖滚动再融资，一旦融资冻结即断裂
- **货币错配**：收入以本币计、债务以外币计，贬值即成灾难
- **银行体系薄弱**：监管不足、信贷集中、道德风险
- **汇率刚性**：盯住美元使本币高估，丧失调节能力

```
外资涌入 + 金融自由化
       ↓
信贷扩张 → 资产泡沫 + 经常账户赤字
       ↓
美元走强 + 出口放缓 → 外资撤离
       ↓
短期外债滚动断裂 → 汇率承压
       ↓
泰铢放弃盯住 → 传染扩散
       ↓
多国汇率崩盘 + 债务危机 + 经济衰退
```

## 三、机制与传导路径

### 3.1 危机引爆：泰铢失守（1997.7）

泰国长期经常账户赤字，依赖短期外资融资。1997 年出口放缓、美元走强后，投机者攻击泰铢，外储消耗殆尽，泰国被迫于 1997 年 7 月放弃盯住汇率，泰铢大幅贬值。

### 3.2 传染机制

| 环节 | 内容 |
|------|------|
| **竞争性贬值** | 一国贬值削弱邻国出口竞争力，引发连锁贬值 |
| **信心传染** | 投资者"一刀切"撤出东南亚与东亚 |
| **共同脆弱性** | 各国同样存在短债、错配与银行问题 |
| **IMF 救助与紧缩** | 救助条件（紧缩财政、高利率）一度加深衰退，引发反弹 |
| **区域蔓延** | 马来西亚、印尼、韩国相继陷入危机 |

### 3.3 香港的防御战

香港在[[联系汇率制度]]下遭受冲击，[[港元]]与股市承压。香港金管局与政府动用外汇基金入市干预，捍卫联系汇率，最终守住，但代价高昂（参见 [[1998香港金融保卫战]]）。

### 3.4 韩国：外储耗竭与 IMF 救助

韩国大企业集团（财阀）高杠杆扩张，短期外债规模庞大。1997 年底韩元暴跌、外储告罄，韩国被迫向 IMF 申请救助，并接受结构性改革条件。

```
泰铢贬值 → 区域内货币竞相贬值
       ↓
外债本币成本飙升 + 银行坏账暴露
       ↓
资本外逃 → 汇率与股市双杀
       ↓
政府外储耗竭 → 求助 IMF
       ↓
紧缩政策 → 经济深度衰退 → 缓慢复苏
```

## 四、关键数据与案例

> 说明：以下为历史事实的概括性表述，精确值存在多种口径。

| 经济 | 危机表现 |
|------|---------|
| **泰国** | 泰铢大幅贬值，金融体系崩溃，经济深度衰退 |
| **印度尼西亚** | 盾币暴跌，经济收缩最严重，叠加政治动荡 |
| **韩国** | 韩元暴跌，财阀债务危机，接受 IMF 救助 |
| **马来西亚** | 林吉特与股市暴跌，实施资本管制 |
| **香港** | 联系汇率受冲击，政府入市捍卫 |

### 4.1 国际救助

IMF 牵头对泰国、印尼、韩国提供大规模救助，附带财政紧缩与结构性改革条件。紧缩与高利率短期加剧了衰退，引发对"华盛顿共识"式危机管理的激烈批评。

### 4.2 复苏

1998-1999 年起，在汇率大幅低估、出口恢复、区域政策协调与全球经济回暖的带动下，东亚经济逐步走出危机。多国加强了外汇储备积累与金融监管。

## 五、后果与教训

### 5.1 直接后果

- **货币与资产价格暴跌**：多国汇率、股市、房价大幅缩水
- **企业与银行破产潮**：高杠杆企业资不抵债，银行坏账爆发
- **经济深度衰退**：部分经济体 GDP 收缩，失业与贫困上升
- **区域政治变化**：印尼政权更迭、多国政府更替
- **国际反思**：IMF 条件、资本账户自由化次序、汇率制度选择被重新审视

### 5.2 关键教训

| 教训 | 内容 |
|------|------|
| **资本账户自由化要有次序** | 开放需与监管、汇率弹性、银行体质配套 |
| **警惕短期外资** | 短债与证券投资可瞬间撤离，需充足外储对冲 |
| **汇率制度要匹配** | 盯住美元在资本自由流动下难以持续（三元悖论） |
| **货币错配是隐性炸弹** | 外币负债 + 本币收入的组合极具破坏性 |
| **银行监管是底线** | 信贷扩张失控是危机的温床 |
| **救助条件要权衡** | 过度紧缩可能加深衰退，需关注社会成本 |

> 参见 [[亚洲金融危机传导机制]]：危机如何从一国传导至区域。
