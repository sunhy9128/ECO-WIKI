# 国产替代

> 用国产供给替换进口依赖 — 从"可用"到"好用"，产业升级与供应链安全的交汇点

## 一、定义

**国产替代**（Import Substitution）指通过政策支持、技术攻关与下游导入，推动国内企业生产**原本依赖进口的产品与技术**，实现供给本土化的过程。它是中国 [[产业升级]] 与供应链安全战略的核心组成部分。

国产替代有两个层次：

- **市场层面**：国产产品在性能、成本上达到可替代进口的水平，被下游主动采用。
- **战略层面**：在关键技术领域降低对进口的依赖，化解 [[卡脖子技术]] 风险。

---

## 二、为什么需要国产替代

### 2.1 三重驱动

| 驱动 | 说明 |
|------|------|
| **安全驱动** | 关键芯片、装备依赖进口，一旦断供将危及产业链，参见 [[卡脖子技术]] |
| **升级驱动** | 制造业从低附加值向高附加值攀升，内需市场培育本土高端供给 |
| **成本驱动** | 进口产品存在溢价与供给波动，本土替代可降低成本与不确定性 |

### 2.2 与产业升级的关系

```
进口依赖（低端组装、核心技术缺失）
       ↓
国产替代（先替代成熟环节）
       ↓
技术攻关（攻克关键环节）
       ↓
自主可控（体系性领先）→ [[新质生产力]]
```

国产替代是 [[产业升级]] 的"中间状态"：先以替代打开市场、积累经验，再向高端突破。

## 三、主要领域与进展模式

### 3.1 半导体领域

- **[[集成电路]]**：从成熟制程向先进制程推进，[[中芯国际]] 等为制造主力。
- **存储芯片**：[[长江存储]]（NAND）、[[长鑫存储]]（DRAM）从零起步追赶，参见 [[存储芯片]]。
- **设备材料**：光刻、刻蚀、沉积设备与光刻胶等国产化率逐步提升。

### 3.2 其他领域

| 领域 | 替代内容 | 代表 |
|------|---------|------|
| **新能源** | 光伏、锂电的国产化率高，已从替代走向全球领先 | 宁德时代等 |
| **高端装备** | 数控机床、工业机器人 | 参见 [[机床]] |
| **工业软件** | CAD/CAE 国产化 | — |
| **民航/航发** | 大飞机与航空发动机 | 参见 [[军工航空产业]] |

## 四、国产替代的推进机制

### 4.1 政策工具

- **需求侧**：政府采购、国产化率考核、"首台套"应用示范。
- **供给侧**：财政补贴、税收优惠、产业基金。
- **生态侧**：标准制定、上下游协同验证。

### 4.2 市场化的关键：下游验证

国产替代的成败不取决于"造出来"，而取决于**"被用起来"**：产品须通过下游的可靠性验证与长期测试，从"能替代"走向"敢替代、愿替代"。这一过程往往以"先低端后高端、先边缘后核心"的节奏推进。

---

## 五、局限与风险

| 局限 | 说明 |
|------|------|
| **技术差距** | 高端环节与进口仍有代差，"替代"不等于"领先" |
| **生态壁垒** | EDA、操作系统等存在生态锁定，替换成本高 |
| **市场意愿** | 部分下游出于风险考虑，对国产导入持谨慎态度 |
| **题材炒作** | 资本市场上的"国产替代"概念鱼龙混杂，需甄别真实兑现 |
| **封闭风险** | 过度封闭替代可能脱离全球分工，损害效率 |

> **核心提醒**：国产替代是"开放的自主"，方向是**可控**而非**自给自足**。真正高质量的替代建立在效率与安全平衡之上——这也是 [[高质量发展]] 对产业政策的隐含要求。

---

## 六、小结

**国产替代**是中国应对 [[卡脖子技术]]、推进 [[产业升级]] 与 [[供应链多元化]] 的核心路径：以政策与需求双轮驱动，先替代、再突破、后领先。对投资者而言，它是理解半导体、新能源、高端装备等赛道长期逻辑的关键框架，也须警惕"替代题材"与"实际兑现"之间的落差。
