# 兵器工业

> 共和国军工的"长子" — 陆战装备与常规武器的产业基石

## 一、定义与概述

**兵器工业**泛指从事武器装备研制与生产的工业体系。狭义上，在中国语境中常指**中国兵器工业集团有限公司**（简称兵器工业集团，英文名 China North Industries Group Corporation，NORINCO），是中央直接管理的国有重要骨干企业，我国国防科技工业的核心力量之一，也是陆军装备的主要供应商。

### 1.1 基本定位

| 维度 | 内容 |
|------|------|
| **隶属** | 国务院国资委监管的中央企业 |
| **行业** | 国防科技工业（兵器） |
| **主要领域** | 坦克装甲车辆、火炮、弹药、光电信息、民爆化工 |
| **地位** | 与[[中国船舶]]、[[中国电科]]并列为国防工业骨干央企 |

### 1.2 与相关概念的关系

- [[国防军工]]：兵器工业是国防军工体系的组成部分
- [[军工航空产业]]：兵工与航空共同构成军工两大制造板块
- [[中国电科]] / [[中国船舶]]：并列的军工央企集团

---

## 二、背景

### 2.1 历史沿革

兵器工业脱胎于新中国早期的兵工厂体系，历经多次整合重组，形成今天以集团化为特征的组织形态。其前身可追溯至建国初期的第五机械工业部（主管兵器），1980 年代后转为企业化运作，1999 年分立为兵器工业与兵器装备两大集团，分工各有侧重。

### 2.2 战略地位

- 陆军装备的科研生产主力，关系国防安全底线
- 军民融合的先行者，民品业务覆盖民爆、化工、装备制造
- 国防工业自主可控的关键环节，涉及大量[[卡脖子技术]]

## 三、产业格局与机制

### 3.1 军品业务结构

```
主战装备（坦克、装甲车、火炮）
       ↓
弹药与毁伤系统（制导弹药、常规弹药）
       ↓
光电与信息化装备（观瞄、火控、侦察）
       ↓
保障与工程装备（工程车辆、防暴装备）
```

### 3.2 民品与军民融合

| 业务 | 说明 |
|------|------|
| **民爆化工** | 工业炸药、雷管等，市占率居前 |
| **特种车辆** | 重型卡车、专用车 |
| **光电材料** | 红外、激光相关材料器件 |
| **海外贸易** | 常规武器与装备的国际军贸业务 |

### 3.3 运作机制

- **集团+研究所+工厂**：集团统一管理，下属研究所负责型号研发，工厂负责批量制造
- **型号研制体系**：论证—设计—试制—试验—定型—批产
- **军贸反哺**：出口创汇与国外需求牵引技术迭代

## 四、关键事件与数据

### 4.1 关键事件

- **两集团分立（1999 年）**：兵器工业与兵器装备集团分设，形成竞争格局
- **主战装备列装**：新一代坦克、远程火箭炮等陆续列装部队
- **军贸出口**：在多个发展中国家市场形成稳定客户群
- **军民融合改革**：混改、资产证券化推进，优质军工资产上市

### 4.2 行业特征

| 特征 | 说明 |
|------|------|
| **计划经济属性强** | 订单驱动，交付以军方需求为纲 |
| **准入壁垒高** | 军工四证等资质门槛 |
| **研发周期长** | 型号从研制到定型通常以十年计 |
| **利润受控** | 定价机制以成本加成与目标价格管理为主 |

## 五、影响

### 5.1 对国防安全

- 保障陆军主战装备的自主供给能力
- 常规武器弹药的战时动员与快速扩产基础

### 5.2 对经济与资本市场

- 军品订单具备逆周期属性，是军工板块的重要组成部分
- 央企改革（混改、重组、资产注入）带来主题投资机会
- 民爆、民品业务与宏观经济景气度相关

### 5.3 对国际军贸格局

- 与美、俄、欧军工企业并存，在中低端市场具备性价比优势
- 出口受地缘政治与国际军控规则约束
