# 2008金融危机

> 从美国房地产泡沫到全球信用冻结 — 二战以来最严重的金融危机

## 一、定义

**2008 年金融危机**（Global Financial Crisis）指 2007-2009 年由**美国次贷危机**引爆、蔓延至全球的金融危机。危机以美国房价见顶回落、次贷违约潮为起点，经**资产证券化**链条放大，最终在 2008 年 9 月[[雷曼兄弟]]破产时演变为**全球系统性金融崩溃**，并拖累实体经济陷入大衰退（Great Recession）。

危机是[[次贷危机]]、影子银行风险与高杠杆金融体系的集中爆发，深刻重塑了全球金融监管格局。

---

## 二、历史背景与起因

### 2.1 危机前的宏观环境

| 背景 | 说明 |
|------|------|
| **低利率与流动性过剩** | 互联网泡沫破裂后美联储持续降息，全球流动性泛滥 |
| **储蓄过剩与"全球失衡"** | 新兴市场与石油出口国积累美元储备，回流美国压低利率 |
| **房市繁荣** | 低利率 + 宽松信贷推动美国房价长期上涨 |
| **金融创新** | 资产证券化、衍生品快速发展，风险被层层包装 |

### 2.2 风险链条的积累

| 环节 | 说明 |
|------|------|
| **次级抵押贷款扩张** | 向信用记录较差的借款人放贷，风控松弛 |
| **资产证券化** | 房贷被打包成 MBS、CDO，风险分散转移 |
| **信用增级与评级失灵** | 评级机构给予高评级，掩盖底层资产质量 |
| **影子银行体系** | 货币市场基金、回购市场、结构性投资载体游离于监管外 |
| **高杠杆** | 投资银行与对冲基金高杠杆持有次贷相关资产 |
| **房价依赖** | 房价上涨是再融资与资产价值的核心支柱 |

```
低利率 + 信贷扩张 → 房价上涨
       ↓
次贷规模扩张 + 证券化包装
       ↓
美联储加息 → 房价见顶回落
       ↓
次贷违约潮 → MBS/CDO 价值崩坏
       ↓
杠杆机构巨亏 → 2008.9 雷曼破产
       ↓
货币市场挤兑 + 信贷冻结 → 全球危机
```

## 三、机制与传导路径

### 3.1 危机的引爆：房价拐点

2006 年后美国房价见顶回落。次级借款人无法再融资，违约率上升；证券化资产价格暴跌，持有者（银行、对冲基金、保险机构）出现巨额亏损。

### 3.2 雷曼破产与系统性冻结

| 环节 | 内容 |
|------|------|
| **2008.3 贝尔斯登** | 被救助式收购，市场警觉 |
| **2008.9.15 雷曼破产** | 政府未出手救助，破产引发全球恐慌 |
| **货币市场挤兑** | 货币市场基金跌破净值，投资者赎回，短期融资冻结 |
| **回购市场断裂** | 抵押品价值缩水，回购利率飙升，杠杆交易被迫去杠杆 |
| **AIG 濒危** | 保险巨头巨量 CDS 敞口，政府被迫接管 |
| **信贷冻结** | 银行惜贷，企业融资断裂，实体经济衰退 |

### 3.3 全球蔓延

美国金融机构的去杠杆与资产抛售迅速传导至欧洲（大量持有美国证券化资产）、新兴市场（资本外流、货币贬值）。危机由金融领域蔓延至实体经济，演变为全球性衰退。

## 四、关键数据与案例

> 说明：以下为历史事实的概括性表述，精确值存在多种口径。

| 阶段 | 事件 |
|------|------|
| **2007** | 次贷违约上升，贝尔斯登旗下基金爆仓，危机初现 |
| **2008.3** | 贝尔斯登被收购，美联储创新工具提供流动性 |
| **2008.9.15** | 雷曼兄弟申请破产，全球恐慌 |
| **2008.9-10** | 政府接管两房与 AIG，货币市场与回购市场冻结 |
| **2008.10-2009** | 多国政府大规模救助银行，美联储开启量化宽松 |
| **2009 中后期** | 全球经济触底，缓慢复苏 |

### 4.1 政策应对

| 政策 | 内容 |
|------|------|
| **央行流动性工具** | 创新工具向银行体系注入流动性 |
| **救助银行体系** | 直接注资、担保、国有化（部分机构） |
| **量化宽松（QE）** | 大规模资产购买压低长期利率 |
| **财政刺激** | 多国推出大规模财政扩张 |
| **监管改革** | 美国[[多德弗兰克法案]]、国际[[巴塞尔协议III]] |

## 五、后果与教训

### 5.1 直接后果

- **全球大衰退**：主要经济体 GDP 收缩，失业率大幅上升
- **银行体系重构**：大量金融机构倒闭或被救助，行业集中度上升
- **主权债务压力**：危机后财政赤字与政府债务激增，欧洲随后爆发主权债务危机
- **货币宽松常态化**：主要央行资产负债表长期扩张
- **监管重塑**：宏观审慎、压力测试、场外衍生品监管加强

### 5.2 关键教训

| 教训 | 内容 |
|------|------|
| **系统性风险不可分散化** | 证券化分散了个体风险，却集中了系统性风险 |
| **影子银行是监管盲区** | 风险潜伏于监管之外的融资体系 |
| "**大而不能倒**" | 系统重要性机构的风险需事前约束 |
| **高杠杆放大尾部风险** | 杠杆让小幅亏损变成致命危机 |
| **救与不救的两难** | 救助引发道德风险，不救助引发系统性崩溃 |
| **宏观审慎必要** | 单一机构监管无法防范系统性风险 |
