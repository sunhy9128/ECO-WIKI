# 金砖国家

> 从投资标签到全球治理平台 — 金砖国家是新兴经济体集体性力量崛起与重塑国际秩序的标志性载体

## 一、定义

**金砖国家**（BRICS）指以新兴市场经济体为核心的国际合作机制。其名称源自巴西、俄罗斯、印度、[[中国]]、南非五国英文首字母的组合：

| 字母 | 国家 |
|------|------|
| B | 巴西（Brazil） |
| R | 俄罗斯（Russia） |
| I | 印度（India） |
| C | 中国（China） |
| S | 南非（South Africa） |

随着扩员，"金砖+"成员扩展至更多新兴市场国家（含沙特、阿联酋、伊朗、[[埃及]]、埃塞俄比亚等），机制代表性进一步扩大。

## 二、背景

### 2.1 从概念到机制

- **2001年**：高盛首席经济学家奥尼尔提出"金砖四国"（BRIC）概念，预测四国将主导全球经济增长
- **2006年**：四国外长首次会晤，概念走向对话平台
- **2009年**：首次正式峰会（叶卡捷琳堡），机制化启动
- **2010年**：南非加入，成为"金砖五国"
- **2024年**：启动新一轮扩员，纳入多个新兴经济体

### 2.2 崛起动因

金砖国家人口与土地面积占全球比重高、增长潜力大，集体诉求是对现有国际经济治理格局（以布雷顿森林体系下的 IMF、世界银行等机构为代表）进行再平衡，争取与自身经济权重相匹配的话语权。

## 三、机制与作用

### 3.1 制度性成果

| 机制 | 定位 |
|------|------|
| **新开发银行（NDB）** | 为新兴市场与发展中国家提供基础设施与可持续发展融资 |
| **应急储备安排（CRA）** | 成员国间的流动性互助机制，缓解外部冲击 |
| **金砖支付系统** | 探索本币结算与替代支付通道（参见 [[金砖支付系统]]） |
| **年度峰会与多边协调** | 就全球治理、安全与经贸议题协调立场 |

### 3.2 核心议题

- **去美元化**：推动本币结算、减少对美元体系的过度依赖（参见 [[去美元化]]、[[美元霸权]]）
- **多极化**：倡导国际关系民主化与[[多极化格局]]
- **全球治理改革**：要求 IMF 份额与投票权改革、提升新兴市场话语权
- **共同发展**：[[粮食]]、能源安全与发展融资合作

## 四、关键事件与数据（概括性）

- 金砖国家经济总量与人口规模在全球占比显著，扩员后覆盖更多能源与新兴市场大国
- 新开发银行累计批准项目覆盖交通、能源、水资源等多领域，贷款规模持续扩大
- 应急储备安排为部分成员国提供危机应对的备用流动性支持
- 金砖框架下本币结算比重逐步提升，推动[[人民币国际化]]与[[CIPS]]应用
- 扩员引发机制内部治理讨论：成员扩容与决策效率、立场协调之间的张力成为焦点

## 五、影响

### 5.1 对国际货币与金融体系

- 金砖本币结算与支付替代方案对美元主导的清算网络形成**渐进分流**（参见 [[美元周期]]、[[金穹系统]]）
- 新开发银行等机构为发展中国家提供多边融资的替代选择，动摇了传统机构的部分垄断
- 但受限于经济体量差异、金融基础设施与政治协调成本，"去美元化"更多是边际性与长期性的

### 5.2 对地缘政治

- 金砖成为新兴市场与"全球南方"协调立场的重要平台
- 与[[中美俄大三角]]、[[中俄全面战略协作伙伴关系]]等议题相互交织
- 大国博弈背景下，金砖扩员兼具经济与战略双重意涵

### 5.3 对中国

- 金砖是中国推动[[人民币国际化]]、扩大朋友圈与参与全球治理的重要抓手
- 能源进口（沙特、俄罗斯、阿联酋等）与金融合作强化能源-货币联动
- 需要在"机制领导者"与"多边平等"之间平衡角色
