# 存储芯片

> 半导体的"大宗商品" — 强周期、高集中、国产化关键赛道

## 一、定义

**存储芯片**（Memory Chip）是**用于存储数据的半导体器件**，是集成电路（IC）的重要品类。与逻辑芯片（负责计算）不同，存储芯片的核心功能是"记住"数据，是计算机、手机、服务器、汽车电子等几乎所有数字设备的必备件。

存储芯片按"断电后是否保留数据"分为两大类：

- **易失性存储（DRAM）**：断电即失，用于内存，速度要求高。
- **非易失性存储（NAND / NOR）**：断电仍保留，用于硬盘、闪存等。

存储芯片行业被称为半导体的"大宗商品"，因为它**标准化程度高、同质化严重、价格受供需周期主导**，是理解半导体产业周期性的核心样本。

---

## 二、主要品类

### 2.1 DRAM（动态随机存取存储器）

- **用途**：手机/服务器/PC 的内存条、显存，CPU 的"工作台"。
- **特征**：工艺先进、容量大、速度快，但断电丢失。
- **市场地位**：存储市场规模最大的单一品类，与 AI 服务器、数据中心需求高度相关。

### 2.2 NAND Flash（闪存）

- **用途**：固态硬盘（SSD）、手机存储、U 盘。
- **特征**：断电不丢数据，按"层数"（堆叠）迭代，3D NAND 是主流。
- **市场地位**：随 AI 数据中心、大模型训练对存储容量需求的爆发而扩张。

### 2.3 NOR Flash

- **用途**：嵌入式系统、汽车电子、IoT 设备的代码存储。
- **特征**：容量较小但读取速度快、可靠性高，市场规模小于 DRAM/NAND。
- **市场地位**：细分市场，国内厂商参与度较高。

## 三、产业链与产业格局

### 3.1 产业链条

```
设计/IDM（晶圆设计+制造）→ 设备与材料 → 晶圆代工/制造 → 封测 → 终端应用
     ↑                                            ↓
     └──────── 周期性供需与价格信号 ────────────┘
```

存储芯片多为 **IDM 模式**（设计与制造一体化），核心环节包括晶圆制造、封装测试、设备材料（光刻、刻蚀、沉积等）。

### 3.2 市场格局：高度集中

全球存储芯片市场由少数巨头主导，合称 [[存储三巨头]]：

- **[[三星电子]]**、**[[SK海力士]]**（[[韩国]]）
- **[[美光科技]]**（[[美国]]）

三家合计占据全球 DRAM 与 NAND 市场的主要份额，形成了"寡头供给 + 强周期"的结构，参见 [[存储三巨头]]。

### 3.3 中国企业

中国大陆的 [[长江存储]]（NAND）与 [[长鑫存储]]（DRAM）是存储国产化的主要力量，处于追赶期，见 [[国产替代]]。

## 四、行业周期特征

存储芯片是**周期性极强的行业**，被称为"半导体周期"最典型的代表：

```
需求扩张 → 供给紧张 → 价格暴涨 → 厂商扩产
       ↑                              ↓
   价格企稳 ← 库存出清 ← 价格暴跌 ← 产能过剩
```

### 4.1 周期驱动因素

| 因素 | 说明 |
|------|------|
| **供给端** | 扩产周期长（建厂 1-2 年以上），产能弹性小，易错配 |
| **需求端** | 与 PC/手机/服务器等终端出货量、AI 资本开支强相关 |
| **库存周期** | 下游（品牌厂）补库/去库放大价格波动 |
| **价格机制** | 产品同质化，价格由供需决定，波动剧烈 |

### 4.2 周期中的投资含义

- **周期底部**：价格跌破成本、厂商缩减资本开支 → 关注反转（"库存去化"）。
- **周期顶部**：价格暴涨、全员扩产 → 警惕过剩风险。
- **与 AI 的关系**：大模型训练与推理带来 HBM（高带宽内存）等结构性需求，参见 [[HBM]]。

## 五、卡脖子属性与国产化

存储芯片是 [[卡脖子技术]] 的重点领域：

- **技术与设备依赖**：先进制程（如 DRAM 的高端工艺）依赖进口设备与材料。
- **出口管制**：高端设备与产品的供应可能受到国际出口管制影响，参见 [[出口管制]]。
- **国产化路径**：从成熟制程切入、逐步向高端突破，配合政策支持与下游导入。

存储国产化的意义不仅是产业升级，更关乎供应链安全，见 [[国产替代]] 与 [[供应链多元化]]。

---

## 六、小结

存储芯片是半导体的"大宗商品"：**品类简单、格局集中、周期剧烈、战略重要**。理解存储芯片，就抓住了半导体周期性的核心；跟踪存储的价格、库存与资本开支，是观察全球科技产业冷暖的重要窗口。
