# 经常账户

> 经常账户是[[concepts/国际收支|国际收支]]平衡表的核心，记录一国与世界的"钱货往来"。持续逆差意味着对外融资依赖，持续顺差则意味着储蓄外流——经常账户余额，是一国对外经济健康度的"体检报告"。

## 一、定义

**经常账户**（Current Account）是国际收支平衡表中记录一国与其他经济体之间**货物、服务、初次收入和二次收入**跨境交易流量的账户。它反映一国真实的对外净赚取能力：经常账户余额等于国民储蓄与国内投资之差，也近似等于该国对外净投资（资本流出）或净借款（资本流入）。

## 二、账户构成

### 2.1 四大子项

| 子项 | 内容 |
|------|------|
| **货物贸易** | 商品进出口（有形贸易），是多数经济体顺差/逆差的主要来源 |
| **服务贸易** | 运输、旅游、金融、知识产权等无形服务跨境收支 |
| **初次收入** | 投资收益（股息、利息）、雇员报酬等要素收入净额 |
| **二次收入** | 侨汇、政府无偿转移等经常转移收支 |

### 2.2 与资本账户的关系

- 国际收支恒等式：**经常账户 + 资本与金融账户 + 储备资产变动 = 0**（净误差与遗漏另计）。
- 经常账户顺差意味着资本净流出（对外净投资）；经常账户逆差则依赖资本流入或动用外汇储备弥补。
- 一国的"[[concepts/双顺差|双顺差]]"（经常账户 + 资本账户双顺差）会带来外汇储备持续积累（参见[[双顺差]]）。

## 三、背景与决定因素

### 3.1 顺差/逆差的形成逻辑

- **储蓄-投资缺口**：储蓄高于投资 → 经常账户顺差；投资高于储蓄 → 逆差。
- **汇率与竞争力**：本币低估、出口竞争力强 → 顺差；本币高估、进口依赖强 → 逆差。
- **[[人口结构]]**：人口红利期储蓄率高，倾向于顺差；老龄化则动用储蓄，逆差倾向上升。
- **资源禀赋**：石油、矿产出产国依靠资源出口获得结构性顺差。

### 3.2 逆差的预警意义

- 经常账户持续逆差意味着**对外融资依赖**：须以资本流入（外债、FDI、证券投资）弥补，一旦资本流入逆转，将被迫调整（贬值、紧缩）甚至触发危机。
- 学术界常以经常账户逆差占 GDP 的比重作为判断外部脆弱性的参考指标，逆差越大、持续越久，脆弱性越高。

## 四、关键数据与案例

- **中国双顺差**：中国长期保持经常账户与资本账户双顺差，外汇储备快速积累，构成"出口导向"增长模式的宏观镜像（参见[[双顺差]]、[[出口导向型经济体]]）。
- **脆弱五国**：2013 年前后市场将印度、印尼、巴西、[[Turkey (土耳其)]]、南非列为"脆弱五国"，其共性之一即经常账户逆差与对外部融资的高度依赖（参见[[脆弱五国（Fragile Five）]]）。
- **石油美元盈余**：[[OPEC]] 产油国在油价上行期经常账户大幅顺差，形成石油美元回流（参见[[石油美元环流]]）。
- **斯里兰卡违约**：2022 年斯里兰卡旅游收入崩溃、进口成本飙升，经常账户压力叠加外储枯竭，最终酿成主权违约（参见[[2022 斯里兰卡违约]]）。
- **1997 亚洲危机**：危机前泰国等国经常账户逆差持续扩大，过度依赖短期资本流入弥补，资本逆转时即告崩溃（参见[[1997亚洲金融危机]]）。

## 五、后果与影响

### 5.1 对汇率

- 顺差国本币存在升值压力，逆差国本币承压；经常账户是汇率中期走势的重要基本面（购买力平价与收支平衡视角）。

### 5.2 对政策

- 逆差国被迫紧缩财政货币或依赖[[concepts/资本管制|资本管制]]，政策空间收窄；顺差国面临本币升值与"贸易摩擦"压力。
- 经常账户调整往往通过汇率贬值、需求收缩与资产价格调整实现，调整过程可能伴随阵痛。

### 5.3 对金融稳定

- 经常账户逆差 + 外币债务高企 + 外汇储备薄弱，构成新兴市场危机的"高危组合"，是美元紧缩周期中率先承压的一类经济体。

### 5.4 按经济体类型的解读

| 经济体类型 | 经常账户特征 | 典型含义 |
|-----------|------------|---------|
| **出口导向型** | 长期顺差 | 储蓄外流、外储积累，本币有升值压力（参见[[出口导向型经济体]]） |
| **资源出口型** | 顺差随大宗商品价格波动 | 石油、矿产品价格决定外部盈余（参见[[石油美元环流]]） |
| **高逆差新兴市场** | 持续逆差、依赖资本流入 | 外部融资中断即陷入危机（参见[[脆弱五国（Fragile Five）]]） |
| **成熟顺差国** | 结构性顺差 | 老龄化储蓄释放前长期对外投资 |

### 5.5 常见的误读

- **顺差不等于好事**：顺差可能伴随内需不足、储蓄过剩与贸易摩擦，调整压力同样存在。
- **逆差不等于坏事**：增长期经济体阶段性逆差（借入资本用于投资）未必不可持续，关键是逆差成因与融资结构。
- **余额看趋势**：单季数据噪声大，应关注占 GDP 比重的趋势与融资结构的可持续性。
