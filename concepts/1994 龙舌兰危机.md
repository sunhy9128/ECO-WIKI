# 1994 龙舌兰危机

> 比索崩盘让"墨西哥奇迹"现形 — 第一场以组合投资外流为动力的新兴市场危机

## 一、定义

**1994 龙舌兰危机**（Tequila Crisis）指 1994 年底至 1995 年初**墨西哥比索汇率崩溃**引发的金融危机。墨西哥曾被誉为"改革明星"，1990 年代初经济自由化与北美自由贸易协定令外资蜂拥而入；1994 年 12 月比索被迫贬值并放弃汇率区间后，资本恐慌性外逃，比索大幅贬值、利率飙升、经济陷入深度衰退。

危机得名于墨西哥国酒"龙舌兰"，因其**传染效应**也波及阿根廷、巴西等拉美国家，被称为"龙舌兰效应"。这是 1990 年代第一场以**组合投资（证券投资）快速流出**为典型特征的新兴市场危机。

---

## 二、历史背景与起因

### 2.1 1990 年代初的"墨西哥奇迹"

| 背景 | 说明 |
|------|------|
| **经济改革** | 私有化、贸易自由化、放松金融管制 |
| **北美自由贸易协定（1994）** | 市场信心高涨，外资流入预期增强 |
| **资本账户开放** | 取消资本管制，外资可自由进出 |
| **稳定汇率政策** | 比索盯住美元、波动区间逐步放宽，被视为隐性锚 |
| **高利率吸引外资** | 比索国债利率远高于美元利率，套息交易盛行 |

### 2.2 脆弱性积累

- **经常账户赤字扩大**：进口激增、比索高估，经常账户逆差占 GDP 比重持续攀升
- **外资结构失衡**：流入以短期证券投资（比索国债为主）为主，而非直接投资
- **银行体系快速扩张**：金融自由化后信贷高速增长，坏账隐患积累
- **政局动荡**：1994 年恰帕斯州武装起义、执政党总统候选人遇刺，信心动摇

### 2.3 触发因素

- **美联储加息**：1994 年美国进入加息周期，全球资本回流美元资产
- **比索高估**：高通胀使比索实际汇率明显高估
- **资本流出加速**：证券投资者撤资，外储快速消耗
- **1994.12 政治冲击**：新任总统就职、社会动荡，市场恐慌发酵

```
经常账户赤字 + 比索高估 + 外资以短期套息为主
       ↓
美联储加息 → 套息交易逆转
       ↓
外储快速消耗
       ↓
12 月 20 日比索贬值
       ↓
恐慌性抛售 → 汇率区间制度被放弃 → 危机全面爆发
```

## 三、机制与传导路径

### 3.1 危机机制

| 环节 | 内容 |
|------|------|
| **盯住汇率脆弱性** | 汇率区间看似稳定，实则高估，积累贬值压力 |
| **套息交易逆转** | 利率差收窄 + 贬值预期 → 套息头寸平仓 |
| **外储耗尽** | 央行消耗外汇储备维持汇率 |
| **贬值螺旋** | 贬值 → 外债本币成本上升 → 进一步贬值预期 |
| **利率飙升** | 央行大幅加息以稳定比索，国内信贷收缩、银行承压 |
| **实体冲击** | 需求崩溃、企业倒闭、银行业危机 |

### 3.2 传染机制（龙舌兰效应）

资本流向相似的新兴市场被"一刀切"式抛售：阿根廷、巴西等国即便基本面不同，也遭受到资本外流与货币贬值的波及。投资者从"逐个评估基本面"转向"整体撤出新兴市场"，即所谓**羊群效应与传染**。

## 四、关键数据与案例

> 说明：以下为历史事实的概括性表述，精确值存在多种口径。

| 阶段 | 事件 |
|------|------|
| **1994.12.20** | 墨西哥宣布比索贬值，市场未达预期、恐慌加剧 |
| **1994.12 下旬** | 汇率区间制度被迫放弃，比索进入自由浮动 |
| **1995 年初** | 比索大幅贬值，国内利率飙升，经济陷入严重衰退 |
| **1995** | 国际救助包出台（美国牵头 + IMF 支持），稳定市场 |
| **1995-1996** | 墨西哥逐渐恢复，出口（尤其对美出口）成为复苏引擎 |

### 4.1 国际救助

危机后美国与 IMF 牵头提供大规模救助，条件包括：紧缩财政、银行业重组、强化金融监管。这一救助模式随后被用于亚洲金融危机，也引发了关于**道德风险**（鼓励投机者冒险）的长期争论。

## 五、后果与教训

### 5.1 直接后果

- **比索大幅贬值**，墨西哥经济陷入 1995 年深度衰退
- **银行业危机**：高利率与坏账暴露，多数银行被国有化重组
- **通胀上升**、实际工资下降、贫困人口增加
- **国际救助与道德风险争论**：奠定后续救助框架的争议基础

### 5.2 关键教训

| 教训 | 内容 |
|------|------|
| **汇率制度要与基本面匹配** | 高估的盯住汇率必然积累危机 |
| **警惕"好外资、坏外资"** | 短期证券投资可迅速撤离，比直接投资更危险 |
| **资本账户开放要有序** | 金融自由化与监管能力需同步 |
| **外储是缓冲** | 盯住汇率制度需要充足的外汇储备 |
| **危机需要快速协调应对** | 救助越迟，传染与损失越大 |

> 参见 [[联系汇率制度]]：香港在 1997-98 年用更高的外储与纪律维护了联系汇率，与墨西哥形成对照。
