# MACD 指标

> 最经典的趋势类技术指标之一 — 用两条均线的"聚散"刻画趋势的强弱与拐点

## 一、定义

**MACD 指标**（指数平滑异同移动平均线，Moving Average Convergence Divergence），由 Gerald Appel 在 20 世纪 70 年代提出，是**基于移动平均线的趋势跟踪指标**。它通过比较两条不同周期的指数移动平均线（EMA）之间的收敛与发散关系，判断价格趋势的方向、强弱以及潜在的转折点。

MACD 属于趋势类指标，适合**有趋势的行情**，在震荡市中信号质量较差。它在 A 股与海外市场均被广泛使用，是 [[技术分析指标]] 体系中最常见的标配指标之一。

---

## 二、计算逻辑

MACD 由三部分组成：DIF（快线）、DEA（慢线/信号线）、MACD 柱。

### 2.1 计算步骤

```
1. EMA12 = 12 日指数移动平均线
   EMA26 = 26 日指数移动平均线
2. DIF = EMA12 − EMA26
3. DEA = DIF 的 9 日指数移动平均（信号线）
4. MACD 柱 = 2 × (DIF − DEA)
```

- **EMA12**（快线）：对短期价格更敏感。
- **EMA26**（慢线）：代表中期趋势。
- **DIF**：快慢线的差值，衡量短期趋势相对中期趋势的偏离。
- **DEA**：DIF 的平滑，用于过滤噪声。
- **MACD 柱**：DIF 与 DEA 的差值放大两倍，直观呈现动量强弱（红柱为正值、绿柱为负值）。

> **注**：12/26/9 为默认参数，可依品种与周期调整，但参数改变会直接影响信号频率与质量。

## 三、使用信号

### 3.1 金叉与死叉

| 信号 | 定义 | 含义 |
|------|------|------|
| **金叉** | DIF 上穿 DEA | 短期趋势转强，偏多信号 |
| **死叉** | DIF 下穿 DEA | 短期趋势转弱，偏空信号 |

金叉/死叉在 0 轴**上方**出现（多头趋势中的回调再向上）通常强于 0 轴下方出现（空头趋势中的反弹），需结合位置判断。

### 3.2 零轴

- **DIF/DEA 在 0 轴上方**：中期趋势偏多，价格处于多头结构。
- **DIF/DEA 在 0 轴下方**：中期趋势偏空，价格处于空头结构。
- **上穿/下穿 0 轴**：中期趋势的确认性拐点，信号强于普通金叉死叉。

### 3.3 背离

背离是 MACD 最有价值、也最难把握的信号：

- **顶背离**：价格创新高，但 DIF/MACD 柱未创新高 → 上涨动能衰减，警惕见顶。
- **底背离**：价格创新低，但 DIF/MACD 柱未创新低 → 下跌动能衰竭，关注反转。

> 背离属于**概率性预警**而非确定性信号，可连续多次背离，须结合价格结构与量能验证。

### 3.4 红绿柱变化

- 红柱**伸长**：多头动能增强；红柱**缩短**：动能衰减。
- 绿柱**伸长**：空头动能增强；绿柱**缩短**：动能衰竭。
- 柱体"面积"与"收敛"常用于判断趋势尾声。

## 四、应用场景与局限

### 4.1 适用场景

- **趋势跟踪**：判断中期多空结构，用于仓位方向管理。
- **择时辅助**：与 K 线形态、[[量价关系]] 结合过滤噪声。
- **指数与个股通用**：适用于大盘指数、行业指数与个股的日线/周线级别。

### 4.2 局限与风险

| 局限 | 说明 |
|------|------|
| **滞后性** | 基于均线，信号天然滞后于价格 |
| **震荡市失灵** | 无趋势时金叉死叉频繁，产生"假信号" |
| **背离可钝化** | 强趋势中背离可反复出现，逆势交易风险高 |
| **参数敏感** | 默认参数不适用所有品种与周期 |
| **单指标依赖** | 单独使用易被噪声误导 |

> **核心提醒**：MACD 是"趋势的跟随者"，不是"趋势的预言者"。它最有价值的用法是**顺势确认**（在趋势方向回调企稳时配合金叉入场），而非逆势抄底摸顶。实战中常与 [[常用技术指标深度]] 中的其他指标（RSI、KDJ、量能指标）交叉验证。

---

## 五、小结

MACD 用两条 EMA 的聚散关系，把"趋势方向 + 趋势强弱 + 拐点预警"浓缩成一套标准化信号。它简单、通用、可量化，但**滞后**与**震荡市失真**是先天缺陷。正确的用法是把 MACD 作为趋势过滤器与动量参考，放在 [[技术分析]] 的完整框架中与其他工具配合，而不是单独依赖。
