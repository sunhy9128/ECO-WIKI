# ADM

> 从粮食加工起家的美国农业巨头 — 全球粮食产业链"ABCD"四大粮商之首

> **🔗 相关语境**：本页在 [[五神]]（全球粮食产业链五大巨头）与 [[粮食危机]] 的讨论中被引用。ADM 是理解"国际粮商如何控制从种子到餐桌的产业链"的关键样本。

## 一、概述

### 1.1 定义

**ADM**（Archer-Daniels-Midland，中文常称"阿丹米"）是一家美国跨国食品加工与农产品贸易公司，总部位于芝加哥，是全球规模最大的农业综合企业之一。它与邦吉（Bunge）、嘉吉（Cargill）、路易达孚（Louis Dreyfus）并称国际粮食贸易的"**ABCD 四大粮商**"，是全球粮食定价体系与供应链网络的核心节点。

### 1.2 历史脉络

- 公司由 Archer 与 Daniels 于二十世纪初在美国中西部创立，后与 Midland 合并形成现名。
- 早期以谷物加工、亚麻籽油压榨起家，后逐步扩张至大豆压榨、玉米加工、淀粉与甜味剂、乙醇与生物燃料、营养配料等。
- 通过上百年的并购与全球化布局，成长为覆盖种植、仓储、运输、加工、贸易、分销的垂直一体化农业巨头。

### 1.3 在产业链中的位置

ADM 处于粮食产业链的**中游加工与贸易环节**：

```
上游（种子、化肥、农药）→ 中游（收储、物流、压榨、加工、贸易）→ 下游（食品、饲料、油脂、燃料）
```

上游由孟山都等种业巨头把控，中游由 ADM 等四大粮商主导，下游连接全球食品工业与消费者。ADM 的核心竞争力在于**规模、物流网络与定价权**，而非单一产品的技术壁垒。

## 二、商业模式与经营机制

### 2.1 主要业务板块

| 板块 | 内容 | 收入属性 |
|------|------|----------|
| **农业服务** | 谷物收储、运输、贸易、出口 | 靠规模与价差 |
| **油籽加工** | 大豆、油菜籽等压榨出油与豆粕 | 加工利润 |
| **淀粉与甜味剂** | 玉米深加工、果葡糖浆等 | 相对稳定 |
| **营养与配料** | 人类营养、动物营养产品 | 高附加值 |

### 2.2 利润来源

- **贸易价差**：利用全球各市场的供需失衡与时间差赚取价差，本质上是"在正确的时间、正确的地点、以正确的价格搬运粮食"。
- **加工毛利**：压榨大豆的利润来自"豆油 + 豆粕"的销售收入与大豆成本的差额，随压榨价差（Crush Spread）波动。
- **物流与仓储收益**：控制港口、铁路、仓储设施，既降低成本又获得通道价值。
- **风险管理**：大规模运用期货与期权对库存和订单进行套期保值，将价格风险对冲出去。

### 2.3 基差与套保

四大粮商之所以能在剧烈波动的农产品价格中持续经营，关键在于**以套期保值锁定利润、以基差定价转移风险**：

```
农民/贸易商 → 基差定价（现货价 = 期货价 + 基差）→ ADM 买入
ADM → 在期货市场卖出对应合约 → 锁定销售价与利润
ADM → 现货售出后平仓期货 → 风险对冲完成
```

基差定价使 ADM 在承担库存物理风险的同时，把商品价格波动风险转移给期货市场。

## 三、ADM 与全球粮食体系

### 3.1 "ABCD"格局

国际粮食贸易长期由四大粮商寡头垄断，其影响力体现为：

- 掌控全球谷物与油籽贸易的绝大部分份额；
- 主导主要农产品出口国的港口、仓储与物流基础设施；
- 在芝加哥期货交易所等定价中心具有举足轻重的地位，深刻影响全球粮食定价。

### 3.2 大豆贸易与新兴市场

ADM 是全球大豆产业链的重要参与者，业务覆盖巴西、阿根廷、巴拉圭等南美大豆主产区以及东南亚。其模式是：

- 在新兴市场大豆产区建立压榨产能与出口物流；
- 将压榨利润与贸易网络本地化，深度绑定当地供应链；
- 与主产国的种植、贸易、融资体系形成一体化生态。

### 3.3 与中国的联系

中国是全球最大的大豆进口国，ADM 等国际粮商在中国市场的渗透路径长期受关注：

- 通过合资、参股方式参与中国油脂压榨行业，一度被指控制了中国相当比例的压榨产能（见 [[五神]] 的相关梳理）；
- 在进口大豆定价、压榨利润分配、市场风险传导等方面对国内油料产业链产生显著影响；
- 由此引发关于**粮食安全**、产业链自主可控的讨论（见 [[粮食安全]]、[[大豆战争]]）。

## 四、应用与局限

### 4.1 积极面：效率与稳定

- 全球化的收储、物流与贸易体系降低了粮食跨国配置的运输成本与信息成本；
- 期货套保体系为整个产业链提供了价格发现与风险管理工具；
- 规模经济使单吨加工与贸易成本持续下降（见 [[规模经济与范围经济]]）。

### 4.2 消极面：寡头与安全风险

- **定价权集中**：四大粮商对全球粮食贸易的高度控制，削弱了主产国与进口国的议价能力；
- **利润随波动放大**：粮价剧烈波动时期，粮商往往获得超额利润，被批评为"发灾难财"；
- **供应链武器化风险**：当粮食贸易被地缘政治化时，进口国可能面临断供风险，这构成进口国的战略脆弱点。

### 4.3 治理与争议

- ADM 历史上曾卷入价格操纵等反垄断调查，也因会计与内部治理问题受到监管关注；
- 作为跨国巨头，其财务核算的复杂性、子公司层级嵌套等问题，也是各国监管与审计的重点。

## 五、与中资粮商的对比

| 维度 | ADM 等国际粮商 | 中储粮、中粮等中资企业 |
|------|---------------|----------------------|
| **业务重心** | 全球贸易与加工 | 储备调节 + 国内贸易 |
| **定价地位** | 国际定价主导者 | 国内市场价格稳定器 |
| **风险偏好** | 主动承担并对冲价格风险 | 以保供稳价为优先 |
| **国际网络** | 遍布全球的物流与港口 | 仍在扩展之中 |

中资粮企在 [[粮食安全]] 战略下承担**储备调节**与**进出口缓冲**职能，与四大粮商的纯市场化逻辑不同。
