# 2015瑞郎危机

> 央行承诺的汇率上限一夜取消，瑞郎瞬间暴涨 — 外汇市场的高杠杆黑天鹅

## 一、定义

**2015 瑞郎危机**（Swiss Franc Shock）指 2015 年 1 月 15 日[[瑞士央行]]突然宣布**取消瑞士法郎兑欧元 1.20 的汇率上限**，瑞郎瞬间大幅升值（日内对欧元一度涨约三成），导致大量外汇经纪商、银行与杠杆投资者爆仓的事件。

事件被市场称为"黑天鹅"：瑞士央行此前反复强调捍卫上限，却在毫无预警的情况下放弃承诺，摧毁了大量以"央行承诺"为前提的头寸。

---

## 二、历史背景与起因

### 2.1 汇率上限的由来（2011）

| 背景 | 说明 |
|------|------|
| **欧债危机避险** | 2011 年[[欧债危机]]爆发，避险资金涌入瑞士 |
| **瑞郎飙升** | 瑞郎对欧元大幅升值，冲击出口型经济 |
| **通缩与增长压力** | 汇率高估压低进口价格、削弱出口，加剧通缩 |
| **设限** | 2011.9 瑞士央行宣布瑞郎兑欧元上限 1.20，捍卫汇率 |

### 2.2 上限为何难以为继

- **干预成本高**：为维持上限，央行需大量买入欧元、抛售瑞郎，外汇储备急剧膨胀
- **外储风险**：持有的欧元资产面临贬值与负利率损失
- **欧元区量化宽松临近**：2015 年初[[欧洲央行]]即将启动大规模 [[资产购买计划]]，欧元走弱，瑞郎升值压力骤增
- **负利率**：瑞士央行已实施负利率，进一步压制的空间有限

```
欧债危机 → 瑞郎避险升值
       ↓
2011 年设 1.20 上限，外储急剧膨胀
       ↓
2015 年欧央行 QE 在即，欧元走弱
       ↓
维持上限成本飙升 → 瑞士央行选择放弃
       ↓
2015.1.15 取消上限 → 瑞郎暴涨
```

## 三、机制与传导路径

### 3.1 危机机制

| 环节 | 内容 |
|------|------|
| **承诺与预期** | 市场以央行"必守上限"为信仰，大量头寸押注其延续 |
| **瞬间跳升** | 取消上限后瑞郎对欧元瞬间大幅升值 |
| **止损连环** | 止损指令被触发，价格进一步冲高，流动性瞬间枯竭 |
| **杠杆爆仓** | 保证金不足，经纪商与客户头寸被强制平仓 |
| **经纪商倒闭** | 负余额客户违约，部分外汇经纪商资不抵债 |
| **央行信誉冲击** | 违背承诺损害央行可信度，市场重新定价央行干预 |

### 3.2 谁受损

- **外汇经纪商**：向客户提供高杠杆，客户爆仓后由经纪商承担亏损，多家经纪商破产
- **做多欧元/做空瑞郎的投资者**：套息与避险头寸反向亏损
- **瑞士出口企业**：瑞郎升值短期冲击出口竞争力
- **持有瑞郎多头者受益**：瑞郎急涨使多头获利，但市场剧烈波动使多数参与者受损

```
1.20 上限取消
       ↓
瑞郎对欧元瞬间升值约 30%
       ↓
止损单踩踏、流动性枯竭
       ↓
杠杆账户连环爆仓
       ↓
经纪商坏账 → 破产或被收购
       ↓
全球外汇市场波动放大
```

## 四、关键数据与案例

> 说明：以下为历史事实的概括性表述，精确值存在多种口径。

| 阶段 | 事件 |
|------|------|
| **2011.9** | 瑞士央行设定 1.20 上限 |
| **2014.12** | 瑞士央行引入负利率辅助维持上限 |
| **2015.1.15** | 突然宣布取消上限，瑞郎暴涨 |
| **2015.1 后续** | 多家外汇经纪商破产，部分被接管；瑞士央行继续负利率 |
| **2015-2016** | 瑞郎高位波动，瑞士经济缓慢适应，通缩压力持续 |

### 4.1 瑞士央行的代价

- 取消上限前积累的巨额外汇储备面临账面损失
- 负利率长期化，银行业盈利承压
- 央行信誉受损，市场对"央行干预承诺"的信任下降

---

## 五、后果与教训

### 5.1 直接后果

- 外汇经纪商行业洗牌，杠杆交易规则收紧
- 瑞郎长期强势，瑞士出口与通胀持续承压
- 负利率与干预工具重新组合，央行应对空间受限
- 全球外汇市场对"央行承诺"的定价方式改变

### 5.2 关键教训

| 教训 | 内容 |
|------|------|
| **央行承诺不是保险** | 政策承诺可被改变，市场不可押注其绝对兑现 |
| **高杠杆是致命伤** | 外汇保证金交易的杠杆放大了尾部风险 |
| **干预成本有极限** | 维持汇率目标与央行资产负债表的代价终会逼出转折 |
| **退出时机的悖论** | 越早退出损失越小，但越可能提前暴露脆弱头寸 |
| **突发事件的定价** | 极端行情下流动性消失，止损未必能成交 |

> 参见 [[汇率制度]]：固定汇率、上限与自由浮动之间的制度选择；瑞士从"上限"退回浮动，是一场剧烈的制度切换。
