# 伊朗制裁

> 自 1979 年伊斯兰革命以来，美国对伊朗实施了持续四十余年的多轮经济[[concepts/金融制裁|金融制裁]]，覆盖石油出口、银行结算、航运保险与军工技术等领域。伊朗制裁是"[[concepts/武器化相互依存|武器化相互依存]]"的长期样本，深刻重塑了全球能源市场与[[entities/中东地缘格局|中东地缘格局]]。

## 一、定义

**伊朗制裁**指美国（及部分西方盟国）以核问题、地区行为、人权等为由，对伊朗实施的长期性经济金融制裁体系。制裁贯穿石油、金融、航运、保险、科技等关键环节，并结合[[二级制裁]]对第三国形成连带威慑，是全球制裁史上持续时间最长、体系最完整的案例之一。

## 二、背景与起因

### 2.1 历史脉络

| 时期 | 事件 |
|------|------|
| **1979** | 伊斯兰革命、美国人质危机，美伊断交，美国启动资产冻结与全面制裁 |
| **1995-1996** | 克林顿政府对伊朗石油与贸易实施全面禁运，并推动域外制裁 |
| **2006-2015** | 因伊朗核计划，联合国安理会及美欧多轮制裁升级，石油出口与银行结算受重创 |
| **2015** | 《伊核协议》（JCPOA）达成，伊朗以限制核活动换取制裁部分解除 |
| **2018** | 美国单方面退出伊核协议并重启"极限施压"制裁，覆盖石油、金融、钢铁等 |
| **2020 后** | 制裁维持并叠加区域冲突升级，中东局势多次因伊朗因素高度紧张 |

### 2.2 战略动因

- **核不扩散**：阻止伊朗获得核武器能力是其核心公开目标。
- **地区影响力**：削弱伊朗对中东代理武装（[[真主党]]、胡塞武装等）的支持。
- **能源博弈**：压缩伊朗石油出口，影响 OPEC 内部的产量与定价格局。

## 三、机制与传导路径

### 3.1 制裁工具组合

```
石油出口禁运（限制买家与航运）
       ↓
金融制裁（切断美元清算、冻结资产）
       ↓
二级制裁（威慑第三国银行、贸易商、保险公司）
       ↓
航运与保险限制（封锁油轮运输与保险承保）
       ↓
出口管制（能源技术、军民两用、无人机等）
       ↓
霍尔木兹海峡安全风险（地缘冲突放大器）
```

### 3.2 核心环节

| 环节 | 制裁方式 |
|------|---------|
| **石油出口** | 限制伊朗原油买家、运输船队与保险服务，伊朗石油出口一度大幅下滑 |
| **银行结算** | 伊朗央行与主要银行被列入制裁名单，被剔除 [[SWIFT]]，国际结算受阻 |
| **二级制裁** | 对购买伊朗石油、与伊朗有金融往来的第三方实施连带制裁 |
| **军工技术** | 对导弹、无人机相关技术实施出口管制，影响其军工产业 |

## 四、关键数据与案例

- **石油出口重创**：在"极限施压"期间，伊朗石油出口较制裁前大幅下降，但通过折扣价、影子船队与转口贸易部分维持，出口量随制裁松紧波动。
- **银行与结算**：伊朗多次被剔除 SWIFT 国际结算通道，倒逼其发展易货贸易、本币结算与第三方过境支付安排。
- **INSTEX 机制**：为规避美国制裁，欧洲多国建立 INSTEX（贸易互换支持工具）以欧元结算伊欧贸易，是国际社会对抗美元金融制裁的象征性尝试（参见[[伊朗石油欧元计价]]）。
- **地缘对冲**：伊朗多次以威胁封锁[[霍尔木兹海峡]]作为反制筹码，霍尔木兹海峡承载全球大量石油海运，其安全直接牵动油价。
- **制裁-谈判循环**：伊核协议谈判、制裁解除与"重新制裁"多次反复，形成"制裁松紧决定伊朗石油供给"的周期。

## 五、后果与影响

### 5.1 对伊朗

- 石油收入下降、通胀与货币贬值压力上升，民生与经济活动持续承压。
- 被迫发展非美元结算、易货贸易与"抵抗经济"，与中俄的经贸合作加深。

### 5.2 对全球能源与金融

- 伊朗供给的折损与制裁预期成为油价的地缘溢价来源，放大能源市场波动。
- 强化"美元基础设施霸权"叙事，同时反向推动伊朗、俄罗斯等国的**去美元化**实践。

### 5.3 对中东格局

- 美伊长期对抗与"[[抵抗轴心]]"网络（黎巴嫩真主党、[[胡塞武装]]、[[伊拉克亲伊朗武装]]）的互动，构成中东地缘持续紧张的重要来源。
- 制裁与反制裁（伊朗铀浓缩反制、地区冲突升级）形成螺旋，威胁区域与全球稳定。
