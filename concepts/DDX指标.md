# DDX指标

> 基于 Level-2 逐笔成交数据衡量"大单"买卖力量的技术指标 — 观察主力资金动向的量化工具

## 一、定义

**DDX 指标**（大单动向，Large Order Direction），是 A 股 Level-2 行情体系中的资金流向指标，用于衡量**大单净买入（或净卖出）的相对强度**。它基于逐笔成交明细中"大单"的主动买卖方向计算，试图刻画大资金（主力资金）的进出行为，是"主力跟踪"类技术指标的代表。

DDX 属于 DDE 指标族的一员，由通达信等行情软件在国内普及，常与 DDY（涨跌动因）、DDZ（大单差分度）配合使用，参见 [[DDXDDYDDZ-指标]]。

### 1.1 与传统量价指标的区别

| 维度 | 传统量价指标（如成交量） | DDX |
|------|------------------------|-----|
| **数据基础** | 分时/日线成交量 | Level-2 逐笔委托与成交明细 |
| **信号来源** | 总量 | 大单方向（主动买/主动卖） |
| **刻画对象** | 市场全体 | 主力/大资金 |
| **时效性** | 相对滞后 | 相对及时 |
| **数据门槛** | 免费行情即可 | 需付费 Level-2 权限 |

## 二、计算逻辑

### 2.1 基础：DDE 大单差分

DDX 的计算首先需要定义"大单"——各软件口径不同，通常按**单笔成交金额或股数阈值**划分（超过一定规模即计为大单），再统计：

```
大单买入量 − 大单卖出量
─────────────────────  →  DDE（大单差分）
      流通股本
```

DDE 表示**单位流通股本中的大单净流向**，为正值表示大单净流入，负值表示净流出。

### 2.2 DDX 的标准化

DDX 为 DDE 的相对强弱值：

```
DDE 当日值 − DDE 的 N 日均值
──────────────────────────  →  DDX
      DDE 的 N 日标准差
```

即将 DDE 做 N 日窗口的标准化处理，得到**大单净流入强度相对历史水平的偏离程度**。DDX 围绕 0 轴波动，行情软件中以柱状图呈现：

- **DDX > 0**：大单净流入强于历史平均 → 主力资金偏积极
- **DDX < 0**：大单净流出强于历史平均 → 主力资金偏撤退
- **柱长代表强度**：柱体越长，偏离越大

> **注意**：不同软件对"大单"阈值、N 日窗口参数的设定存在差异，DDX 数值**没有绝对含义**。横向对比不同软件结果意义有限，纵向对比同一软件的历史分布更有参考价值。

## 三、使用信号

### 3.1 单一信号

| 信号 | 含义 | 使用注意 |
|------|------|---------|
| **DDX 持续为正** | 大单持续净流入 | 结合价格位置判断是否追高 |
| **DDX 由负转正** | 主力资金转向流入 | 可能对应放量突破或企稳 |
| **DDX 由正转负** | 主力资金流出 | 警惕短线回落 |
| **DDX 显著放大** | 资金异动、分歧加大 | 注意是吸筹还是出货 |

### 3.2 组合使用

- **DDX + 价格形态**：DDX 连续为正且股价放量突破关键位，信号更强；若 DDX 为正但股价滞涨，可能为主力对倒诱多，参见 [[诱多]]。
- **DDX + DDY + DDZ**：三者同向共振时，资金信号可信度更高；出现分歧时以价格走势为准。
- **DDX + 筹码分布**：结合筹码集中度判断主力处于吸筹还是派发阶段。

## 四、应用场景与局限

### 4.1 适用场景

- **短线/事件驱动交易**：捕捉大单资金异动，结合 [[量价关系]] 判断。
- **龙虎榜个股跟踪**：与席位数据相互印证。
- **Level-2 用户的择时辅助**：作为 [[技术分析]] 体系的补充工具。

### 4.2 局限与风险

| 局限 | 说明 |
|------|------|
| **数据噪声** | 逐笔数据可被算法单/拆单扰动，"大单"≠主力意图 |
| **对倒陷阱** | 资金可通过对倒制造"大单净流入"假象，参见 [[诱多]] |
| **无绝对阈值** | DDX 是相对指标，需结合个股流通盘与历史分布 |
| **数据门槛** | 免费行情用户无法直接使用 |
| **不适合长线** | 刻画短期资金行为，与基本面无关 |

> **核心提醒**：DDX 反映的是"大单买卖方向的统计"，并非"主力意图"的直接证据。大资金可以拆分小单隐蔽进出，也可以挂大单诱导跟风。任何资金流向指标都只是**概率性参考**，须与价格、量能、位置综合判断。

---

## 五、小结

DDX 是 A 股 Level-2 生态下"看主力"的代表性指标，核心价值在于把**单向成交量拆分为大单方向**。它丰富了传统量价分析，但存在被操纵的可能，使用时须结合 [[市场微观结构]] 与 [[技术分析]] 体系综合判断，避免陷入"唯资金论"。
