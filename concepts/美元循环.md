# 美元循环

> 美元既是美国的本币，也是全球的"外汇"。美国通过贸易逆差向外输出美元，再通过美债与金融资产让美元回流——这一"输出-回流"循环构成了美元霸权运转的底层机制，也埋下了"特里芬难题"的结构性矛盾。

## 一、定义

**美元循环**（Dollar Circulation）指美元在全球经济中"流出—流转—回流"的闭环体系：美国以贸易逆差、对外投资和援助等方式向外输出美元；世界各国以美元进行贸易结算、持有外汇储备；盈余国再将美元投资于美国国债等美元资产，使美元回流美国，支撑美国的财政赤字与消费。这一循环让美国得以以较低成本获得全球商品与融资，同时让全世界分担美元的信用风险。

## 二、背景与起因

### 2.1 从布雷顿森林到美元本位

- 1944 年布雷顿森林体系确立美元与黄金挂钩、各国货币盯住美元的格局，美元成为国际核心货币。
- 1971 年尼克松冲击宣布美元与黄金脱钩，1973 年固定汇率体系瓦解，美元进入**纯信用货币本位**时代。
- 黄金脱钩后，美元的国际地位不再依赖黄金背书，而依赖全球对其信用与流动性的信任。

### 2.2 循环的支柱

- **贸易结算货币**：大宗商品（尤其石油）以美元计价，进出口贸易大量以美元结算。
- **储备货币**：各国央行持有美元资产作为外汇储备与国际支付准备。
- **安全资产供给**：美国国债市场深度与流动性全球第一，成为美元回流的主要"蓄水池"。

## 三、机制与传导路径

### 3.1 美元的国际循环

```
美国进口商品 → 贸易逆差 → 输出美元
       ↓
出口国获得美元收入（贸易顺差国积累美元）
       ↓
出口国以美元结算国际交易、持有外汇储备
       ↓
出口国购买美债 / 美元资产 → 美元回流美国
       ↓
美国以低成本再融资 → 维持消费与财政赤字
       ↓
循环周而复始（石油美元是其中的核心一环）
```

### 3.2 核心环节

| 环节 | 内容 |
|------|------|
| **贸易输出** | 美国长期贸易逆差使美元流向全球出口国（[[中国]]、[[日本]]、[[德国]]、沙特等） |
| **石油美元** | 石油以美元计价，产油国盈余以美元资产形式回流（参见[[石油美元环流]]） |
| **美债回流** | 外国央行与主权基金将美元储备投资于美国国债与机构债 |
| **离岸市场** | 欧洲美元等离岸市场扩大美元的全球流转规模 |
| **金融循环** | 美元资产（股、债、存款）为全球投资者提供避风港与定价基准 |

## 四、关键数据与案例

- **美国贸易逆差**：美国长期维持货物贸易逆差，是全球美元供给的最大来源，逆差规模随经济周期大幅波动。
- **美元储备占比**：美元在全球官方外汇储备中占主导地位，构成各国金融安全的重要依赖（占比随去美元化进程逐步回落但仍是绝对多数）。
- **美债全球持有**：外国央行与官方机构持有大量美国国债，日本、中国等国为重要持有方，其增减持直接影响美债收益率与美元汇率。
- **特里芬难题**：为向全球供给美元，美国必须持续逆差，但持续逆差又会侵蚀美元信用——这是美元循环无法摆脱的内在矛盾（参见[[特里芬难题]]）。
- **石油美元协议**：1970 年代美沙协议将石油结算绑定美元，为美元循环提供大宗商品锚（参见[[沙特协议]]）。

## 五、后果与影响

### 5.1 对美国的"[[Exorbitant Privilege（过度特权）]]"

- 美国能以本币举债、以逆差换商品，被称作"过度特权"（Exorbitant Privilege），其融资成本显著低于其他国家。
- 美元循环使美国制裁工具（切断美元通道）拥有全球威慑力，构成"美元霸权"的金融基础。

### 5.2 对世界的成本

- 全球承担美元波动与美联储货币政策外溢的风险，"美元是我们的货币，却是你们的问题"。
- 美元周期（加息-回流）反复冲击新兴市场，形成"美元潮汐"。
- 美国国债违约风险与财政纪律问题令各国储备安全性承压。

### 5.3 循环的裂痕与去美元化

- 制裁武器化（如冻结俄罗斯央行储备）削弱各国对美元资产的信任，推动储备多元化、黄金增持与替代支付系统建设。
- 石油美元松动：部分产油国探索以其他货币结算石油交易，本币结算与双边货币互换扩大。
- 美元循环仍在运转，但"裂而不崩"——去美元化是渐进的结构性趋势而非短期事件。
