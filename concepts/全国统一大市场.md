# 全国统一大市场

> "该涨价就得涨价，政府没钱补贴"——公用事业定价机制改革的核心逻辑

## 一、定义

**全国统一大市场**指在中国全国范围内形成**规则统一、竞争公平、要素自由流动、市场充分开放**的一体化市场体系。

其目标是破除**地方保护**和**市场分割**，让市场价格机制和竞争机制充分发挥作用，实现资源的全国性优化配置。建设全国统一大市场是实现 [[高质量发展]]、畅通国内大循环的基础性工程。

---

## 二、政策背景与演进

### 2.1 历史脉络

```
1990s：确立社会主义市场经济体制目标
       ↓
2000s：区域市场初步形成，地方保护仍普遍
       ↓
2022年：《关于加快建设全国统一大市场的意见》出台
       ↓
二十届三中全会：进一步部署市场基础制度与要素市场化改革
```

### 2.2 市场分割的根源

| 根源 | 表现 |
|------|------|
| **地方财税竞争** | 地方政府为税收与政绩设置隐性壁垒 |
| **土地财政依赖** | 以土地和优惠政策招商引资（[[土地财政]]） |
| **户籍与社保分割** | 劳动力跨区域流动受限 |
| **公用事业属地化** | 水、电、气、交通定价各自为政 |

---

## 三、改革机制与内容

### 3.1 市场基础制度规则统一

- 完善**产权制度**，加强商业秘密保护
- 探索**个人破产制度**（深圳已先行试点），完善市场主体退出机制
- 统一市场监管规则，禁止地方性壁垒

### 3.2 公用事业定价机制改革

> "政府减少补贴，让要素价格由市场供求决定"

改革领域：**水价、电价、气价、地铁票价**等公用事业价格。

| 改革前 | 改革后 |
|--------|--------|
| 地方保护、区域分割 | 全国统一规则 |
| 公用事业政府补贴 | 市场定价 + 成本透明 |
| 企业进入门槛不统一 | 产权保护 + 公平竞争 |
| 要素价格扭曲 | 反映真实成本与供求 |

### 3.3 要素市场化配置

- 劳动力：打破户籍壁垒，促进人口自由流动（参见 [[城镇化]]、[[人口结构]]）
- 土地：城乡统一建设用地市场，盘活闲置资源
- 资本：统一资本市场，减少地区间金融资源错配
- 数据与技术：培育数据要素市场，促进科技成果转化

### 3.4 竞争政策基础地位

- 强化竞争政策**基础地位**
- 加强 [[反垄断法]] 执法，公平审查涉企政策
- 破除行政性垄断与地方保护（参见 [[竞争政策]]、[[市场竞争]]）

## 四、关键矛盾与平衡

**"该涨价就得涨价" vs 民生承受能力**：

| 立场 | 逻辑 |
|------|------|
| 涨价方 | 政府无力持续补贴，价格低于成本不可持续（如地铁票价长期亏损） |
| 民生方 | 公用事业涨价直接冲击低收入群体，加重生活负担 |
| 平衡路径 | 渐进式调整 + 针对性补贴 + 成本透明化 |

> 该矛盾的解决依赖财税体制与 [[社会保障]] 的配合：价格市场化同时，对低收入群体实施定向补偿。

---

## 五、影响与评价

### 5.1 积极意义

- 促进要素自由流动，提升整体经济效率（参见 [[资源配置]]）
- 破除地方保护，降低交易成本
- 发挥超大规模市场优势，支撑内需战略
- 为 [[新质生产力]] 提供统一、竞争的市场环境

### 5.2 挑战与风险

| 挑战 | 说明 |
|------|------|
| 地方利益阻力 | 破除保护触动地方财税格局 |
| 公用事业涨价 | 民生压力与舆情风险 |
| 市场失灵 | 部分领域存在 [[市场失灵]]，需政府干预与 [[公共物品]] 供给 |
| 过渡期震荡 | 要素流动加剧区域间竞争与分化 |

### 5.3 与相关改革联动

统一大市场与 [[财税改革]]（破除地方财政激励扭曲）、[[国企改革]]（竞争性环节市场化）、[[社会保障]]（劳动力自由流动的制度配套）构成系统性改革组合。
