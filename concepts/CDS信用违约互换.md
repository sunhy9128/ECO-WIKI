# CDS信用违约互换

> 信用风险的"保险单"——把债券违约风险从一方转移给另一方

## 一、定义

**信用违约互换（Credit Default Swap，CDS）** 是场外交易的**信用衍生品**，买方定期向卖方支付保费（以名义本金的基点计），作为交换，当**参考实体**发生违约、破产、重组等**信用事件**时，卖方须向买方赔付参考债务的损失。其本质是**信用风险的保险**。

CDS 是最常见的信用衍生工具，2008 年金融危机前后在全球快速扩张，成为衡量信用风险与投机交易的核心工具。

### 1.1 交易结构

```
保护买方（风险转移方）
   │  定期支付保费（spread，基点）
   ▼
保护卖方（风险承接方）
   │  信用事件发生时赔偿损失
   ▼
参考实体（公司/主权债务发行方）
```

- **参考实体**：信用风险所指向的债务发行人
- **名义本金**：CDS 合约覆盖的债务金额（保费与赔付均按其计算）
- **保费/利差**：买方支付的年化费率，通常以基点表示，随信用风险变化
- **信用事件**：违约、破产、重组等触发赔付的条款，由 ISDA 主协议标准化定义

---

## 二、CDS 的运作机制

### 2.1 结算方式

| 方式 | 说明 |
|------|------|
| **实物交割** | 买方将参考债券交付卖方，换取名义本金 |
| **现金结算** | 按违约后债券的市场回收价计算差额赔付 |
| **拍卖结算** | 通过行业拍卖确定回收价后现金结算（ISDA 标准做法） |

### 2.2 定价逻辑

- CDS 利差 ≈ **违约概率 ×（1 − 回收率）**，另加风险溢价与流动性溢价
- 利差走阔意味着市场认为违约风险上升，反之则回落
- 利差与参考债券收益率的**信用利差**高度联动，参见 [[信用利差]]

### 2.3 与传统保险的区别

| 维度 | 传统保险 | CDS |
|------|---------|-----|
| **标的** | 实物风险 | 信用风险 |
| **投保人** | 须有保险利益 | 可无持有（裸 CDS） |
| **监管** | 强监管 | 场外、监管较弱 |
| **对手方** | 保险公司 | 任意交易对手 |

## 三、CDS 的用途

### 3.1 [[风险管理]]

- 债券/贷款持有者买入 CDS 对冲违约敞口，相当于"为持仓买保险"
- 银行借此转移信贷风险、释放资本占用，参见 [[资本充足率]]

### 3.2 投机与做空

- 不持有债券的投资者可买入 CDS 押注信用恶化，即[[做空CDS]]
- 也可卖出 CDS 收取保费，押注信用改善（相当于做多信用）

### 3.3 合成头寸

- 用 CDS 合成债券多头/空头，规避现货市场流动性不足的问题
- 曾用于构建合成债务抵押证券（Synthetic CDO），放大信用杠杆

### 3.4 信用定价参考

- CDS 利差被广泛用作市场对违约概率的实时定价参考
- 与评级机构观点形成对照，见 [[信用风险]]

## 四、历史角色

### 4.1 ISDA 与标准化

- ISDA 通过主协议与定义书统一信用事件、结算等条款，推动 CDS 从双边合约走向标准化
- 标准化的同时，场外市场的透明度与对手方风险问题依然突出

### 4.2 2008 年金融危机

- CDS 规模远超对应债券，形成"多倍叠加"的杠杆链条
- 参见 [[AIG]]：作为 CDS 卖方承保巨额次贷风险，危机中无力赔付，暴露 CDS 的**对手方风险**与监管空白
- 参见 [[2008全球金融危机]]：CDS 放大信用危机的传导速度与范围

### 4.3 欧债危机

- 主权 CDS 利差成为衡量欧洲国家信用风险的标尺，参见 [[欧债危机]]、[[希腊]]、[[欧元区]]
- 市场对**裸主权 CDS** 的投机性质展开激烈争论，催生监管收紧

## 五、风险与争议

| 风险 | 说明 |
|------|------|
| **对手方风险** | 卖方违约使保护失效，2008 年危机核心教训之一 |
| **信息不对称** | 场外非标准化合约条款复杂，参见 [[信息不对称]]、[[逆向选择]] |
| **杠杆放大** | 名义规模远超实际债务，风险敞口被成倍放大 |
| **[[道德风险与委托代理]]** | 投机性做空可能加剧恐慌与信用收缩 |
| **[[监管套利]]** | 绕过资本与保证金要求 |

## 六、一句话总结

> **CDS = 把债券违约风险像保险一样买卖**：买方付保费换保护，卖方收保费担风险。它既是信用风险定价的利器，也是 2008 年危机中杠杆与对手方风险的放大器。
