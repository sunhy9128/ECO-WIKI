# 金融危机

> 资产价格、金融机构与支付体系同时剧烈恶化的系统性事件——金融危机是金融体系内在脆弱性的集中爆发，也是宏观政策的重要分水岭。

## 一、概述

**金融危机**指金融体系发生严重紊乱，表现为信贷急剧收缩、资产价格暴跌、金融机构大量倒闭、汇率或主权债务违约等，并显著拖累实体经济的现象。它区别于单一企业的财务危机，核心特征是**系统性**：风险在金融机构之间相互传染，个别环节的违约通过资产负债表链条扩散至整个体系。

金融危机通常被划分为：**货币危机**、**银行危机**、**债务危机**与**系统性危机**（多种危机的叠加），后两者往往相伴发生，被称为"孪生危机"。

## 二、背景

### 2.1 金融体系的固有脆弱性

- **期限错配**：银行"借短放长"，挤兑时流动性瞬间枯竭（见 [[期限错配]]）
- **杠杆累积**：信贷扩张期杠杆率上升，资产价格下跌时被迫去杠杆
- **信息不对称**：借贷双方信息不对称，羊群行为放大波动（见 [[信息不对称]]、[[行为金融学]]）
- **道德风险**：隐性刚兑与"大而不倒"鼓励过度冒险（见 [[道德风险与委托代理]]）

### 2.2 危机的宏观诱因

- 过度宽松的货币政策催生资产泡沫（见 [[泡沫经济]]）
- 国际资本大进大出与汇率错配（见 [[美元潮汐]]、[[三元悖论]]）
- 外部冲击（大宗商品价格、地缘冲突、突发疫情）

### 2.3 明斯基时刻

金融稳定期越长，市场越乐观，杠杆与风险偏好越积越高，最终在某个临界点集中逆转——这一"稳定孕育不稳定"的过程被称为"明斯基时刻"，是理解金融危机周期性爆发的核心框架。

## 三、机制与作用

### 3.1 危机演化的典型链条

```
资产价格泡沫 → 信贷扩张
        ↓
负面冲击（加息/违约/外部事件）
        ↓
资产价格暴跌 → 抵押品贬值
        ↓
去杠杆与抛售（恐慌）
        ↓
银行/机构流动性枯竭 → 挤兑与传染
        ↓
信贷冻结 → 实体经济衰退
```

### 3.2 传染机制

| 渠道 | 说明 |
|------|------|
| 直接敞口 | 机构间同业与衍生品交易违约传导 |
| 资产抛售 | 被迫平仓引发跨资产价格螺旋 |
| 信心传染 | 恐慌从个案蔓延至同类机构与市场 |
| 国际传导 | 资本流出、汇率冲击在新兴市场间扩散（见 [[新兴市场危机]]） |

### 3.3 政策应对的"最后贷款人"

危机中，中央银行承担[[最后贷款人]]职能，通过注入流动性、降息、购买资产（[[量化宽松]]）稳定体系；财政部与存款保险机构则处理处置与救助（见 [[存款保险]]）。

## 四、关键事件与数据

### 4.1 1997 亚洲金融危机

泰铢放弃盯住美元引发区域货币连锁贬值，印尼、韩国等相继爆发危机，暴露"固定汇率 + 高外债 + 资本自由流动"的组合风险（见 [[1997亚洲金融危机]]、[[1997亚洲金融危机]]、[[1998香港金融保卫战]]）。

### 4.2 1998 俄罗斯与 LTCM

俄罗斯卢布危机与违约引发全球避险，长期资本管理公司（LTCM）巨额杠杆头寸濒临崩溃，倒逼美联储组织救助（见 [[1998 俄罗斯卢布危机]]、[[长期资本管理公司]]、[[1998年LTCM危机]]）。

### 4.3 2008 全球金融危机

美国次贷违约引发全球系统性危机，雷曼兄弟倒闭冲击全球，危机从"次贷"扩散为"全球金融海啸"（见 [[2008全球金融危机]]、[[2008全球金融危机]]、[[2008全球金融危机]]、[[雷曼兄弟]]）。

### 4.4 2020 年 3 月流动性危机

疫情冲击下全球风险资产暴跌、美元流动性骤紧，"现金为王"引发美元抢购与全球美元荒（见 [[2020年3月流动性危机]]、[[全球流动性危机]]、[[美元流动性]]）。

### 4.5 区域与债务型危机

欧债危机（见 [[欧债危机]]、[[欧债危机]]）、1982 年拉美债务危机、2018—2019 年土耳其阿根廷货币危机等，构成危机谱系中的"债务"与"货币"分支。

## 五、影响

### 5.1 实体经济

- 信贷收缩导致投资与消费骤降，产出大幅回落，失业上升
- 危机后往往伴随"资产负债表衰退"（见 [[资产负债表衰退]]）
- 财政成本：救市与债务重组推升政府债务（见 [[财政政策与货币政策协同]]）

### 5.2 金融监管

危机推动监管范式转向：更严格的资本充足率（[[巴塞尔协议III]]）、宏观审慎框架、压力测试与"大而不能倒"处置机制成为标配。

### 5.3 货币政策

危机改变央行操作模式：从"预设规则"转向"危机应对"，量化宽松、[[前瞻指引]]、紧急流动性工具成为常态化工具。

### 5.4 国际货币与金融格局

危机暴露单一货币体系的风险，推动储备货币多元化、区域货币合作与[[金融安全]]议题升温（见 [[去美元化]]、[[人民币国际化]]）。
