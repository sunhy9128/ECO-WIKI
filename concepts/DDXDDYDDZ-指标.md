# DDXDDYDDZ-指标

> A 股 Level-2 数据中的"主力资金"三件套 — DDX 看大单方向、DDY 看涨跌动因、DDZ 看承接力度

## 一、总览

**DDX/DDY/DDZ** 是 A 股 Level-2（逐笔成交）行情生态下的一组资金流向指标，由通达信等行情软件推广普及。三者共享同一套"大单差分"数据基础，但从不同角度刻画主力资金行为：

| 指标 | 全称 | 核心视角 | 一句话理解 |
|------|------|---------|-----------|
| **DDX** | 大单动向 | 大单净流向强度 | 大资金在买还是在卖 |
| **DDY** | 涨跌动因 | 委托单主动性的贡献 | 谁的委托单推动了价格 |
| **DDZ** | 大单差分度 | 大单占比的离散程度 | 主力承接力强不强 |

三者合称"DDE 指标族"，详细计算基础见 [[DDX指标]]。

---

## 二、DDX — 大单动向

DDX 衡量**大单净买入相对历史水平的强弱**，围绕 0 轴波动，正值为大单净流入、负值为净流出。它是三指标中最常用、也最容易被误读的一个：

- **优势**：直观反映大单方向，信号简单。
- **陷阱**：大单可通过对倒制造，DDX 为正不代表主力真在吸筹，参见 [[诱多]]。

## 三、DDY — 涨跌动因

**DDY**（涨跌动因）基于**委托单的主动性**计算。逐笔行情中，成交可分为主动买（吃卖一价）与主动卖（砸买一价），DDY 统计"主动买入的单数贡献 − 主动卖出的单数贡献"，衡量**委托单方向对价格上涨的贡献程度**：

- **DDY 为正**：主动买盘占优，价格上行有量能支撑。
- **DDY 为负**：主动卖盘占优，抛压较重。
- **与 DDX 的关系**：DDX 看"大单净额"，DDY 看"委托单主动性"。两者同向时资金逻辑一致；背离时（如 DDX 正、DDY 负）说明大单买入但整体委托盘在撤离，需警惕。

## 四、DDZ — 大单差分度

**DDZ**（大单差分度）衡量**大单成交在总成交中的占比及其离散程度**，用于评估主力资金的"承接力"与集中度：

- **DDZ 高**：大单占比高、成交集中，说明主力参与度高、承接有力。
- **DDZ 低**：大单占比低、成交分散，说明以中小单为主、缺乏主力主导。
- **用途**：常用来筛选"主力高度控盘"的个股，配合 DDX/DDY 判断大单行为的持续性。

---

## 五、三者组合使用的框架

```
DDX 判定方向（大单净流入/流出）
       ↓
DDY 验证质量（主动性委托是否配合）
       ↓
DDZ 衡量强度（主力承接力与集中度）
       ↓
结合价格形态与量能 → 综合决策
```

| 组合情景 | 典型解读 |
|---------|---------|
| DDX↑ + DDY↑ + DDZ↑ | 主力真金白银流入，信号最强 |
| DDX↑ + DDY↓ | 大单买入但主动性不足，可能对倒 |
| DDX↓ + DDY↓ + DDZ↓ | 资金撤离，抛压明确 |
| 三者背离 | 以价格走势为准，指标仅为参考 |

## 六、局限与注意

| 局限 | 说明 |
|------|------|
| **数据口径不一** | 各软件"大单"阈值、算法不同，数值不可跨软件对比 |
| **可被操纵** | 对倒、拆分、算法单均可扭曲大单统计 |
| **短期属性** | 刻画日内/短期资金行为，与中长期价值无关 |
| **样本失真** | 流通盘极小或流动性差的个股，大单占比天然失真 |
| **滞后性** | 资金流入不等于股价立即上涨，存在时滞 |

> **核心提醒**：DDX/DDY/DDZ 是"资金行为统计"，不是"主力意图说明书"。它们可以作为短线选股与择时的辅助，但必须在 [[量价关系]] 和 [[技术分析]] 的整体框架下使用，并结合基本面排除噪音。
