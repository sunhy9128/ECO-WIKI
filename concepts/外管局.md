# 外管局

> 外管局是中国的"外汇管家"：管外汇储备、管跨境资金流动、管汇率形成机制。它与央行联手维护人民币汇率稳定与金融安全，是中国外汇管理体系的执行中枢。

## 一、定义

**外管局**（国家外汇管理局，State Administration of Foreign Exchange, SAFE）是国务院直属的副部级机构，负责中国外汇管理政策的制定与执行。其核心职能包括：经营管理国家外汇储备、管理经常项目与资本项目下的外汇收支、监测跨境资金流动、维护国际收支平衡与人民币汇率合理稳定。

## 二、背景与机构沿革

### 2.1 成立背景

- 1978 年改革开放后，外汇成为稀缺战略资源，需要专门机构统一管理。
- 1979 年国务院批准设立国家外汇管理总局，1982 年改为国家外汇管理局，与中国人民银行关系密切，实际作为央行内设机构运作。
- 1994 年汇率并轨与结售汇制度改革，外管局职能进一步强化。

### 2.2 机构定位

- 外管局是央行体系的重要组成部分，局长通常由央行系统官员出任（如潘功胜曾任外管局局长）。
- 其决策与表态直接牵动人民币汇率、外汇储备规模与跨境资本流动预期，是市场高度关注的政策信号源。

## 三、核心职能与机制

### 3.1 主要职责

| 职能 | 内容 |
|------|------|
| **外汇储备管理** | 经营与保值增值国家外汇储备，坚持安全性、流动性、收益性原则 |
| **国际收支统计** | 编制国际收支平衡表，监测经常账户与资本账户变动 |
| **经常项目管理** | 贸易、服务、收益等经常项下外汇收支的真实性审核 |
| **资本项目管理** | 对外投资、外债、证券投资的审批、登记与额度管理 |
| **外汇市场监管** | 监管银行间外汇市场，管理结售汇业务 |
| **跨境资金监测** | 对跨境资金流动实施宏观审慎管理与风险预警 |

### 3.2 传导路径

```
国际收支与跨境资金流动监测
       ↓
外汇储备运用 + 汇率中间价管理
       ↓
外汇市场干预（必要时）
       ↓
经常/资本项目政策调整（额度、登记、审慎工具）
       ↓
汇率稳定与金融安全
```

## 四、关键数据与案例

- **外汇储备规模**：中国外汇储备长期位居全球第一，是应对汇率波动与资本外流的核心安全垫；外管局负责其日常经营与结构优化（参见[[外汇储备]]）。
- **8.11 汇改**：2015 年汇改后资本外流压力加大，外管局加强真实性审核与跨境资金宏观审慎管理，与央行协同维护汇率稳定（参见[[8.11 汇改]]）。
- **离岸人民币管理**：外管局与央行通过收紧离岸人民币流动性、规范跨境套利等方式，平抑在岸-离岸价差与贬值预期（参见[[离岸人民币]]）。
- **跨境资金登记**：对外投资、跨境融资等业务实施登记与额度管理，形成资本项目开放的"闸门"（参见[[跨境资金登记]]）。
- **官员表态信号**：历任外管局领导（如易纲、潘功胜）对汇率与资本流动的公开表态，常被市场解读为政策取向信号。

## 五、后果与影响

### 5.1 对汇率与资本流动

- 外管局通过储备运用、市场干预与政策工具，抑制汇率超调与资本大进大出，为货币政策独立性争取空间。
- 其"稳汇率、稳预期、稳外资"的政策基调，影响人民币资产的国际配置意愿。

### 5.2 对市场效率

- 真实性审核与额度管理带来合规成本，部分削弱市场自由化程度，也构成"非市场化力量"的一部分（参见[[汇率非市场化]]）。
- 在开放与管控之间，外管局持续扮演"渐进改革"的执行者角色，服务于人民币国际化的长期战略。

### 5.3 对人民币国际化

- 外汇管理的松紧直接影响离岸人民币供给与跨境结算便利度，是人民币国际化进程中的关键政策变量（参见[[人民币国际化]]）。
