# 回购注销

> 用公司现金回购自家股票并注销 — 直接增厚每股收益、向股东"还钱"的资本运作方式

## 一、定义

**回购注销**指上市公司用自有资金**从市场回购本公司股份并予以注销（减少注册资本）**的资本运作。与"回购但不注销"（回购后用于员工持股、股权激励或库存股）不同，**注销意味着总股本减少**，在利润不变的情况下直接**增厚每股收益（EPS）**。

回购注销是成熟市场常见的股东回报手段，被视为"用现金回报股东"的替代形式——与现金分红并列为两种主要的利润分配方式，参见 [[股息与分红]] 与 [[股份回购与注销]]。

---

## 二、运作机制

### 2.1 基本流程

```
公司现金充裕 → 发布回购计划
       ↓
在二级市场回购股份（或要约回购）
       ↓
回购股份注销 → 总股本减少
       ↓
EPS 增厚 + 每股净资产提升
```

### 2.2 为什么注销能提升价值

| 指标 | 回购前 | 回购注销后 |
|------|--------|-----------|
| **总股本** | N | N − 注销数 |
| **净利润** | E（不变） | E（不变） |
| **EPS** | E/N | E/(N−注销数) ↑ |
| **每股净资产** | BV/N | BV/(N−注销数) ↑ |
| **股息率（按股计）** | 不变 | 每股分红能力相对提升 |

在盈利不变时，股本缩小直接抬升每股指标；若股票以低于内在价值回购，则"注销"相当于**以低于价值的价格为留存股东增厚权益**。

## 三、回购注销 vs 其他回报方式

| 维度 | 现金分红 | 回购注销 | 回购不注销 |
|------|---------|---------|-----------|
| **股东获得** | 现金 | 股本缩减、EPS 增厚 | 股份保留（激励/库存） |
| **EPS 影响** | 无 | 直接增厚 | 无 |
| **税务（A股）** | 分红需考虑个税 | 无直接个税 | 无 |
| **信号意义** | 现金流稳定 | 管理层认为股价低估 | 主要为股权激励 |
| **灵活性** | 一次性 | 一次性注销 | 可后续处置 |

- 分红给股东"现金"，回购注销给股东"更值钱的股权"。
- 回购不注销（如用于激励）对存量股东 EPS 无增厚，参见 [[股份回购与注销]] 的区分。
- A 股历史上存在"重分红轻回购"的偏好，近年政策引导下回购注销渐受鼓励，参见 [[重分红轻回购]]。

## 四、回购注销的信号意义

### 4.1 向市场传递的信号

- **低估信号**：管理层以真金白银回购，通常暗示认为股价被低估。
- **现金流信号**：能回购注销的公司，现金流充裕、盈利质量较好。
- **治理信号**：愿意"还钱给股东"，降低代理成本，见 [[积极股东]]。
- **防御信号**：回购可对冲恶意收购或支撑股价，参见 [[恶意收购]] 与 [[赎罪性质回购]]。

### 4.2 A 股语境下的关注点

- **回购力度与执行力**：计划规模、实际完成比例比公告本身更重要。
- **回购资金来源**：自有资金 vs 借款回购，质量不同。
- **注销比例**：全部注销 vs 部分注销（留存用于激励）对 EPS 影响不同。
- **回购时机**：低位回购注销的"性价比"更高。

## 五、局限与风险

| 局限 | 说明 |
|------|------|
| **一次性效应** | 注销一次性增厚 EPS，不改变盈利能力 |
| **资金消耗** | 消耗现金，可能削弱研发与扩张投入 |
| **"护盘"性质** | 部分回购是股价维稳而非价值判断，参见 [[赎罪性质回购]] |
| **择时风险** | 高位回购注销等于"高价买回股份"，损害股东利益 |
| **执行不确定** | 计划与实际完成之间可能存在落差 |

> **核心提醒**：回购注销是"结果友好"的信号，但需穿透看**动机、价格与执行力**。只有"以合理价格、真正注销、现金来源健康"的回购注销，才对股东价值有实质增厚；以护盘或作秀为目的的回购，其价值含量大打折扣。

---

## 六、小结

**回购注销**是上市公司用现金缩减股本、增厚每股收益的资本运作，被视为"变相分红"与低估信号。它对 EPS 与每股净资产的提升是"数学上确定"的，但对股东价值的实质贡献取决于**回购价格是否低于内在价值**与**动机是否真实**。作为投资者，应把回购注销放在公司金融、股东回报与 [[回购市场]] 的整体框架中评估。
