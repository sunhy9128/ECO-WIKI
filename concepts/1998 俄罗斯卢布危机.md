# 1998 俄罗斯卢布危机

> 大国主权违约 + 汇率崩盘，让华尔街对冲基金集体颤抖

## 一、定义

**1998 年俄罗斯卢布危机**指 1998 年 8 月 17 日俄罗斯政府在**短期国债（GKO）上违约**、宣布卢布贬值的金融危机。俄罗斯成为近代少有的**对本国货币计价债务违约**的主权国家。

危机的独特之处在于其**全球传染力**：俄罗斯经济体量不大，却因大量西方对冲基金持有其高息国债，违约直接重创长期资本管理公司（LTCM）等机构，迫使美联储协调救援，引发全球金融市场动荡。

---

## 二、历史背景与起因

### 2.1 转型期的经济脆弱

| 背景 | 说明 |
|------|------|
| **苏联解体后的转型** | 1990 年代俄罗斯经历[[休克疗法]]与[[俄罗斯转型]]，经济持续收缩 |
| **财政赤字巨大** | 税基薄弱、征管不力，财政长期赤字 |
| **税收"以物易物"** | 预算收入不足，政府靠发债与借外债维持 |
| **短期国债扩张** | 以高利率发行 GKO 短期国债，期限短、依赖滚动 |
| **外债结构** | 借入美元外债 + 发行卢布国债，双重压力 |

### 2.2 触发因素

- **亚洲金融危机蔓延（1997-1998）**：东亚货币危机削弱了全球对新兴市场的风险偏好
- **大宗商品价格暴跌**：石油、有色金属等出口价格走低，创汇能力下降
- **资本外逃**：外资撤出新兴市场，俄罗斯外储快速消耗
- **利率飙升**：为维持卢布汇率，央行把利率推至极高水平，财政付息成本失控

```
财政赤字 + 短期国债滚动依赖
       ↓
亚洲危机 → 新兴市场风险偏好下降
       ↓
资本外逃 + 外储消耗
       ↓
央行高利率护汇率 → 付息成本失控
       ↓
1998.8.17 违约 + 卢布贬值
```

## 三、机制与传导路径

### 3.1 危机机制

| 环节 | 内容 |
|------|------|
| **财政-汇率矛盾** | 高利率护汇率 → 债务利息滚雪球 → 财政不可持续 |
| **违约决定** | 政府选择对内违约（GKO）并暂停偿还部分外债 |
| **卢布贬值** | 央行放弃干预，卢布大幅贬值 |
| **国内银行崩溃** | 银行持有大量 GKO 与外汇负债，资产端违约、负债端美元化 |
| **通胀反弹** | 贬值推高进口品价格，通胀率一度大幅回升 |
| **政治动荡** | 政府更迭，政治不确定性加剧 |

### 3.2 对全球的传染（LTCM 危机）

大量西方机构在"利差交易"中做多俄罗斯高息国债、同时做空其它资产；违约与贬值使此类头寸**同时巨亏**，多空两端受损。长期资本管理公司（LTCM）因高杠杆与头寸集中，濒临倒闭。

```
LTCM 高杠杆 + 高度集中的套利头寸
       ↓
俄罗斯违约冲击其多空两端头寸
       ↓
亏损超出资本金、保证金连环追缴
       ↓
银行与对手方风险暴露
       ↓
1998.9 美联储协调救助、紧急降息
```

## 四、关键数据与案例

> 说明：以下为历史事实的概括性表述，精确值存在多种口径。

| 阶段 | 事件 |
|------|------|
| **1997.11** | 亚洲危机冲击下卢布承压，央行干预 |
| **1998 上半年** | 外储持续消耗，利率居高不下 |
| **1998.8.17** | 政府宣布违约与卢布贬值，暂停部分外债偿还 |
| **1998.8-9** | 卢布进一步贬值、银行体系瘫痪 |
| **1998.9** | 美联储组织救助 LTCM，紧急降息稳定市场 |

### 4.1 救助与退出

- 违约后俄罗斯停止大规模干预，转向浮动汇率
- 2000 年代初油价上涨 + 财政纪律修复，俄罗斯经济复苏并重建外储
- 危机的"违约换轻装"经验被日后其它国家作为参照

---

## 五、后果与教训

### 5.1 直接后果

- **主权违约**：对内违约 + 部分外债暂停，主权信用受损
- **银行体系崩溃**：银行大面积倒闭或资不抵债
- **通胀飙升**：卢布贬值引发输入型通胀
- **全球经济震荡**：LTCM 危机暴露高杠杆对冲基金的尾部风险
- **美联储危机管理**：紧急降息与私人部门协调救助成为样本

### 5.2 关键教训

| 教训 | 内容 |
|------|------|
| **短期债务依赖是死穴** | 短债滚动 + 汇率承诺 = 最危险的组合 |
| **财政与汇率政策要一致** | 高利率护汇率必须以财政可持续为前提 |
| **本币违约是主权"底气"** | 发行本币债违约可转嫁成本，但也摧毁信誉 |
| **杠杆与传染** | 高杠杆机构放大了小国违约的全球影响 |
| **外储与油价** | 资源型经济体的脆弱性取决于外储缓冲与大宗商品价格 |
