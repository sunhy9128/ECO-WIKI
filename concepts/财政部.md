# 财政部

> 管钱、发债、定税负 — 财政部是宏观财政政策的核心执行部门，也是连接政府预算与金融市场的关键枢纽

## 一、定义

**财政部**（Ministry of Finance，本库相关实体条目见 [[中华人民共和国财政部]]）是国家主管财政收支、政府预算、税收政策、公共债务与财政监督的政府部门。在中国体制下，财政部是[[国务院]]的组成部门，承担"国家账本"的编制与管理职能。

### 1.1 核心职能

| 职能 | 内容 |
|------|------|
| **预算管理** | 编制中央与地方预算草案，组织预算执行与决算 |
| **税收政策** | 拟订税种税率方案，参与[[财税改革]] |
| **国债管理** | 国债发行、偿还与余额管理 |
| **转移支付** | 中央对地方财政转移支付制度（参见 [[转移支付]]） |
| **财政监督** | 监督财政资金使用，防范财政风险 |

## 二、背景

### 2.1 财政体制的演进

从计划经济时期的"统收统支"，到 1994 年[[分税制]]改革确立中央与地方财政分配关系，再到近年预算管理制度改革与地方债务治理，财政部始终处于制度变迁的核心位置。分税制改变了中央与地方的财权事权格局，也塑造了[[土地财政]]与地方融资体制的运行环境。

### 2.2 财政政策角色的强化

在宏观经济调控中，财政政策与货币政策并列为两大支柱（参见 [[财政政策与货币政策协同]]）。财政部的支出安排、减税降费与债务融资决策，直接影响总需求与[[财政政策乘数]]的发挥。

## 三、机制与作用

### 3.1 财政政策工具

| 工具 | 机制 |
|------|------|
| **支出** | 政府购买、投资与转移支付直接注入需求 |
| **税收** | 调整税率与税基影响企业与居民可支配收入 |
| **国债** | 融资支持赤字与重点项目（参见 [[国债缓冲机制]]） |
| **特别国债** | 特定用途的专项融资工具 |

### 3.2 与央行的关系

- **分工**：财政部管财政收支与债务融资，央行管货币供给与利率（参见 [[中国人民银行]]、[[中央银行]]）
- **配合**：国债发行需要央行流动性环境配合，财政政策扩张也影响货币条件
- **红线**：多数国家法律禁止央行直接为政府赤字融资，即避免[[财政货币化]]；财政与货币保持相对独立是制度常态

### 3.3 在化债中的角色

中国地方债务治理中，财政部主导发行特殊再融资债券、推动债务置换与化解（参见 [[化债]]、[[地方政府隐性债务]]）。财政纪律约束与债务风险化解构成其双重任务。

## 四、关键事件与数据（概括性）

- 1994 年分税制改革确立现行中央地方财政关系
- 历年积极财政政策中，中央财政通过增发国债、专项债与减税降费稳增长
- 地方债务风险处置中，财政部牵头"一揽子化债方案"，发行特殊再融资债券置换存量隐性债务
- 预算管理改革持续深化，全面实施绩效管理、推进"开正门、堵偏门"的地方举债新机制

## 五、影响

### 5.1 对宏观经济

- 财政扩张力度决定稳增长的强度与可持续性
- 减税降费影响企业投资与居民消费（参见 [[财政政策乘数]]）
- 赤字与债务规模影响宏观杠杆与市场对财政空间的预期

### 5.2 对金融市场

- 国债发行节奏与供给影响[[国债收益率曲线]]与债市定价
- 财政存款（国库现金）变动影响银行间流动性
- 化债政策的发行安排直接作用于[[信用利差]]与城投估值

### 5.3 对地方政府

- 转移支付制度平衡区域财力差距
- 债务限额与"开前门、堵后门"约束地方举债行为
- 绩效管理倒逼财政资金提质增效
