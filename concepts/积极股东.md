# 积极股东

> 从"用脚投票"到"用手投票"——股东直接介入公司治理，推动价值创造

## 一、定义

**积极股东（Active Ownership / Active Shareholder）** 指股东通过**行使投票权、参与公司治理、与管理层对话、提交股东提案**等方式，主动影响被投企业的战略、运营与治理结构的做法。

传统上股东可选择"用脚投票"（卖出离场），而积极股东选择"用手投票"——留下来并施加影响。[[concepts/主权财富基金|主权财富基金]]、养老基金与被动指数基金等大型机构投资者日益重视这一策略，将其作为长期价值管理与受托责任的重要工具。

### 1.1 与消极股东对比

| 维度 | 消极股东 | 积极股东 |
|------|---------|---------|
| **参与方式** | 买入持有、卖出离场 | 投票、对话、提案 |
| **与管理层关系** | 疏离 | 主动介入 |
| **影响力** | 弱 | 强 |
| **典型主体** | 散户、部分基金 | 机构、主权基金、激进投资者 |

---

## 二、积极股东的实现方式

### 2.1 参与工具

| 方式 | 说明 |
|------|------|
| **代理投票** | 在股东大会上就议案行使表决权 |
| **管理层对话** | 与管理层就战略、风险、薪酬直接沟通 |
| **股东提案** | 提交治理、ESG 相关议案列入议程 |
| **公开施压** | 通过媒体、信函影响舆论与管理层 |
| **代理权之争** | 争取董事会席位、罢免管理层（激进形态） |

### 2.2 关注议题

- 董事会构成与独立性、管理层薪酬合理性
- 资本配置（分红、回购、并购）与股东回报
- [[风险管理]]、ESG 议题（气候、性别、供应链），参见 [[ESG 投资]]
- 财务透明度与信息披露质量

### 2.3 与[[concepts/被动投资|被动投资]]的互补

- 被动基金"无法卖出"，更倾向以积极治理改善持仓价值，形成"被动投资 + 主动治理"组合
- 参见 [[被动投资]]：低成本跟踪指数的同时，通过投票权影响被投公司

## 三、典型实践主体

### 3.1 主权财富基金

- 参见 [[挪威主权基金]]：明确制定投票政策，参与全球数千家公司的治理议题，在气候变化、董事独立性上长期施压
- 参见 [[GIC]]、[[主权财富基金]]：以长期利益相关者身份参与被投企业治理

### 3.2 机构与激进投资者

- 养老基金、资产管理公司通过代理投票行使受托责任
- 激进投资者（如部分对冲基金）则以更进攻性的方式推动重组、分拆或换帅
- 参见 [[安邦]]、[[万科]]：境内资本举牌与股东博弈的典型案例

---

## 四、作用与批评

### 4.1 积极作用

- 提升公司治理水平，抑制大股东侵占与代理成本，参见 [[信息不对称]]、[[逆向选择]]
- 改善资本配置效率，推动股东回报
- 补充监管难以覆盖的治理短板

### 4.2 争议与局限

| 批评 | 说明 |
|------|------|
| **短期主义** | 激进股东可能为短期股价牺牲长期投资 |
| **越界干预** | 外行股东过度介入经营细节 |
| **利益冲突** | 投票权与其他业务关系存在潜在利益冲突 |
| **效果不均衡** | 治理改善对公司价值的传导因企业而异 |

---

## 五、应用场景

| 场景 | 说明 |
|------|------|
| **长期资金管理** | 主权基金、养老金以积极治理维护长期价值 |
| **[[估值修复]]** | 推动回购、分红，治理折价收窄（参见 [[韩国折价（Korea Discount）]]） |
| **风险监督** | 通过治理监督防范重大风险与丑闻 |

## 六、一句话总结

> **积极股东 = 股东以投票、对话、提案等方式主动参与公司治理**，与被动投资的低成本持有互为补充，是机构投资者行使受托责任、推动治理溢价的核心手段。
