# 做空CDS

> 不持有债券也能"买保险"——用 CDS 合约押注一家公司或一个国家信用恶化

## 一、定义

**做空 CDS** 指投资者**购买信用违约互换（CDS）合约、押注参考实体的信用质量将恶化**的交易行为。CDS 本质上是一份信用保护合约：买方定期支付保费（以基点计），若参考实体发生违约等信用事件，卖方须赔偿买方损失。

从经济效果看，购买 CDS 等于**做空参考实体的信用**——参考实体信用恶化、CDS 利差走阔时，保护买方持有的合约价值上升，可平仓获利。这与直接做空股票或债券不同：做空 CDS 不需要借入任何标的资产，只需买入保护合约。

### 1.1 与做空股票的区别

| 维度 | 做空股票 | 做空 CDS |
|------|---------|---------|
| **标的** | 公司股票 | 公司/主权信用 |
| **工具** | 融券卖出 | 买入 CDS 保护 |
| **借券** | 需要借券 | 不需要借券 |
| **关键变量** | 股价 | [[concepts/信用利差|信用利差]] |
| **触发点** | 无明确事件 | 信用事件（违约等） |

## 二、做空 CDS 的运作机制

### 2.1 两种情形

- **保护性购买（[[套期保值]]）**：持有债券的投资者买入 CDS 对冲违约风险，属于风险对冲而非投机做空
- **裸 CDS 做空（Naked CDS）**：不持有任何相关债券、纯粹押注信用恶化的投机行为，是"做空 CDS"的核心形态

### 2.2 盈利逻辑

```
参考实体信用恶化（评级下调/违约/重组）
       ↓
CDS 利差走阔（保费上升）
       ↓
保护买方所持合约市值上升
       ↓
卖出合约平仓 / 触发信用事件获赔
       ↓
赚取利差收益
```

### 2.3 定价基础

- CDS 价格以**信用利差**（基点，bp）表示，反映市场对违约概率的定价
- 利差 = 违约概率 ×（1 − 回收率）的近似函数，参见 [[CDS信用违约互换]]
- 做空 CDS 的成本是持续支付的保费，类似做空的"借券费 + 利息"

## 三、典型场景

### 3.1 [[concepts/2008全球金融危机|2008 年金融危机]]中的角色

- 金融机构大量买入 CDS 做空次级抵押贷款相关证券
- 参见 [[AIG]]：AIG 作为 CDS 卖方承保了巨额次级债风险，危机爆发后无力赔付，成为[[entities/系统性风险|系统性风险]]爆发的标志性事件；参见 [[2008全球金融危机]]
- CDS 市场的信息不对称与杠杆放大了金融体系的脆弱性

### 3.2 欧债危机

- 2010-2012 年，投资者通过做空 CDS 押注希腊等主权国家信用恶化，参见 [[欧债危机]]、[[希腊]]
- 主权 CDS 利差成为市场恐慌的风向标，与国债收益率形成联动
- 因担心投机性做空放大危机，欧盟一度讨论并限制**裸主权 CDS**

### 3.3 做空 CDS 的合法性与争议

| 观点 | 内容 |
|------|------|
| **支持** | 增加市场流动性，提供信用风险的定价与对冲工具 |
| **反对** | 裸 CDS 相当于"对没有保险利益的标的投保"，可能助长投机、放大危机 |
| **监管** | 部分司法辖区限制裸主权 CDS，要求证明持有可保利益 |

## 四、做空 CDS 的风险与局限

- **保费持续损耗**：信用未恶化期间，保护买方持续支付保费
- **尾部风险**：信用事件一旦发生，利差可能暴涨，反之做空方向若错误则亏损有限（仅保费）
- **对手方风险**：CDS 是场外合约，卖方违约时保护失去意义，参见 [[信用风险]]
- **流动性**：冷门参考实体的 CDS 流动性差，平仓困难

## 五、一句话总结

> **做空 CDS = 买入信用保护、押注信用恶化**，是无需借券即可做空信用的衍生工具，在 2008 年危机与欧债危机中扮演关键角色，也因其"无保险利益投保"特性而备受争议。
