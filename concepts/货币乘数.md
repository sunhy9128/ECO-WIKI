# 货币乘数

> 央行投放 1 元基础货币，最终能变成多少广义货币？——乘数效应是理解银行信用创造的关键概念。

## 一、定义与概述

**货币乘数**（Money Multiplier）指**基础货币**（流通现金 + 银行准备金）通过商业银行的存款创造功能被放大的倍数，即：

```
货币乘数 = 广义货币（M2）/ 基础货币（M0 + 准备金）
```

它刻画了银行体系"吸收存款 → 发放贷款 → 派生存款"的连锁过程（见 [[部分准备金制度]] 与 [[货币创造]]）。基础货币由央行供给，而广义货币由银行体系内生创造，乘数正是连接二者的桥梁。

## 二、存款创造过程

以最简单情形说明：设法定[[concepts/存款准备金率|存款准备金率]]为 10%。

```
央行投放 100 元基础货币给 A 银行
       ↓
A 银行保留 10 元准备金，放贷 90 元
       ↓
90 元流入借款人账户（存款派生），B 银行保留 9 元，放贷 81 元
       ↓
……依次类推
       ↓
存款总额 = 100 + 90 + 81 + … = 100 / 0.1 = 1000 元
```

最终存款总额为初始基础货币的 1/准备金率倍，即货币乘数 = 1 / r。现实中，现金漏损、[[entities/超额准备金|超额准备金]]等因素使乘数小于理论值。

## 三、货币乘数的公式与影响因素

### 3.1 一般公式

设 **r** 为存款准备金率、**c** 为现金漏损率（公众持有现金占存款之比）、**e** 为超额准备金率：

```
货币乘数 m = (1 + c) / (r + e + c)
```

- 分子 (1+c)：现金也是货币的一部分，需计入供给。
- 分母三项分别反映银行准备金约束、银行惜贷（超储）与公众现金偏好。

### 3.2 影响因素

| 因素 | 变动方向 | 对乘数影响 |
|------|---------|-----------|
| 法定存款准备金率 r | ↑ | ↓（收缩信用创造能力） |
| 现金漏损率 c | ↑ | ↓（资金流出银行体系） |
| 超额准备金率 e | ↑ | ↓（银行不愿放贷） |
| 存款利率 / 贷款需求 | ↑ | ↑（刺激贷款派生） |

值得强调的是：**准备金率只是约束之一**。银行的放贷意愿（取决于[[entities/资本充足率|资本充足率]]、风险偏好、贷款需求）同样决定实际乘数——这正是"货币乘数不是常数，而是随经济周期变动"的原因。

## 四、关键事件与数据

- **[[中国]] 2000-2010 年代**：伴随外汇占款激增，央行连续上调法定准备金率，主动压低货币乘数，以对冲基础货币被动扩张（见 [[央行对冲工具]]、[[外汇占款]]）。
- **2014 年以来**：中国经济进入"宽货币、稳信用"阶段，降准空间打开，但货币乘数上升的同时信贷需求偏弱，"宽信用"效果取决于实体需求而非单纯的准备金放松。
- **美国金融危机后**：银行大量囤积超额准备金，货币乘数从危机前的约 9 大幅降至 3-4，说明在 [[资产负债表衰退]] 与风险厌恶环境下，即使央行扩表，信用创造也可能"淤积"在准备金账户（见 [[超额准备金]]、[[扩表与缩表]]）。

## 五、货币乘数 vs 货币层级

现代货币理论视角下，货币并非"央行创造后由银行机械放大"，而是银行在满足资本与流动性约束的前提下内生创造。因此：

- 乘数框架适合描述**准备金约束主导**的经济体（如传统银行体系）。
- 在资本充足率与流动性监管主导的时代，**银行资本与借款人的偿债能力**才是信用扩张的硬约束，"乘数"更多是一个描述性而非预言性概念。

相关概念参见 [[货币层级]]、[[货币信用]] 与 [[现代货币理论 (MMT)]]。

## 六、影响与评价

- **政策意义**：央行无法精确控制货币乘数，只能通过准备金率、利率与监管约束间接影响——因此"降准创造多少货币"的估算应保持谨慎。
- **局限与争议**：乘数理论假设贷款必须由准备金支持且银行被动放贷；现实中银行主动创造存款、央行被动"追踪"准备金，使传统乘数模型的解释力下降。学术界已更多使用"内生货币"视角。
- **对投资者的启示**：观察货币乘数与 M2 增速，有助于判断信用周期位置，从而把握资产配置的宏观环境（见 [[信用利差]]、[[库存周期]]）。
