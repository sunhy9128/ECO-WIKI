# 国防军工

> 国家安全的技术底座与大国博弈的战略产业 — 兼具国防属性与科技属性

## 一、定义与概述

**国防军工**（Defense Industry / 军工产业）指从事武器装备与国防科技研究、设计、制造、维修与保障的产业体系，是国家军事能力的工业与技术基础。在中国，国防军工以国有军工集团为骨干，涵盖核、航天、航空、[[船舶]]、兵器、电子信息六大行业，是典型的**国家战略产业**。

### 1.1 六大行业板块

| 板块 | 主要方向 | 代表主体 |
|------|---------|---------|
| **核** | 核武器、核动力、核燃料 | [[中核集团]] |
| **航天** | 运载火箭、卫星、导弹 | 航天科技、航天科工 |
| **航空** | 军用飞机、航空发动机 | 航空工业 |
| **船舶** | 水面舰艇、潜艇、海工装备 | [[中国船舶]] |
| **兵器** | 坦克、火炮、弹药 | [[兵器工业]] |
| **电子信息** | 雷达、通信、电子对抗 | [[中国电科]] |

### 1.2 与相关概念的关系

- [[兵器工业]]：陆战装备板块

## 二、背景

### 2.1 历史沿革

新中国成立初期，国防工业在极其薄弱的基础上起步，经过"两弹一星"等重大工程建立独立完整的体系。改革开放后，军工体系经历"军转民"、公司化改制与集团化重组，形成今天的十大军工集团格局。进入 21 世纪，随着国际安全环境变化，国防投入持续增长，军工产业进入新一轮景气周期。

### 2.2 战略地位

- **安全基石**：武器装备的自主供给能力是国防安全的底线
- **科技引擎**：军工是大量前沿技术的先导与孵化器
- **产业带动**：对高端制造、新材料、电子信息有强拉动效应
- **自主可控**：涉及大量[[卡脖子技术]]，与[[国产替代]]深度绑定

## 三、机制与作用

### 3.1 产业运作机制

```
军方需求牵引（装备订货/型号任务）
       ↓
军工集团组织研制（论证-研制-定型-批产）
       ↓
元器件/材料供应链配套（军转民、民参军）
       ↓
交付列装 + 维保升级
       ↓
军贸出口（反哺研发）
```

### 3.2 军工的特殊经济属性

| 属性 | 说明 |
|------|------|
| **订单驱动** | 需求以军方计划和型号任务为主 |
| **准计划经济** | 定价、产能、布局受国家管控 |
| **高准入壁垒** | 保密资质、军工四证等门槛 |
| **逆周期特征** | 军费开支相对经济周期平稳 |
| **技术溢出** | 军技民用带动产业升级 |

### 3.3 作用

- 保障国家安全与主权完整
- 支撑科技自主创新与高端制造升级
- 为资本市场提供确定性较高的长期成长赛道

## 四、关键事件与数据

### 4.1 关键节点

- **十大军工集团格局形成**：历经多次重组，形成核、航天、航空、船舶、兵器、电子等骨干集团
- **国企改革深化**：军工资产证券化率提升，优质资产陆续注入上市公司
- **新域新质作战力量**：无人机、太空、网络等新兴领域成为建设重点（见 [[无人机消耗战]]）
- **军民融合战略**：鼓励民企参与军品配套，扩大产业基础

### 4.2 结构性趋势

| 趋势 | 说明 |
|------|------|
| **信息化/智能化** | 装备从机械化向信息化、智能化升级 |
| **低成本规模化** | 消耗性武器强调数量与成本平衡 |
| **自主可控** | 关键器件、芯片、软件国产化提速 |
| **军贸多元化** | 出口市场从传统伙伴向外拓展 |

## 五、影响

### 5.1 对国家安全

- 构建威慑与实战能力的技术基础
- 降低对进口装备与技术的依赖风险

### 5.2 对经济与产业

- 带动高端材料、精密制造、电子信息全链条发展
- 军工订单支撑部分区域经济与就业
- 军转民技术（卫星导航、航空发动机、半导体）反哺民用产业

### 5.3 对资本市场

- 军工是 A 股重要板块，具备事件驱动与业绩驱动双重属性
- 央企改革与资产注入构成主题催化
- 军贸与地缘事件影响板块情绪
