# 天量成交

> 市场单日成交额创历史或阶段新高 — 情绪极端化的"信号弹"，也是转折风险的预警灯

## 一、定义

**天量成交**指市场（指数）或个股的**单日成交金额/成交量创出历史或阶段新高**，显著超出近期平均水平的现象。它意味着市场交易活跃度达到极端水平，多空换手激烈。

在 A 股语境中，"天量"通常指：

- **指数天量**：两市总成交额创历史新高或阶段新高（如突破此前的重要量能高点）。
- **个股天量**：单只股票放出历史最大成交量。
- **相对天量**：相对近期均量放大数倍，即使未创历史新高。

天量是 [[量价关系]] 分析中的极端样本：量能是价格运动的"燃料"，天量既可能加速趋势，也可能透支趋势。

---

## 二、天量出现的原因

### 2.1 情绪与资金驱动

| 触发因素 | 说明 |
|---------|------|
| **重大政策转折** | 政策超预期（如降息、刺激计划）引发资金集中入场 |
| **指数关键点位** | 突破或冲击重要整数关口/技术压力位，多空剧烈交锋 |
| **重大事件落地** | 重要会议、财报、外部事件催化集中交易 |
| **增量资金入市** | 新开户激增、外资大幅流入、杠杆资金扩张 |
| **多空分歧极大** | 看多与看空力量同时放量对冲 |

### 2.2 A 股的特殊性

A 股以散户为主（参见 [[散户行为]]），情绪驱动的交易占比高，叠加 [[融资融券]] 等杠杆资金，放量幅度与持续性往往强于成熟市场。"天量"既是资金热情的标志，也是情绪过热的风险信号。

---

## 三、天量的解读：量价配合

### 3.1 关键问题：天量之后看方向

天量本身**不构成买卖信号**，关键在于**天量出现的位置与后续量价配合**：

| 情景 | 含义 | 风险 |
|------|------|------|
| **低位天量 + 放量上涨** | 增量资金进场，可能开启趋势 | 需验证持续放量 |
| **高位天量 + 滞涨/长上影** | 获利盘与追高盘激烈换手 | 警惕"天量天价"见顶 |
| **天量 + 大幅下跌** | 恐慌性抛售，趋势可能反转 | 或为最后的放量出清 |
| **天量后快速缩量** | 热度难以为继，可能回落 | 谨防"一日游"行情 |

### 3.2 "天量天价"与"地量地价"

- **天量天价**：历史高位放出的天量，常被视为阶段性见顶信号——因为能推动价格的增量买盘已充分释放。
- **地量地价**：成交量极度萎缩常对应阶段性底部，与天量互为镜像。

> 但天量后也常出现"天量后再放量"的加速行情，**天量不是必然顶**，须结合价格结构与情绪周期综合判断，参见 [[结构性行情]]。

---

## 四、应用场景

### 4.1 用于择时与仓位管理

- **指数天量出现后**：提高对波动与回撤的警惕，控制追高仓位。
- **个股天量突破**：确认放量突破有效性的同时，观察换手是否健康。
- **与指标结合**：天量配合 [[MACD 指标]]、[[DDX指标]] 等判断资金性质。

### 4.2 用于情绪观察

天量是情绪极化的量化体现，是 [[泡沫经济]] 或 [[流动性幻觉]] 的观察窗口：当"天量"成为常态而价格滞涨，市场可能进入"量价背离"的过热阶段。

---

## 五、局限与误用

| 误区 | 说明 |
|------|------|
| **天量=顶/底** | 天量只是概率性信号，趋势市中天量后可再放量 |
| **忽略位置** | 同样天量，低位与高位含义完全不同 |
| **忽略结构** | 未区分"放量上涨/下跌/滞涨"的组合 |
| **总量口径** | 市值扩张会使"天量"记录不断刷新，需看相对量 |
| **情绪噪声** | 天量日噪音大，短线信号易失真 |

> **核心提醒**：天量成交是"温度计"而非"方向盘"——它如实反映市场情绪达到极端，但极端之后既可能是加速也可能是反转。解读天量，永远要回答三个问题：**在什么位置、配什么价格形态、后续量能如何**。

---

## 六、小结

**天量成交**是市场情绪极端化的标志：它显示增量资金与分歧同时放大，可能预示趋势加速，也可能透支动能、酝酿转折。观察天量时，应结合位置、价格形态与后续量能做组合判断，并将其置于 [[量价关系]] 与 [[技术分析]] 的整体框架之中。
