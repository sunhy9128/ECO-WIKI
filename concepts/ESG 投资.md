# ESG 投资

> 把环境、社会与治理因素放进投资决策——从"道德选项"到"[[风险管理]]"

## 一、定义

**ESG 投资（Environmental, Social and Governance）** 指将**环境、社会、治理**三大类非财务因素**系统纳入投资决策与组合管理**的投资方法。

ESG 的核心是识别并定价传统财务分析可能忽略的长期风险与机会：气候风险、劳工标准、董事会治理等，认为这些因素最终会影响企业的现金流与长期价值。[[concepts/主权财富基金|主权财富基金]]与养老基金是 ESG 投资的主要推动者，[[挪威主权基金]] 在此领域尤为积极。

### 1.1 三大支柱

| 支柱 | 关注内容 |
|------|---------|
| **环境（E）** | 气候变化、碳排放、资源消耗、污染 |
| **社会（S）** | 劳工权利、供应链、社区、产品安全 |
| **治理（G）** | 董事会、股东权利、薪酬、透明度、反腐败 |

---

## 二、ESG 投资的实现方式

### 2.1 主要策略

| 策略 | 说明 |
|------|------|
| **负面筛选** | 排除特定行业（烟草、争议武器等） |
| **正面筛选** | 优选 ESG 表现领先者 |
| **ESG 整合** | 将 ESG 因子纳入估值与选股模型 |
| **主题投资** | 投向清洁能源、低碳转型等主题 |
| **股东参与** | 通过投票与对话推动改善，参见 [[积极股东]] |
| **影响力投资** | 以可衡量的社会/环境成果为目标 |

### 2.2 与[[concepts/被动投资|被动投资]]的结合

- 指数层面嵌入 ESG 筛选（ESG 指数、低碳指数），形成"被动 + ESG"产品
- 参见 [[被动投资]]：低成本跟踪与可持续筛选的结合

---

## 三、实践主体与框架

### 3.1 主要推动者

- 主权财富基金与养老基金因其**超长期负债**，对长期可持续风险最为敏感
- 参见 [[挪威主权基金]]：基于受托责任制定明确 ESG 框架，在气候与治理议题上长期施压
- 参见 [[主权财富基金]]、[[GIC]]：普遍将 ESG 纳入长期配置与投票政策

### 3.2 主流框架与标准

- UNPRI（联合国负责任投资原则）等倡议推动机构承诺
- 信息披露标准（如气候相关财务披露）逐步成为上市公司与投资人的共同语言
- 数据与评级提供商为组合管理提供 ESG 评分基础

## 四、ESG 的价值逻辑

| 维度 | 说明 |
|------|------|
| **[[domains/风险管理|风险管理]]** | 前瞻识别监管、诉讼、声誉与转型风险 |
| **长期回报** | 治理与可持续性好的企业长期现金流更稳健 |
| **受托责任** | 回应受益人价值观与长期利益，参见 [[长期主义]] |
| **政策协同** | 契合碳中和与可持续发展政策方向 |

---

## 五、争议与批评

| 批评 | 说明 |
|------|------|
| **漂绿** | 包装性披露多、实质行动少，真实性难验证 |
| **与受托责任冲突** | 非财务目标可能牺牲回报，存在法律争议 |
| **数据与口径不一** | 评级机构方法差异大，结果互不兼容 |
| **被动放行** | 指数化 ESG 可能仅"购买"而非"改变"坏企业 |
| **回报影响** | 对投资业绩的影响存在争议，实证结论不一 |

---

## 六、应用场景与局限

| 场景 | 说明 |
|------|------|
| **主权基金/养老金** | 长期资金将 ESG 作为风险管理框架 |
| **资产配置** | ESG 指数、主题基金丰富配置维度 |
| **公司治理** | 与积极股东协同推动治理改善 |

**局限**：数据质量、方法论分歧、漂绿风险与回报权衡仍是核心短板，ESG 应视为**风险与价值分析的一部分**而非单一的道德筛选。

## 七、一句话总结

> **ESG 投资 = 将环境、社会、治理因素纳入投资决策**，以管理长期风险、服务受托责任。它从主权基金与养老金起步，已成为主流配置维度，但漂绿与口径分歧仍是待解难题。
