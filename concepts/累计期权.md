# 累计期权

> 名字叫"期权"，结构却像"对赌"——收益封顶、损失无限，被称为"I Kill You Later"

## 一、定义

**累计期权（Accumulator）**，又称 **KODA**（Knock-Out Discount Accumulator，敲出折价累计期权），是一种**奇异期权**：在约定期限内，持有者须**按约定价格（通常低于市场价）每日买入一定数量的标的资产**，直到累计买入量达到合约上限，或标的触及**敲出价（Knock-Out）**使合约提前终止。

因其"收益有顶、亏损无底"的非对称结构，市场戏称为 **I Kill You Later（我晚点杀你）**。常见于挂钩股票、外汇、大宗商品的结构化产品，尤其盛行于[[港股]]市场，曾被大量销售给企业和高净值投资者作为融资与套保工具。

### 1.1 核心特征

| 维度 | 说明 |
|------|------|
| **方向** | 本质是持续买入标的（做多）的远期承诺 |
| **买入价** | 通常较签约时市价有折价（Discount） |
| **敲出条款** | 标的价格涨至敲出价，合约立即终止（盈利被锁定上限） |
| **下行风险** | 标的大跌时仍须按高价持续买入，损失**无下限** |
| **结构** | 由一系列远期/期权组合而成的奇异期权 |

---

## 二、运作机制

### 2.1 典型条款

```
合约期限：如一年
买入价：签约时市价的九折（示例）
每日买入量：名义金额 ÷ 天数
敲出价：签约时市价 + 20%（示例）
触发敲出：合约终止，已实现收益保留
标的下跌：仍按买入价每日买入 → 亏损累积
```

- **折价买入**：只要标的横盘或缓涨，持有者每日都能以低于市价的成本建仓，账面占便宜
- **敲出封顶**：价格一旦触及敲出价，合约提前结束，上方收益被封顶
- **下跌无底**：标的下跌时，持有者仍须按高于市价的买入价持续接货，亏损随跌幅扩大而加速

### 2.2 与普通期权/权证的区别

| 维度 | 普通看涨期权 | 累计期权 |
|------|------------|---------|
| **权利** | 有权不行权 | **必须**按计划买入 |
| **收益** | 上涨时无限 | 上涨时被敲出封顶 |
| **亏损** | 最多损失权利金 | 理论上无限 |
| **成本** | 一次性权利金 | 持续买入 + 潜在巨亏 |
| **性质** | 权利 | 义务 |

### 2.3 定价原理

- 累计期权可拆解为**一系列折价远期买入合约 + 敲出期权条款**的组合
- 表面上的"折价买入"是通过出售上方收益（敲出）与下方义务换来的
- 因此其"免费午餐"实为被包装的风险转移结构

## 三、典型案例

### 3.1 企业与外汇累计期权

- 部分企业为"[[套期保值]]"外币支出购买外汇累计期权，锁定相对有利的汇率
- 汇率剧烈反向波动时，企业被迫按高价持续买入，产生巨额账面浮亏
- 2008 年前后多家港股上市公司因此爆出重大衍生品亏损

### 3.2 杠杆与损失

- 合约通常设 2-4 倍杠杆：跌 10%，持有者或须按数倍名义量买入，实际损失远大于跌 10%
- 损失无下限的特征使其成为"对赌"式工具而非单纯的套保工具

### 3.3 监管反思

- 事件后市场反思**金融产品销售适当性**：复杂奇异期权被不适当地卖给缺乏风险认知的企业与个人
- 监管加强了对结构化产品条款披露与投资者适当性的要求

## 四、应用场景与局限

| 场景 | 说明 |
|------|------|
| **企业套保** | 锁定采购/支出成本，但需评估极端情形下的义务 |
| **融资替代** | 以折价建仓降低初始成本，实为变相加杠杆 |
| **收益增强** | 在低波动市况下赚取折价，但须承担尾部风险 |

**局限**：

- 收益结构不对称（封顶 vs 无底），风险收益比极差
- 条款复杂、透明度低，普通投资者难以评估真实风险
- 杠杆机制放大损失，极端行情下可致巨额亏损

## 五、一句话总结

> **累计期权 = 以"折价买入 + 敲出封顶"为诱饵、实则强制接货、亏损无底**的奇异期权。它在给持有者"免费折价"的同时，把上方收益和下行风险都留给了持有者——"I Kill You Later"正是对其不对称结构的写照。
