# 开正门、堵偏门

> 地方债务治理的基本方针 — 以规范融资渠道置换隐性债务乱象

## 一、定义与概述

**"开正门、堵偏门"**是中国财政与债务管理领域的基本方针，指在处置地方政府债务风险时，一方面**开放并规范合法的融资渠道**（"正门"），另一方面**堵住不合规的隐性举债渠道**（"偏门"），引导地方债务从"隐性、无序"转向"显性、规范"。它是理解中国[[化债]]与地方债务治理逻辑的核心框架。

### 1.1 内涵拆解

| 维度 | 正门 | 偏门 |
|------|------|------|
| **性质** | 依法合规的融资渠道 | 违规/变相的举债方式 |
| **形式** | 地方债、专项债、一般债 | 违规担保、隐性债务、影子融资 |
| **特征** | 显性、透明、受限额约束 | 隐性、分散、脱离监管 |
| **监管** | 纳入预算管理 | 被清理、问责与堵截 |
| **政策态度** | 扩大与规范 | 坚决堵住 |

### 1.2 与相关概念的关系

- [[化债]]：本方针指导下的债务化解实践
- [[地方政府隐性债务]]：偏门所产生的治理对象
- [[城投公司]]：正门与偏门之间的关键主体
- [[金融体制改革]]：配套的制度环境

## 二、背景

### 2.1 政策背景

地方政府在"事权多、财权少"的约束下，长期依赖土地财政与融资平台举债，形成了规模较大的隐性债务。隐性债务透明度低、成本高、风险传导性强，对财政可持续与金融稳定构成威胁。为此，决策层确立"开正门、堵偏门"方针，构建规范、透明、可持续的地方政府举债融资机制。

### 2.2 传导逻辑

```
地方融资需求旺盛（财权事权不匹配）
       ↓
正门受限 → 偏门滋生（违规担保、明股实债等）
       ↓
隐性债务累积、风险积聚
       ↓
"开正门、堵偏门"：规范替代 + 堵漏清理
       ↓
债务显性化、成本下降、风险收敛
```

## 三、机制与作用

### 3.1 开正门：规范化融资渠道

| 渠道 | 说明 |
|------|------|
| **地方政府债券** | 一般债与专项债，纳入预算与限额管理 |
| **专项债扩容** | 投向基建、化债、收购存量房等指定领域 |
| **特殊再融资债券** | 置换存量隐性债务，降低利息负担 |
| **财政转移支付** | 补充地方财力（见 [[转移支付]]） |
| **规范PPP/REITs** | 拓宽市场化合规融资 |

### 3.2 堵偏门：清理与问责

- 严禁新增隐性债务，压实"终身问责、倒查责任"
- 清理违规担保、变相举债、明股实债等模式
- 规范融资平台转型，剥离政府融资功能（见 [[城投公司]]）
- 金融监管配合，切断影子渠道资金供给

### 3.3 主要作用

- **显性化**：将隐性债务逐步置换为显性债务，透明可控
- **降成本**：以低息政府债置换高息隐性债务
- **防增量**：从制度上堵住新增隐性债务的口子
- **促规范**：推动地方财政治理与预算约束现代化

## 四、关键事件与数据

### 4.1 关键节点

- **债务限额管理确立**：地方债"开前门"的制度框架
- **新预算法实施**：赋予地方规范举债权限，同时严控隐性债务
- **一揽子化债方案**：特殊再融资债券大规模置换存量债务（详见 [[化债]]）
- **融资平台转型推进**：名单制管理、分类处置

### 4.2 政策特征

| 特征 | 说明 |
|------|------|
| **制度先行** | 以限额、预算、清单管理构建正门 |
| **问责配套** | 终身问责倒逼堵偏门 |
| **标本兼治** | 既处置存量，又约束增量 |
| **金融协同** | 银行、债券、AMC 多工具配合 |

---

## 五、影响

### 5.1 对地方财政

- 债务结构优化，利息负担下降
- 融资渠道规范，财政可持续性增强
- 土地财政依赖与平台输血模式逐步退出

### 5.2 对金融体系

- 隐性风险显性化，金融体系不确定性下降
- 银行对平台融资的敞口管理与期限匹配改善
- 城投与地方国企信用定价回归基本面

### 5.3 对宏观经济

- 短期财政与基建节奏受化债影响
- 长期有利于防风险与高质量发展
- 规范举债有助于稳定市场预期与信用环境
