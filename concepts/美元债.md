# 美元债

> 中资企业（尤以房企为代表）在境外发行的以美元计价的债券。它是 [[债务重组]] 中"境外债权人"这一侧的载体，也是 [[恒大全事件]] 里境内外债权人分歧、重组投票失败的机制核心——美元债持有人的利益结构，决定了他们比境内银行更不接受削债。

## 一、定义与分类

**美元债** = 非美国主体发行的以美元计价的债券。**中资美元债** = 中国企业（房企/城投/银行/科技）在境外（主要香港）发行的美元债券。

对境内主体而言，美元债是**离岸融资渠道**：发行在境外、计价在美元、受境外法律（如香港法/纽约法）管辖，违约时境外债权人可诉诸当地清盘程序。

## 二、为什么发美元债（发行动机）

| 动机 | 机制 |
|------|------|
| **成本优势** | 美元利率低（2015-2017、2020-2021）时，境外融资成本低于境内 |
| **规避境内约束** | 境内发债额度、信贷集中度、房地产融资红线等限制绕不开 |
| **币种匹配** | 有美元收入的出口/出海企业天然匹配美元负债 |
| **历史扩张期** | 2015 年起房企"高杠杆、高周转"扩张期大规模发债，恒大即典型 |

## 三、风险与脆弱性

美元债对中资主体的根本脆弱性来自 **币种错配**（即 [[Original Sin（原罪）]]）：

1. **原罪效应**：收入是人民币、负债是美元，本币贬值 → 美元债务按本币计价的偿还额翻倍
2. **再融资风险**：美元债到期需滚动续借，一旦美元利率上升 + 自身信用恶化 → 滚续失败 → 违约
3. **交叉违约**：一条债违约触发其他债券/贷款合同中的交叉违约条款，风险连锁引爆
4. **无抵押债权**：美元债通常无资产担保，回收依赖发行人信用与重组条款，劣于境内有抵押贷款

宏观上，美元债的融资环境由 [[美元周期]]/[[美元潮汐]] 决定：美元加息 + 收紧流动性时，中资美元债融资成本上升、滚续窗口关闭（见 [[美元流动性]]）。

## 四、恒大全事件：境内外债权人分歧的标本

恒大是美元债风险链条的最完整实证：

| 节点 | 事实 |
|------|------|
| 2022.08.30 | 恒大公布境外债重组方案，涉及约 **190 亿美元**（约合千亿人民币） |
| 2023.04 | 债权人投票：**Class A 77% 同意** vs **Class C 30% 否决**，未达门槛，方案整体失败 |
| 2024.01.29 | 香港高院颁布强制清盘令 |
| 回收 | 境外债债权人回收率仅 **0.5%-3%**（对照接受重组的假设回收率约 30%） |

**为什么境内外债权人分歧如此之大**：

| 维度 | 境内债权人（银行/信托） | 境外美元债持有人 |
|------|----------------------|----------------|
| 抵押 | 有（项目/土地） | 通常无抵押 |
| 背书 | 国家信用背书、可展期 | 无国家背书 |
| 政治任务 | 承担保交楼、维稳 | 无 |
| 谈判筹码 | 资产处置依赖其配合 | 可诉诸香港清盘程序施压 |
| 对削债的容忍度 | 高（可吃下坏账） | 低（削债即实亏） |

> 核心矛盾：**境内债权人"没得选就接受"，境外债权人"不接受还能靠清盘施压"**。投票机制的 Class 分级使境外票数被单独统计，30% 否决足以拖垮整体方案——这就是 [[债务重组]] 里"债权人投票是最困难环节"的实证。
