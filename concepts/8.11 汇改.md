# 8.11 汇改

> 2015 年 8 月 11 日，中国人民银行对人民币兑美元中间价定价机制进行重大改革，被市场称为"8.11 汇改"，是人民币汇率形成机制市场化进程中的分水岭事件。

## 一、概述

**8.11 汇改**指中国人民银行于 2015 年 8 月 11 日宣布完善人民币兑美元汇率中间价报价机制的改革。核心变化是：做市商在报价中间价时，参考上一交易日银行间外汇市场收盘汇率，并结合市场供求与一篮子货币汇率变化。改革当天人民币兑美元中间价一次性大幅下调，随后开启了一段以贬值为主、波动显著加大的时期。

该事件是[[人民币汇率形成机制]]演变的关键节点：从此人民币汇率从"以管理为主"逐步走向"以市场供求为基础、参考一篮子货币进行调节"的更大弹性格局。

## 二、背景

### 2.1 此前的中间价形成机制

改革之前，人民币兑美元中间价由央行授权外汇交易中心，在上一交易日收盘价基础上"询价"确定，央行的管理色彩浓厚，中间价长期偏离市场汇率，形成了持续的**单边升值预期**与套利空间。

### 2.2 内外部压力

| 因素 | 说明 |
|------|------|
| **升值预期** | 2014 年前人民币长期单边升值，热钱流入 |
| **资本外流** | 2014 年起经济增速放缓，资本流出压力上升 |
| **外汇储备下降** | 外储由峰值持续回落，干预成本上升 |
| **外部诉求** | 人民币纳入 SDR 货币篮子的评估，要求汇率形成机制更市场化 |

### 2.3 改革目标

- 提高中间价形成的市场化程度
- 增强人民币汇率弹性
- 减少央行对汇率的日常干预成本
- 为人民币国际化与入篮 SDR 创造条件

## 三、机制与作用

### 3.1 新中间价定价逻辑

```
做市商参考上一交易日收盘价
        ↓
结合市场供求
        ↓
结合一篮子货币汇率变化
        ↓
形成当日中间价
```

### 3.2 后续机制演进

| 阶段 | 变化 |
|------|------|
| 2015.8 | 8.11 汇改：参考收盘价报价 |
| 2015.12 | 引入 CFETS 人民币汇率指数，转向"参考一篮子货币" |
| 2016 | 中间价定价公式逐步公开化 |
| 2017.5 | 引入"逆周期因子"，对冲顺周期羊群效应 |
| 2018.1 | 逆周期因子暂停使用 |
| 2018.8 | 逆周期因子重启（贸易摩擦背景下） |
| 2020 以来 | 逆周期因子淡出，中间价与市场价更趋一致 |

### 3.3 作用

- **定价透明化**：中间价与市场汇率偏离度收窄
- **弹性提升**：人民币单日波幅限制逐步放宽，双向波动成为常态
- **压力释放**：通过一次性贬值释放积累的贬值压力，避免长期单边预期累积

## 四、关键事件与数据

### 4.1 2015 年 8 月 11 日

- 央行宣布改革中间价报价机制
- 当日人民币兑美元中间价一次性下调约 2%
- 随后数个交易日继续调整，市场剧烈波动

### 4.2 后续冲击

| 时间 | 事件 |
|------|------|
| 2015 年底-2016 年初 | 人民币贬值压力延续，股市"熔断"期间形成"股汇双杀" |
| 2016.1 | 离岸与在岸人民币价差显著走阔 |
| 2017 | 逆周期因子引入后，单边贬值预期被抑制，汇率企稳回升 |
| 2018-2019 | 贸易摩擦背景下人民币再度承压 |
| 2022-2024 | 美元加息周期中人民币明显贬值，但波动逐步回归市场驱动 |

> 注意：8.11 汇改后的贬值并非单次事件，而是一个持续数年的弹性化过程，具体点位以市场行情为准，此处不做具体数字断言。

## 五、影响

### 5.1 对人民币汇率形成机制

8.11 汇改确立了"收盘价 + 一篮子货币 + 逆周期因子"的中间价框架，此后人民币汇率弹性显著增强，[[汇率非市场化]]的特征逐步弱化。

### 5.2 对资本流动与外汇储备

- 贬值预期一度引发资本流出压力，[[外汇储备]]规模由峰值明显回落
- 为对冲贬值压力，央行加强了[[外汇管制]]与跨境资金流动宏观审慎管理

### 5.3 对资产市场

- 2015 年四季度至 2016 年初，"股汇双杀"表明汇率与股市存在联动（见 [[股汇负相关]] 与 [[股汇关系]]）
- 贬值预期下，人民币资产风险溢价上升

### 5.4 对人民币国际化

- 短期看，贬值预期不利于境外主体持有人民币资产的意愿
- 长期看，更市场化的汇率形成机制是人民币国际化的制度基础

### 5.5 对外贸与进出口企业

- 汇率弹性提升使[[出口盈利预期]]的不确定性上升，企业汇率风险管理需求增加
- 央行配套推出远期外汇、掉期等[[央行对冲工具]]与风险准备金制度
