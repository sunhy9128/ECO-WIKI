# 稳三保

> 房地产风险处置的政策目标框架 — 从"保交楼"到"保民生、保稳定"的防线递进

## 一、定义与概述

**稳三保**是房地产调控进入风险化解阶段后形成的政策目标框架，核心内涵为**"稳楼市、保交楼、保民生、保稳定"**。它以"保交楼"为切入点和首要抓手，通过保障已售未交付商品房按期交付，守住民生底线，最终服务于社会稳定与防范系统性风险。该框架体现了房地产政策从"增长导向"向"安全导向"的转向。

### 1.1 内涵拆解

| 环节 | 内涵 | 意义 |
|------|------|------|
| **稳** | 稳楼市、稳预期 | 防止市场失速与信心崩塌 |
| **保交楼** | 保障期房按期交付 | 直接处置交付风险 |
| **保民生** | 保障购房者权益与基本住房需求 | 守住民生底线 |
| **保稳定** | 防范群体性事件与系统性风险 | 社会稳定目标 |

## 二、背景

### 2.1 政策背景

2021 年下半年以来，部分房企出现流动性危机，多地项目停工缓建，"烂尾楼"风险凸显。为稳定市场预期、保护购房者权益，决策层提出"保交楼"专项工作，并逐步扩展为"保交楼、保民生、保稳定"的三保框架，形成从**交付风险 → 民生风险 → 社会稳定**的传导链条与应对主线。

### 2.2 传导逻辑

```
房企流动性危机
       ↓
项目停工、交付延期
       ↓
购房者权益受损（民生风险）
       ↓
群体性事件与社会稳定风险
       ↓
"稳三保"政策干预（保交楼优先）
```

## 三、机制与作用

### 3.1 主要机制

| 机制 | 说明 |
|------|------|
| **专项借款** | 政策性资金支持已售逾期项目复工 |
| **融资白名单** | 对合规项目提供信贷支持（见 [[房地产白名单]]） |
| **项目收并购** | 优质房企与 AMC 介入纾困项目 |
| **现房/资金监管** | 强化预售资金监管，防范资金挪用 |
| **地方政府属地责任** | 压实"一城一策"与属地处置责任 |

### 3.2 作用

- **守住交付底线**：优先保障已售未交付项目的复工交付
- **稳定预期**：缓解购房者恐慌，抑制二手房价与市场信心螺旋下行
- **隔离风险**：将个别房企风险限制在局部，避免向金融体系传染
- **维护稳定**：降低群体性事件与民生诉求压力

---

## 四、关键事件与数据

### 4.1 关键节点

- **"保交楼"专项工作启动**：中央统筹，政策性银行专项借款介入
- **融资白名单机制落地**：向合规项目开放融资渠道
- **政策表述升级**：从"保交楼"扩展为"保交楼、保民生、保稳定"
- **城市与企业试点**：一线城市取消限购、降低首付与利率，配合化解风险

### 4.2 政策特征

| 特征 | 说明 |
|------|------|
| **民生优先** | 交付优先于企业救助 |
| **属地责任** | 地方政府承担主要处置责任 |
| **项目制纾困** | 以项目而非集团为纾困单元 |
| **金融配合** | 信贷、专项债、AMC 多工具协同 |

---

## 五、影响

### 5.1 对购房者

- 部分项目复工交付，权益得到保障
- 期房信心修复需要时间，现房销售倾向上升

### 5.2 对房企与行业

- 优质项目获得资金支持，行业出清加速
- 高杠杆模式终结，行业转向低杠杆、重交付经营
- 房企分化加剧，弱势主体持续出清

### 5.3 对金融体系

- 阻断风险向银行、城投与债券市场传染
- 资产质量压力局部缓解，但存量风险化解仍任重道远

### 5.4 对社会稳定

- 降低"烂尾楼"引发群体性事件的概率
- 保障性住房与民生政策协同，缓解社会压力
