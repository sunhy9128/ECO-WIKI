# 被动投资

> 不预测、不择时、低费用——用"买入并持有指数"对抗市场平均

## 一、定义

**被动投资（Passive Investing）** 指投资者**以跟踪市场指数为目标**、而非试图战胜市场的投资策略。其核心做法是买入并长期持有代表整个市场或某个市场的指数基金/ETF，以**低费用、低换手率、高透明度**为特征。

被动投资不追求跑赢基准，而是"成为"基准——通过持有指数的全部或代表性成分，获得与市场整体一致的收益。大型主权基金与养老基金普遍采用**被动为主、主动为辅**的配置框架。

### 1.1 与主动投资的对比

| 维度 | 被动投资 | 主动投资 |
|------|---------|---------|
| **目标** | 跟踪指数、获得市场平均 | 战胜市场基准 |
| **费用** | 低（管理费低） | 高（管理费 + 业绩分成） |
| **换手率** | 低 | 高 |
| **透明度** | 高（成分公开） | 低 |
| **依赖基金经理** | 低 | 高 |
| **长期胜率** | 大概率接近基准 | 多数跑不赢基准 |

## 二、理论依据与机制

### 2.1 理论基础

- **市场有效性**：若价格已充分反映信息，主动选股难以稳定获得超额收益
- **成本复利**：费用的微小差异在长周期复利下产生巨大差距，参见 [[长期主义]]
- **均值回归**：多数主动基金的长期表现回归于市场平均

### 2.2 实现方式

| 方式 | 说明 |
|------|------|
| **指数基金** | 按指数权重买入成分股，被动跟踪 |
| **ETF** | 交易所交易，兼具指数化与交易便利 |
| **市值加权** | 按市值占比配置，最大公司权重最高 |
| **Smart Beta** | 在被动框架内加入因子权重（价值、红利、低波动） |

### 2.3 操作流程

```
确定目标指数（如宽基、行业、地区）
       ↓
按权重买入成分 / 复制指数
       ↓
低换手持有，仅在成分调整时再平衡
       ↓
定期再平衡 + 分红再投资
       ↓
获得与指数趋同的长期回报
```

## 三、[[concepts/主权财富基金|主权财富基金]]的实践

- 参见 [[挪威主权基金]]：全球规模最大的主权基金之一，以**指数化被动投资为主**，辅以有限主动策略，覆盖全球数千只股票
- 参见 [[主权财富基金]]、[[GIC]]：普遍采用被动为主的长期配置框架
- 被动投资与[[concepts/长期主义|长期主义]]天然契合：不择时、不频繁交易，契合超长期资金属性

## 四、优点与局限

### 4.1 优点

- **低成本**：费率显著低于主动基金，长期复利优势明显
- **纪律性**：避免情绪化交易与追涨杀跌，参见 [[散户行为]]
- **透明可预期**：成分公开、风格稳定，便于资产配置
- **规模效应**：可容纳超大资金体量，适合主权基金

### 4.2 局限与批评

| 批评 | 说明 |
|------|------|
| **指数泡沫** | 资金涌入头部权重股，推高集中度与估值 |
| **治理弱化** | 自动买入成分股，可能"无条件"支持平庸管理层 |
| **市场失效** | 若多数资金被动化，价格发现功能可能受损 |
| **风险集中** | 市值加权在泡沫期过度暴露于热门行业 |

---

## 五、与[[concepts/积极股东|积极股东]]的张力

- 被动投资者"买入即持有"，看似与管理层疏离，实则通过**代理投票与股东参与**行使治理权利，形成"被动投资 + 主动治理"的模式
- 参见 [[积极股东]]：被动基金巨头正在成为推动公司治理变革的重要力量
- 参见 [[ESG 投资]]：被动指数产品也常叠加 ESG 筛选，回应受托责任

## 六、一句话总结

> **被动投资 = 用指数化、低成本、低换手的方式"成为市场"**，以牺牲超额收益的确定性换取费用的确定性与长期复利，是主权基金与长期资金的基础配置策略。
