# 市场失灵

> 市场并非万能 — 当"看不见的手"失灵时，政府干预就有了经济学依据

## 一、概述

### 1.1 定义

**市场失灵**（Market Failure）指**市场机制在某些情形下无法实现资源的最优配置**，即价格机制不能有效引导资源流向社会价值最高的用途，从而使自由放任的市场均衡偏离帕累托最优。市场失灵是政府干预的传统经济学依据。

### 1.2 与市场局限的区别

- **市场失灵**：价格机制在特定结构条件下失效（如外部性、公共物品）；
- **市场不完全**：交易成本、信息成本使市场运行不完美，但不必然失灵；
- 需要区分"市场失灵"与"市场结果不合意"（如贫富差距），后者涉及分配正义，而非效率问题（见 [[收入分配]]）。

### 1.3 四种经典情形

| 失灵类型 | 核心问题 | 典型例子 |
|----------|----------|----------|
| **外部性** | 价格未反映全部社会成本/收益 | 污染、疫苗外溢 |
| **公共物品** | 非排他、非竞争导致供给不足 | 国防、路灯、基础科研 |
| **垄断** | 市场势力导致产量过低、价格过高 | 自然垄断、卡特尔 |
| **信息不对称** | 交易双方信息不均导致逆向选择与道德风险 | 二手车市场、保险、信贷 |

## 二、理论机制

### 2.1 外部性

当个体的行为对他人的福利产生**未通过价格补偿的**影响时，即存在外部性：

```
负外部性：污染者成本 < 社会成本 → 生产过多
正外部性：创新者收益 < 社会收益 → 创新不足
```

外部性导致私人成本（收益）与社会成本（收益）偏离，市场均衡偏离社会最优，需要以税收、补贴、排放权交易等工具纠正（见 [[市场失灵与外部性]]）。

### 2.2 公共物品与公地悲剧

- **公共物品**具备非排他性与非竞争性，市场无法有效供给，易出现"搭便车"（见 [[公共物品]]）；
- **公共资源**具有竞争性但难以排他，容易因过度使用而枯竭，形成"公地悲剧"（见 [[公地悲剧]]）；
- 两者的共同根源在于**产权难以清晰界定**，从而无法通过价格机制形成使用约束（见 [[产权理论与制度经济学]]）。

### 2.3 垄断与市场势力

```
垄断者边际收益 < 价格 → 定价高于边际成本、产量低于竞争水平
        ↓
消费者剩余被转移，产生无谓损失
        ↓
资源配置效率下降
```

自然垄断（规模经济显著、重复建设浪费的行业）与人为垄断（卡特尔、行政壁垒）都构成市场失灵，需以反垄断与竞争政策矫正（见 [[反垄断法]]、[[竞争政策]]、[[规模不经济]]）。

### 2.4 信息不对称

信息不对称导致两类经典问题：

| 问题 | 发生时点 | 机制 |
|------|----------|------|
| **逆向选择** | 交易前 | 劣质品把优质品逐出市场（柠檬市场）（见 [[逆向选择]]） |
| **道德风险** | 交易后 | 一方行为因有保险/担保而更冒险（见 [[道德风险与委托代理]]） |

保险市场、信贷市场、二手商品市场是信息不对称的典型场景。市场自发的信号传递（担保、认证、声誉）与信息披露制度（见 [[信息不对称]]）只能部分缓解失灵。

## 三、矫正手段与政府角色

### 3.1 政府干预的工具箱

| 工具 | 适用失灵 | 例子 |
|------|----------|------|
| **庇古税/补贴** | 外部性 | 碳税、减排补贴 |
| **总量控制与交易** | 外部性 | 碳排放权交易 |
| **公共提供** | 公共物品 | 国防、基础科研投入 |
| **反垄断执法** | 垄断 | 经营者集中审查、拆分 |
| **信息披露监管** | 信息不对称 | 上市公司强制披露、产品标签 |
| **直接规制** | 上述多种 | 价格管制、准入审批 |

### 3.2 政府失灵：干预的限度

政府矫正也可能失败，形成**政府失灵**：

- 信息不足：政府同样面临信息约束，难以精确设定税率与规制标准；
- 寻租与俘获：监管者可能被被监管者俘获（见 [[美国旋转门制度]]）；
- 官僚激励偏差：官员目标与社会福利不一致；
- 干预滞后与路径依赖：政策调整滞后于市场变化。

因此政策设计应遵循**次优原则**：干预的收益须与政府失灵的成本相权衡。

### 3.3 市场失灵在不同领域的表现

- **金融市场**：信息不对称与外部性集中，系统性风险构成独特的市场失灵，需要监管（见 [[金融稳定]]、[[银行风险]]）；
- **劳动市场**：信息不对称与匹配摩擦导致失业与非自愿失业；
- **公共品领域**：疫苗、基础科研、防灾等正外部性领域需公共投入（见 [[公共物品]]）。

## 四、应用与局限

### 4.1 分析应用

- **政策评估**：判断某项政府干预（监管、补贴、税收）是否针对真实的市场失灵，是政策合理性论证的关键；
- **改革边界**：市场化改革应识别哪些领域真正需要市场、哪些领域天然失灵需保留公共机制（见 [[中国改革]]、[[国企改革]]）；
- **竞争政策**：反垄断执法的合理性依据，正是垄断造成的市场失灵（见 [[反垄断法]]）。

### 4.2 局限与争论

- **测量困难**：外部性、垄断损失难以精确度量，干预可能"矫枉过正"；
- **概念边界模糊**：哪些属于"失灵"存在学派分歧——奥地利学派倾向认为多数"失灵"源于政府制造或信息分散，而非市场本身缺陷；
- **静态vs动态**：市场短期失灵（如波动）可能伴随着长期动态效率（如试错与创新），简单干预反而损害长期配置效率。

### 4.3 综合判断

> 市场失灵为政府干预提供了**必要条件而非充分条件**。合理的政策应：
> ① 先确认失灵真实存在且可测量；
> ② 再评估干预工具的边际收益大于其副作用；
> ③ 最后选择对价格信号扭曲最小的方式，并随时评估退出。
