# 恒大全事件

> 中国房地产风险处置的标志性事件：从 2021 年债务危机曝光、2023 年重组方案投票失败，到 2024 年香港高院清盘令，完整演绎了"早重组 > 晚重组 > 清盘"的债务处置链条，是 [[保交楼]] 与 [[债务重组]] 两大框架的典型反例教材。

## 一、核心定义

**恒大全事件** = 恒大集团 2021-2024 年债务危机的完整处置链条。它不只是单一公司的财务事件，而是中国房地产下行周期中**规模最大、结局最差**的风险处置样本：规模大到"不能倒"（百万套房子 + 数十万购房者），却因重组分歧与实控人风险走向清盘，境外债权人回收率仅 0.5%-3%。

在知识库框架中的位置：
- 它是 [[债务重组]] 的**失败案例**——重组投票未过 → 清盘（对照"早重组 > 晚重组 > 清盘"）
- 它是 [[保交楼]] 的**最大挑战**——债务重组失败后，保交楼无人敢接手
- 它是 [[分摊痛苦]] 的**反面数学**——债权人不同意分摊，清盘后回收率远低于接受重组

- 2025.08.25 ◆ 上午九时，中国恒大在港交所正式摘牌（停牌 18 个月后退市定局，"万亿"恒大落幕）
- 清盘程序持续推进，处置恒大汽车、恒大物业等剩余资产
- 境外债权人回收率预期 0.5%-3%（★，vault 已验证）

**核心叙事**：2021.12 实质违约 → 2022 重组僵局 → 2023 方案被否 + 实控人被抓 → 2024 清盘令 + 财务造假处罚 → 2025.08.25 退市摘牌。"早重组 > 晚重组 > 清盘"的完整演绎。另：信达香港董事长梁森林曾"入局"恒大董事会任"外援"；许家印成被执行人（恒大地产战投往事埋雷）。

## 四、重组为何失败

### 4.1 债权人投票是死结

重组方案的关键节点是债权人投票，需达到法定多数门槛。恒大案例中：

- **Class A 77% 同意**——过了门槛
- **Class C 30% 否决**——远低于 77% 门槛

境内外债权人利益不一致，境外债权人不接受削债幅度，方案整体失败。

### 4.2 四大教训

1. **规模太大不能倒**：恒大 = 百万套房子 + 数十万购房者，尾部风险被放大到系统性层面
2. **重组分歧**：境外 vs 境内债权人利益不一致，投票环节互相否决
3. **实控人风险**：被调查 → 没人敢签字，重组方案失去拍板人
4. **清盘结局**：债权人回收率 0.5%-3%，远低于接受重组的假设回收率（约 30%）

## 五、处置数学：接受重组 vs 清盘

来自 [[分摊痛苦]] 的债务重组数学框架：

```
原始债务：1个亿
第一次重组：1亿 → 3000万（削债70%）
二次重组可能：3000万 → 900万（再削70%）

债权人选择：
A. 不同意 → 债务人清盘 → 回收率0.5%-3%（恒大案例）
B. 同意 → 回收率30%（假设）
```

**理性选择 = 接受重组**。恒大的结局证明：拖延和分歧只会让情况更糟——**早重组 > 晚重组 > 清盘**。

## 六、保交楼意义

恒大的保交楼情况：

> **恒大的保交楼意义**：必须与债务重组同步推进，否则无人敢接手。

债务重组失败 → 清盘 → 项目无人续建 → 烂尾风险落地。恒大证明了两者的耦合关系：保交楼不是独立的民生工程，它依赖债务处置先落地。

## 七、宏观背景

恒大全事件发生在 [[房地产]] 债务逻辑的框架内——"债务不是手段而是目的"，债务转移到普通人身上驱动劳动意愿。恒大的崩塌动摇了这一链条：当"房价永远涨"的预期破灭，加杠杆者的债务变成坏账，最终通过 [[分摊痛苦]] 的三条路径转移：银行承担（坏账拨备）、国家承担（财政兜底）、社会承担（通胀稀释）。
