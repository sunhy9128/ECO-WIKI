# 名义利率与通胀预期

> 名义利率 = 实际利率 + 通胀预期。通胀来临时，投资者要求更高的名义收益率补偿购买力损失——这不是单方面的"索取"，而是市场供需定价的必然结果。

## 一、概述

**名义利率**是合同上写明的利率（票面利息、报价收益率），**实际利率**是扣除通胀后投资者真正获得的购买力回报。核心等式（费雪方程）：

```
名义利率 = 实际利率 + 预期通胀率
实际利率 = 名义利率 − 预期通胀率
```

投资者真正在乎的是**实际购买力回报**，不是账面数字。因此通胀预期上升时，名义利率必须随之上移，否则资金会用脚投票（撤出储蓄与债券，转向黄金、房产、股票、海外资产）。

## 二、机制：为什么利率会被抬起来

"投资者要求更高的名义收益率"不是谈判，而是**市场定价行为**。完整链条：

```
通胀预期 ↑
  → 名义利率不变时, 实际利率 = 名义 − 通胀 变成负数（确定亏损）
    → 投资者撤资（不买新债, 卖出存量债）
      → 债券价格 ↓, 收益率被动 ↑
      → 借款人（政府/企业）必须融资, 别无选择, 接受更高利率
        → 名义利率上升至实际利率恢复合理的水平
```

关键点：
1. **"要求" = 用脚投票**：投资者不买 → 资金供给减少 → 利率（资金价格）上升。
2. **"同意" = 借款人必须融资**：政府发债补赤字、企业融资扩周转，价格再高也得借。
3. **成交于均衡点**：边际投资者觉得补偿够了（实际收益恢复），借款人也借到了钱——没人"被说服"，是价格调整到双方都能接受。

## 三、存量债券如何跌价（二级市场）

存量债券是**固定利率合同**。新债利率升高后，旧债的低票息显得不值钱 → 价格下跌，直到新买家持有到期的收益率（YTM）接近新市场水平。

### 3.1 例：面值 100、票息 2% 的 3 年期老债，以 94 元买入

**现金流**：第 1 年末 +2，第 2 年末 +2，第 3 年末 +102。

**YTM 定义**：找到一个折现率 r，使现金流现值之和等于买入价 94：

```
2/(1+r) + 2/(1+r)² + 102/(1+r)³ = 94
```

**试算逼近**：

| 试 r | 现值合计 | 判定 |
|---|---|---|
| 4.0% | 2/1.04 + 2/1.04² + 102/1.04³ = 94.447 | 高于 94 → r 取低了 |
| 4.2% | 2/1.042 + 2/1.042² + 102/1.042³ = 93.916 | 略低于 94 → r 略高 |

插值：r ≈ 4% + (94.447−94)/(94.447−93.916) × 0.2% ≈ **4.17%**

**精确验证（r = 4.169%）**：

```
2/(1.04169)     = 1.919956
2/(1.04169)²    = 1.843116
102/(1.04169)³  = 90.236927
合计            = 94.000000  ✓
```

**收益拆解**：

| 收益来源 | 计算 | 年化 |
|---|---|---|
| 票息收益 | 每年 2/94 | 2.128% |
| 资本利得 | (100−94)/94 = 6.383%，摊 3 年 | ≈ 2.084% |

≈ 4.13% + 复利效应 ≈ **4.169%**。

票息只有 2%，但 6 元折价买入把实际回报抬到 4.17%，接近新发债市场水平——这就是"利率升 → 存量债价格跌 → 跌到 YTM 接近新市场利率为止"的完整机制。**剩余期限越长，需要跌的折价越大。**

## 四、一级市场：新债票息如何定（以 3 年期国债拍卖为例）

**核心：先定收益率，再反推票息，最后微调价格。** 财政部不"定"票息，市场竞标"定"收益率：

```
① 竞标 → 市场报出愿意接受的收益率（如通胀预期 5% + 实际利率需求 → 4.5%）
② 定票息 → 取最接近收益率的标准步长整数值（0.25% / 0.125% 一档）
③ 算价格 → 票息折现 + 面值折现，得出发行价（平价 / 溢价 / 折价）
```

票息必须落在标准步长上——存量债券利息要标准化，方便交易与拆零；每只债一个怪异票息会摧毁二级市场流动性。

### 4.1 四种情形（面值 100、3 年期）

| 竞标收益率 | 可取票息 | 发行价 = Σ票息折现 + 面值折现 | 结果 |
|---|---|---|---|
| 正好 4.5% | 4.5% | 4.5/1.045 + 4.5/1.045² + 104.5/1.045³ = **100.00** | 平价发行 |
| 4.6% | 4.5% | 4.5/1.046 + 4.5/1.046² + 104.5/1.046³ = **99.73** | 折价 0.27 |
| 4.4% | 4.5% | 4.5/1.044 + 4.5/1.044² + 104.5/1.044³ = **100.28** | 溢价 0.28 |
| 4.6% | 4.75%（跳上档） | 4.75/1.046 + 4.75/1.046² + 104.75/1.046³ = **100.41** | 溢价 0.41 |

**结论：票息定多少不重要，价格自动找平。** 无论票息取哪档，买家实际到手的收益率都等于竞标收益率——与三节"94 元折价买入 → YTM 4.17%"是同一套现值逻辑，只是方向反过来。

### 4.2 通胀如何传导到新债票息

```
通胀预期 5% 上来
  → 投资者要求实际回报补偿（害怕购买力缩水）
    → 拍卖竞标报出高收益率 4.5%
      → 财政部取票息 4.5%（平价发行）
        → 二级市场老债（2% 票息）价格下跌, YTM 被迫跟上 4.5%
```

**一级市场和二级市场是同一块黑板**：
- 一级（新拍卖）：竞标直接定收益率 → 反推票息
- 二级（存量交易）：价格浮动 → 隐含 YTM 向新债收益率收敛

## 五、误区澄清

1. **"新债票息 4.5%" ≠ 投资者赚 4.5% 名义回报**。实际回报 ≈ 4.5% − 通胀 5% = −0.5%。通胀未消前，新债买家的真实购买力仍缩水。票息抬升只是把亏损从"赖账式暴亏"变成"明码标价的小亏"，防止资金全部出逃。
2. **定价的是预测通胀，不是已发生的通胀**。所以央行管理通胀预期至关重要——预期失控 → 名义利率被抬上天 → 存量债务成本暴增。
3. **日本的反例**：长期通缩（负通胀）时，实际利率 = 名义 − (−1%) = 名义 + 1%，所以 0% 名义利率仍有人买（见 [[concepts/负利率]]）。

## 六、现实例证

- **2022 年美国通胀飙升** → 美联储加息 → 10 年期美债收益率从 1.5% 冲至 4%+。
- **拉美高通胀国家**（见 [[concepts/恶性通胀]]、[[concepts/魏玛恶性通胀]]）：名义利率常年 10%+，因预期通胀极高。
