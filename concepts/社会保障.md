# 社会保障

> 社会的"安全网"与财政的"重担"——制度设计决定可持续性

## 一、定义

**社会保障**（Social Security）指国家通过立法建立的社会保险、社会救助、社会福利等制度的总称，为公民在**养老、医疗、失业、工伤、生育**等风险发生时提供基本保障。

其功能包括：

| 功能 | 说明 |
|------|------|
| **风险分散** | 以社会保险方式分散个人风险 |
| **收入再分配** | 转移支付性质的兜底保障（参见 [[收入分配]]） |
| **社会稳定** | 缓解贫困与阶层矛盾 |
| **需求管理** | 降低预防性储蓄，促进消费 |

---

## 二、制度构成与演进

### 2.1 中国社会保障体系

```
社会保险（五险）：养老、医疗、失业、工伤、生育
       ↓
社会救助：低保、特困供养、临时救助
       ↓
社会福利：养老院、儿童福利等
       ↓
补充保障：企业年金、职业年金、个人养老金
```

### 2.2 发展脉络

```
1950s-1980s：单位保障 / 国家保险（城镇）、集体保障（农村）
       ↓
1990s：社会保险制度改革，统账结合
       ↓
2000s：社保覆盖面扩大，全民参保
       ↓
当前：全国统筹、多层次体系、应对老龄化
```

### 2.3 城乡二元结构的打破

中国社会保障长期存在**城乡分割**与**制度碎片化**：职工与居民两套体系，待遇差距大。改革方向是**城乡统筹、全国统筹**，配合 [[城镇化]] 进程中流动人口的社保转移接续。

---

## 三、机制与核心问题

### 3.1 养老保险的运行机制

```
现收现付制 + 个人账户（部分积累）
       ↓
当前缴费者供养当前退休者
       ↓
人口老龄化 → 缴费人数相对减少、领取人数增加
       ↓
收支缺口扩大，财政需兜底
```

### 3.2 人口结构对社保的冲击

- 劳动年龄人口减少 → 缴费基数收缩
- 老年人口增加 → 待遇支出膨胀
- 抚养比上升 → 制度可持续性承压

> 参见 [[人口结构]]：老龄化是社会保障体系面临的最根本长期约束。

### 3.3 筹资模式比较

| 模式 | 代表 | 特点 |
|------|------|------|
| 现收现付制 | 部分欧洲国家 | 代际转移，易受老龄化冲击 |
| 基金积累制 | 部分拉美、东亚国家 | 个人储蓄属性，受资本市场影响 |
| 混合模式 | 中国统账结合 | 兼顾互助与积累 |

## 四、关键举措与改革方向

### 4.1 应对老龄化的措施

1. **渐进式延迟退休** — 增加缴费、减少领取年限
2. **养老保险全国统筹** — 平衡地区收支差异
3. **划转国有资本充实社保基金** — 多渠道补充资金
4. **发展第三支柱** — 个人养老金制度，构建多层次养老保障
5. **生育支持配套** — 降低抚养成本（参见 [[人口结构]]）

### 4.2 医疗保障

- 医保基金收支平衡压力上升
- 集采控费、支付方式改革（DRG/DIP）控费增效
- 大病保险与医疗救助衔接，防范因病致贫

### 4.3 财政可持续性

社保支出是财政支出的重要组成部分，其增长快于财政总收入增长。社保基金的可持续性直接关系到 **财政可持续性**，与 [[财税改革]] 紧密相关。

## 五、国际比较与启示

| 经济体 | 制度特点 | 面临的挑战 |
|--------|----------|-----------|
| **日本** | 国民皆保险、厚生年金与国民年金 | 老龄化最深，财政负担沉重（参见 [[日本财政扩张担忧]]） |
| **英国** | 国家养老金 + 职业年金 | 政府养老金水平有限，私人储蓄不足（[[英国养老金制度]]、[[英国养老金危机]]） |
| **德国** | 社会保险主导的莱茵模式 | 缴费率上升压力 |
| **美国** | 社会保障税（OASDI）+ 401k | 信托基金预计耗尽风险 |

> 各国共性挑战：**人口老龄化 + 低利率环境**下，养老金的投资回报与财政补贴均承压。

## 六、影响与评价

### 6.1 积极意义

- 保障基本民生，是 [[收入分配]] 再分配的核心工具
- 降低预防性储蓄，支持消费与内需
- 为 [[城镇化]] 中人口流动提供制度保障

### 6.2 挑战与风险

| 挑战 | 说明 |
|------|------|
| 收支缺口 | 老龄化使基金收支长期承压 |
| 制度碎片化 | 城乡、地区、群体间待遇差距 |
| 财政绑定 | 社保缺口最终由财政兜底 |
| 激励问题 | 缴费与待遇设计影响参保积极性 |
