# 银行风险

> 银行的本质是经营风险 — 风险识别与资本缓冲决定一家银行的生死

## 一、概述

### 1.1 定义

**银行风险**指银行在经营活动中因不确定性而遭受损失的可能性。银行以**期限转换、流动性转换和信用中介**为核心功能（吸收存款、发放贷款），这一商业模式天然使其暴露于多维风险之中（见 [[货币创造]]、[[期限错配]]）。

### 1.2 银行风险的特殊性

- **高杠杆**：银行的资本占总资产比例通常很低，少量资产损失即可侵蚀全部资本；
- **挤兑敏感**：存款随时可提取、资产难以短期变现，信任一旦动摇可能引发挤兑（见 [[银行挤兑]]）；
- **系统性关联**：银行通过同业、支付与信贷网络相互关联，单家风险可能传染为系统性风险（见 [[系统性风险]]）；
- **政策与公共性**：银行关系支付体系、信贷供给与金融稳定，其风险外溢具有公共性（见 [[金融稳定]]）。

### 1.3 风险是业务的另一面

银行并不以"消除风险"为目标，而是以**识别、定价、承担与缓冲**风险为业务。风险管理的本质是让银行在承担风险的同时，保有足够的资本与流动性以吸收意外损失。

---

## 二、主要风险类型

### 2.1 信用风险

**信用风险**是银行最核心的风险，指借款人或交易对手违约导致损失的风险：

- 集中于贷款业务，也存在于债券投资、同业往来与表外信用承诺；
- 违约概率、违约损失率与风险暴露共同决定预期损失；
- 信用风险随经济周期波动，在经济下行期集中暴露（见 [[信用风险]]）。

### 2.2 市场风险

**市场风险**指利率、汇率、股价、商品价格等市场因子不利变动导致的损失风险（见 [[市场风险]]）：

- 利率风险是银行的固有风险：资产负债期限错配使净利息收入与资本价值随利率波动（见 [[利率风险]]、[[久期]]）；
- 交易账户的债券、外汇、衍生品持仓直接暴露于市场波动（见 [[市场风险与VaR模型]]）。

### 2.3 流动性风险

**流动性风险**指银行无法以合理成本及时获得充足资金以履行到期义务的风险：

```
资产端：贷款难以快速变现、资产价格随抛售下跌
负债端：存款流失、同业融资渠道收紧
        ↓
流动性枯竭 → 被迫贱卖资产 → 螺旋恶化
```

流动性风险往往是挤兑与银行倒闭的直接触发点（见 [[流动性风险]]、[[2023年SVB危机]]、[[2020年3月流动性危机]]）。

### 2.4 操作风险

**操作风险**指因内部流程、人员、系统或外部事件导致的损失风险（见 [[操作风险]]、[[操作风险深度]]）：

- 欺诈、差错、IT 故障、模型错误、外包失败等；
- 巴塞尔协议将操作风险纳入资本监管框架。

### 2.5 其他重要风险

| 风险 | 说明 |
|------|------|
| **集中度风险** | 授信集中于单一客户、行业或地区（见 [[集中度风险]]） |
| **声誉风险** | 负面事件侵蚀客户信任，间接引发资金流失 |
| **国别/主权风险** | 跨国敞口的地缘与主权违约风险 |
| **模型与合规风险** | 模型失效、监管违规导致损失 |
| **系统性风险** | 个体风险在体系内放大传染（见 [[系统性风险]]） |

## 三、风险管理机制

### 3.1 三道防线

```
第一道防线：业务部门（承担并管理风险）
第二道防线：风险管理/合规部门（识别、度量、监控）
第三道防线：内部审计（独立验证）
```

风险管理强调**独立性**：风险度量与业务考核分离，防止"以业绩换风险"。

### 3.2 资本与流动性缓冲

| 工具 | 作用 |
|------|------|
| **资本充足率** | 吸收非预期损失的资本缓冲（见 [[资本充足率]]） |
| **拨备** | 覆盖预期损失 |
| **流动性覆盖率（LCR）** | 确保优质流动性资产覆盖短期净流出（见 [[LCR流动性覆盖率]]） |
| **净稳定资金比率（NSFR）** | 确保负债结构匹配资产久期（见 [[净稳定资金比率]]） |
| **压力测试** | 在极端情景下检验资本与流动性韧性（见 [[压力测试]]） |

### 3.3 监管框架

- **[[2026-04-29-巴塞尔协议]]**：确立资本计量、杠杆率与流动性监管的国际标准（见 [[巴塞尔协议III]]）；
- **宏观审慎**：[[逆周期资本缓冲]]、系统重要性银行附加资本，抑制系统性风险累积；
- **微观审慎**：日常监管、现场检查与早期纠正措施（见 [[银行监管]]）；
- **存款保险**：保护小额存款人、阻断挤兑自我实现（见 [[存款保险]]）；
- **最后贷款人**：央行在流动性危机中提供应急流动性支持（见 [[最后贷款人]]）。

## 四、银行风险的现实案例

| 案例 | 风险类型 | 教训 |
|------|----------|------|
| **2008 全球金融危机** | 信用 + 流动性 + 系统性 | 影子银行与杠杆失控的传染（见 [[2008全球金融危机]]、[[影子银行]]） |
| **2023 年 SVB 危机** | 利率 + 流动性 | 久期错配与储户结构单一（见 [[2023年SVB危机]]） |
| **1998 年 [[长期资本管理公司]] 危机** | 市场 + [[杠杆]] | 高杠杆策略的尾部风险（见 [[1998年LTCM危机]]） |
| **雷曼兄弟倒闭** | 流动性 + 系统性 | 大而不能倒与风险传染（见 [[雷曼兄弟]]） |

历史反复表明：**风险在繁荣期累积、在转折点集中暴露**，稳健的资本与流动性缓冲是穿越周期的前提。

## 五、应用与局限

### 5.1 风险管理的前沿问题

- **模型风险**：VaR 等模型对尾部风险估计不足，极端情景需靠压力测试补充（见 [[市场风险与VaR模型]]）；
- **监管套利**：银行将业务转移至监管较弱的表外与影子体系，削弱监管有效性（见 [[监管套利]]、[[影子银行]]）；
- **道德风险**：存款保险与"大而不能倒"可能弱化市场约束，诱导过度冒险（见 [[道德风险与委托代理]]）；
- **气候与地缘风险**：转型风险、供应链风险与制裁风险成为新的风险维度（见 [[地缘政治对抗]]）。

### 5.2 局限与平衡

- 过度监管会增加合规成本、压缩信用供给，需在**安全**与**效率**之间权衡；
- 风险管理难以完全消除不确定性，尾部事件（黑天鹅）始终存在；
- 银行风险的最终承担者是存款人、股东与纳税人，风险偏好的校准本质上是一个治理与监管问题。
