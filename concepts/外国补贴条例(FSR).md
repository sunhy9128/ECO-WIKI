# 外国补贴条例(FSR)

> 欧盟首次建立外国补贴审查制度 — 以"公平竞争"之名重塑跨国投资与公共采购规则

## 一、定义与概述

**《外国补贴条例》**（Foreign Subsidies Regulation，简称 FSR）是欧盟为应对外国政府补贴扭曲欧盟内部市场而设立的审查制度，于 2023 年生效。FSR 授权欧盟委员会对在欧盟从事**并购交易**、**公共采购投标**及**其他市场行为**的企业进行外国补贴审查，若认定其接受的外国补贴扭曲了市场竞争，可附加救济措施甚至禁止交易。它填补了欧盟在国际补贴监管领域的制度空白，被普遍视为针对国家补贴体系、尤其是对华经贸关系的重点工具。

### 1.1 核心定位

| 维度 | 内容 |
|------|------|
| **性质** | 欧盟外国补贴审查制度（首次建立） |
| **监管对象** | 接受外国政府补贴并在欧盟运营的企业 |
| **适用场景** | 并购、公共采购、其他市场行为 |
| **审查主体** | 欧盟委员会 |
| **处罚手段** | 附加条件、救济措施、禁止交易 |

### 1.2 与相关概念的关系

- [[反补贴]]：传统贸易救济手段的制度延伸
- [[欧盟]]：立法主体
- [[欧盟委员会]]：审查与执法机构
- [[供应链强制多元化新规]] / [[数字服务法(DSA)]]：欧盟对华经济安全工具组合

## 二、背景

### 2.1 制度空白

欧盟原有反补贴规则主要针对**进口商品**（反补贴税），但对外国政府直接补贴**在欧盟投资经营的企业**缺乏系统监管。随着外资在欧盟并购与公共采购中的活跃，欧盟认为存在补贴扭曲竞争的制度漏洞，FSR 旨在填补这一空白。

### 2.2 对华背景

中国企业在欧盟的并购与投资活跃，且国家补贴体系与欧盟市场规则存在差异，使 FSR 被高度关注为针对中国的审查工具。在 2026 年 5 月欧委会敲定的对华贸易围堵方案中，FSR 被列为可主动运用的工具之一（详见 [[欧盟要与中国打贸易战？]]）。

## 三、机制与作用

### 3.1 审查机制

```
识别外国补贴（财务资助 + 受益企业）
       ↓
达到申报门槛 → 强制申报
       ↓
初步审查（认定扭曲市场竞争）
       ↓
深入调查（评估救济措施）
       ↓
附加条件 / 剥离 / 禁止交易
```

### 3.2 核心条款

| 条款 | 内容 |
|------|------|
| **申报门槛** | 并购与公共采购达到一定规模须申报 |
| **补贴定义** | 外国政府提供的财务资助，使企业获益 |
| **扭曲认定** | 从补贴金额、市场地位、行业环境等综合评估 |
| **依职权调查** | 未达门槛但涉嫌扭曲的，可主动调查 |
| **救济措施** | 承诺、行为性救济、结构性救济 |
| **处罚** | 违反申报义务可罚款并禁止交易 |

### 3.3 主要作用

- 填补外国补贴监管的制度空白
- 强化欧盟在跨国并购与公共采购中的谈判地位
- 提高外资（尤其补贴依赖型企业）在欧经营的不确定性
- 构成欧盟产业政策与经济安全战略的执法抓手

## 四、关键事件与数据

### 4.1 立法进程

- 2020 年 6 月：欧盟委员会发布白皮书，启动外国补贴议题
- 2023 年：FSR 正式生效，分阶段实施
- 并购与公共采购申报义务相继落地
- 欧盟委员会逐步启动依职权调查，执法案例不断积累

### 4.2 对华应用背景

- 中资企业在欧并购、公共采购与绿地投资面临更严格审查
- 在贸易摩擦背景下，FSR 与反补贴税、保障措施等工具叠加（见 [[欧盟对华贸易战]]）
- 审查范围覆盖新能源、高铁、通信设备等中国优势行业

---

## 五、影响

### 5.1 对跨国投资的影响

- 外国企业在欧并购与公共采购的合规成本与不确定性上升
- 补贴密集型企业可能被迫剥离或调整交易结构
- 全球投资流向出现"规避欧盟审查"的再配置压力

### 5.2 对中国企业的影响

- 在欧投资与市场准入面临更强的制度性约束
- 国家补贴支持的项目可能成为审查焦点
- 倒逼企业调整投资模式与补贴依赖结构

### 5.3 对欧盟与全球规则的影响

- 欧盟在全球率先建立外国补贴审查范式，可能引发模仿与扩散
- 加剧主要经济体在补贴规则上的制度竞争
- 对自由贸易与投资便利化形成新的制度性摩擦
