# 本币贬值

> 本币贬值是一把双刃剑：既可能刺激出口、改善贸易平衡，也可能推升进口成本、加重外债负担。对于高外债、依赖进口的新兴市场而言，贬值往往不是"竞争优势"而是"危机触发器"。

## 一、定义

**本币贬值**（Currency Depreciation）指一国货币相对于其他货币（通常以美元为参照）的汇率下降，即同样数量的本币能兑换的外币减少，或购买等额外币需要支付更多本币。它是与[[本币升值]]相对的汇率变动方向，可由市场供求自发驱动，也可由央行主动调整或在外汇压力下被迫发生。

## 二、背景与成因

### 2.1 贬值的主要驱动因素

| 成因 | 传导逻辑 |
|------|---------|
| **贸易逆差** | 进口大于出口，外汇需求大于供给，本币承压 |
| **资本外流** | 利差收窄、风险偏好下降，资金流出推低本币 |
| **通胀差异** | 本国通胀高于贸易伙伴，购买力平价下本币趋贬 |
| **美元走强** | 美联储紧缩、美元指数上行，非美货币普遍承压 |
| **地缘与避险** | 风险事件触发资金撤出，本币遭抛售 |
| **政策调整** | 央行主动贬值以刺激出口或应对压力 |

### 2.2 贬值类型

- **主动贬值**：为提升出口竞争力、缓解通缩而主动下调汇率（如广场协议前后部分国家，或日韩汇率管理中的干预）。
- **被动/无序贬值**：因资本外流、外储不足而被迫贬值，往往伴随危机（如 1997 亚洲、2014 俄罗斯、2018 土耳其）。

## 三、机制与传导路径

### 3.1 贬值的经济传导

```
本币贬值
   ├─→ 出口商品外币价下降 → 出口量上升（J曲线效应）
   ├─→ 进口商品本币价上升 → 输入型通胀
   ├─→ 外债（外币计价）本币负担加重 → 偿债压力
   ├─→ 资产价格（以外币衡量的）缩水 → 资本外逃
   └─→ 央行动用外储干预 → 外储消耗 → 贬值预期自我强化
```

### 3.2 关键概念

- **J 曲线效应**：贬值初期贸易差额可能恶化（进口涨价快于出口放量），随后才逐步改善。
- **贬值-通胀螺旋**：贬值→进口成本上升→通胀→货币进一步贬值，新兴市场危机中常见。
- **货币错配**：本国企业/政府债务以美元计价而收入以本币计价时，贬值直接放大偿债负担，是新兴市场脆弱性的核心来源。

## 四、关键数据与案例

- **1997 亚洲金融危机**：泰铢等货币放弃钉住后大幅贬值，外债负担与资本外逃相互强化，引发区域性危机（参见[[1997亚洲金融危机]]）。
- **1998 俄罗斯卢布危机**：卢布大幅贬值与债务违约并存，政府被迫违约并重组，贬值成为危机全面爆发的信号（参见[[1998 俄罗斯卢布危机]]）。
- **2014-2015 俄罗斯卢布危机**：油价暴跌与制裁叠加，卢布对美元汇率腰斩式下跌，央行大幅加息应对（参见[[2014-2015 俄罗斯卢布危机]]）。
- **2018-2019 土耳其、阿根廷**：高通胀、高外债经济体在美联储紧缩下本币大幅贬值，恶性通胀与资本管制轮番出现。
- **日韩经验**：日元、韩元在不同时期的贬值对出口企业盈利与股市形成支撑，"股牛汇弱"现象在出口导向型经济体中屡见不鲜（参见[[股牛汇弱]]、[[出口导向型经济体]]）。

## 五、后果与影响

### 5.1 有利面

- **出口竞争力**：出口商品在国际市场更便宜，利好出口导向型企业的营收与盈利。
- **贸易再平衡**：进口减少、出口增加，有助于收窄贸易逆差。
- **汇率缓冲**：在浮动汇率下，贬值是吸收外部冲击（如美元走强）的自动稳定器。

### 5.2 不利面

- **输入型通胀**：进口能源、粮食、中间品成本上升，推升国内物价（参见[[输入型通胀]]）。
- **外债负担加重**：美元计价的债务在贬值后本币价值骤增，偿债与再融资压力陡增。
- **资本外流**：贬值预期引发居民与企业换汇避险，形成"资本外流-贬值"螺旋。
- **信心冲击**：无序贬值通常伴随股市下跌、资产价格缩水与主权信用受损。

### 5.3 对股汇关系

- 贬值对股市的影响取决于经济体类型与驱动因素：出口导向型经济体可能"股牛汇弱"，进口依赖与高外债经济体则往往"股汇双杀"（参见[[股汇关系]]）。
