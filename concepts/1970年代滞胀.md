# 1970年代滞胀

> 经济增长停滞与高通胀并存 — 打破凯恩斯主义共识的十年

## 一、定义

**滞胀**（Stagflation）指**经济停滞（零增长或负增长）与高通胀并存**的经济状态，兼有高失业率，传统宏观经济学曾认为这三种现象不会同时出现。

1970 年代成为滞胀的经典样本：[[美国]]、英国等主要经济体在石油供给冲击、布雷顿森林体系瓦解与货币政策失当的共同作用下，陷入"低增长 + 高通胀 + 高失业"的组合。这一现象直接动摇了以[[菲利普斯曲线]]为基础的需求管理框架。

### 1.1 滞胀与一般通胀的区别

| 维度 | 一般通胀 | 滞胀 |
|------|---------|------|
| **[[经济增长]]** | 通常过热 | 停滞或衰退 |
| **失业率** | 较低 | 高企 |
| **成因** | 总需求过热 | 供给冲击 + 需求政策失衡 |
| **政策困境** | 紧缩即可治理 | 紧缩治通胀但加剧衰退 |
| **典型时期** | 繁荣周期 | 1970 年代 |

---

## 二、历史背景与起因

### 2.1 结构性背景

| 背景因素 | 说明 |
|---------|------|
| **布雷顿森林体系瓦解** | 1971-1973 年美元与黄金脱钩，固定汇率转向浮动，全球货币纪律松动 |
| **第一次石油危机（1973）** | 石油输出国组织减产禁运，油价大幅上涨，直接推高生产成本 |
| **第二次石油危机（1979）** | 伊朗革命引发新一轮油价上涨，二次冲击全球 |
| **越南战争财政扩张** | 美国战费开支与"大社会"福利计划并存，财政赤字扩大 |
| **工资-物价螺旋** | 工会推动工资追赶物价，企业将成本转嫁，形成螺旋（参见 [[价格传导非对称性]]） |
| **价格管制失效** | 尼克松政府价格管制短暂压制物价，解除后报复性反弹 |

### 2.2 供给冲击的核心作用

1970 年代滞胀的独特之处在于**成因以供给端为主**：

```
油价与大宗商品价格上涨
       ↓
企业生产成本上升
       ↓
供给曲线左移（产出下降）
       ↓
物价上涨 + 产出下降 = 滞胀
       ↓
工资追赶 → 成本再度上升 → 通胀预期固化
```

传统[[凯恩斯主义]]的需求管理只能解决"需求不足"或"需求过热"单一问题，面对供给冲击左右为难：刺激需求会加剧通胀，紧缩需求会加深衰退。

## 三、机制与传导路径

### 3.1 通胀预期与菲利普斯曲线失效

短期菲利普斯曲线描述通胀与失业的负相关关系；1970 年代的经验表明，**长期中通胀与失业并不存在此消彼长**。当工人与企业的通胀预期上升并固化后，通胀预期本身成为物价上涨的推动力，形成"预期自我实现"的循环。

### 3.2 货币政策的失误

美联储主席伯恩斯时代（1970-1978）在政治压力下倾向于**温和紧缩**，实际利率长期偏低，货币增速偏快，未能及时打破通胀预期。直到 1979 年[[沃尔克]]出任美联储主席，才转向激进加息。

### 3.3 政策两难

| 选择 | 效果 | 代价 |
|------|------|------|
| 紧缩（控通胀） | 通胀回落 | 失业上升、衰退加深 |
| 宽松（保增长） | 增长改善 | 通胀进一步恶化 |
| 价格管制（行政干预） | 短期压价 | 扭曲供给、反弹 |

## 四、关键数据与案例

> 说明：以下数字为历史事实的概括性表述，具体精确值存在多种口径。

| 案例 | 表现 | 政策应对 |
|------|------|---------|
| **美国（1973-1975）** | 通胀由个位数升至两位数，GDP 出现负增长季度 | 尼克松价格管制 → 福特"WIN"运动 → 沃尔克加息 |
| **英国（1973-1975）** | 通胀一度超过 20%，经济陷入衰退 | 工资政策与财政紧缩反复 |
| **[[日本]]（1973-1974）** | 石油危机冲击下通胀飙升、增长骤停 | 转向紧货币，随后较快恢复 |
| **沃尔克冲击（1979-1982）** | 联邦基金利率大幅抬升至历史高位 | 以深度衰退换取通胀预期扭转 |

### 4.1 沃尔克式的治理路径

```
1979 沃尔克上任
       ↓
大幅加息（联邦基金利率抬升）
       ↓
经济深度衰退、失业率上升
       ↓
通胀预期被打破、通胀趋势性回落
       ↓
为 1980 年代低通胀、长扩张奠定基础
```

## 五、后果与教训

### 5.1 直接后果

- **经济停滞十年**：主要经济体增长放缓，失业率在 1980 年代初达到高位
- **通胀预期固化**：工资-物价螺旋使治理成本显著上升
- **政策范式转换**：凯恩斯主义需求管理受质疑，货币主义、理性预期理论兴起
- **央行独立性诉求**：政治干预货币政策的弊端暴露，推动央行独立与通胀目标制

### 5.2 关键教训

| 教训 | 内容 |
|------|------|
| **[[[[美联储独立性]]]]** | 政治压力下宽松，是通胀失控的重要原因 |
| **预期管理** | 通胀预期一旦固化，治理成本成倍上升 |
| **供给端视角** | 宏观政策需同时关注供给冲击，不能只看总需求 |
| **信誉比速度重要** | 沃尔克的成功在于以可信承诺打破预期 |
| **适度容忍短期衰退** | 治理通胀往往需要付出短期增长代价 |

> 参见 [[菲利普斯曲线]]、[[滞胀]]、[[第一次石油危机]]、[[沃尔克]] 了解关联机制。

## 六、对本库其它主题的关联

1970 年代滞胀是理解后续多次金融事件的重要背景：

- **[[1982 拉美债务危机]]**：沃尔克加息治通胀，直接抽紧全球美元流动性，触发拉美债务崩溃
- **[[美元周期]]**：美元大幅升值与加息是新兴市场危机的周期源头
- **[[魏玛恶性通胀]]**：同属通胀主题，但成因与烈度不同
- **[[恶性通胀]]**：滞胀若失控可滑向恶性通胀
- **[[量化宽松]]**：2008 年后央行面对通缩风险的政策回应，与 1970 年代方向相反
- **[[沃尔克规则]]**：以沃尔克命名的金融监管规则，是后危机时代立法
