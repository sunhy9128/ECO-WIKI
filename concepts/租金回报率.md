# 租金回报率

> 衡量"买房收租划不划算"的核心指标 — 与房价收入比共同构成评估房产投资价值的两把尺子

## 一、定义

**租金回报率**（Rental Yield，又称租金收益率）指**年租金收入与房屋总价之比**，反映持有房产所获租金收益的年度回报水平。

```
租金回报率 = 年租金收入 ÷ 房屋总价（或购入成本）× 100%
```

### 1.1 常用口径

| 口径 | 计算方式 | 说明 |
|------|---------|------|
| **毛租金回报率** | 年租金收入 ÷ 房价 | 未扣持有成本，用于横向比较 |
| **净租金回报率** |（年租金 − 税费、物业、维修等）÷ 房价 | 更接近实际收益 |
| **租售比** | 房屋总价 ÷ 月租金 | 即"多少个月租金收回房价"，为回报率的倒数 |

### 1.2 与房价收入比的关系

[[房价收入比]]衡量"买房难不难"（房价与收入之比），租金回报率衡量"买房划不划算"（租金与房价之比）。两者共同刻画房地产的**估值水平**：房价收入比高、租金回报率低，通常意味着房价相对租金与居民购买力偏贵。

## 二、背景

### 2.1 房地产从"居住品"到"投资品"

在住房市场化改革与城镇化快速推进背景下，房产兼具居住消费与资产投资双重属性。租金回报率因此成为居民在"买房 vs 租房"、"购房 vs 其他资产"之间权衡的关键参数（参见 [[房地产]]、[[城镇化]]）。

### 2.2 低利率环境下的资产荒

当无风险利率下行、理财收益走低时，投资者开始用租金回报率与[[国债收益率曲线]]、存款利率等比较，租金回报率的相对吸引力上升，成为资产配置的重要参考。

## 三、机制与作用

### 3.1 租金回报率的决定因素

| 因素 | 影响 |
|------|------|
| **房价水平** | 房价越高，同等租金下回报率越低 |
| **租金水平** | 由当地就业、人口与收入决定（参见 [[收入分配]]） |
| **持有成本** | 税费、物业费、空置率、维修成本压低净回报 |
| **利率环境** | 房贷利率与租金回报率的相对关系决定购房/租房选择 |
| **政策因素** | [[房产税]]、租赁住房政策影响持有收益与租金供给 |

### 3.2 作为估值锚

- **与国际对比**：成熟市场租金回报率往往与房贷利率、长期国债收益率形成合理利差；当租金回报率显著低于房贷利率时，纯"以租养贷"难以成立，房价依赖升值预期支撑
- **泡沫警示**：租金回报率持续走低、租售比过高，是[[泡沫经济]]的典型信号之一
- **政策标尺**：租赁住房、保障性住房建设常以租金回报率为项目可持续性评估依据

## 四、关键事件与数据（概括性）

- 中国一线城市住宅租金回报率长期处于偏低区间，明显低于多数国际大都市
- 部分三四线城市与商办物业、小户型回报率相对较高，但伴随空置与流动性风险
- 与国际城市相比，中国大城市租金回报率与无风险利率、房贷利率之间的"倒挂"程度较深，反映房价定价中升值预期权重较大
- 近年租赁市场政策加码、保租房入市，租金涨幅总体温和，回报率提升更多依赖房价企稳

## 五、影响

### 5.1 对微观决策的影响

- **购房者**：以租金回报率判断"以租养贷"可行性，决定加杠杆意愿
- **租房者**：低回报率环境下，长期租房 vs 购房的权衡更复杂
- **机构投资者**：REITs 与长租公寓以租金回报率为估值与定价核心

### 5.2 对宏观的启示

- 租金回报率过低意味着资产价格对利率与预期高度敏感，一旦预期逆转易放大调整（参见 [[硬着陆]]、[[软着陆]]）
- 租金回报率与[[房价收入比]]共同构成评估房地产健康度与[[70城房价]]走势的重要参照
- 对政策而言，稳定租金回报率有赖于"稳房价、促租金、控杠杆"的综合施策
