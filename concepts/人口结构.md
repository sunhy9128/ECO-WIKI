# 人口结构

> 东亚生育率"诅咒"：政府努力，效果微乎其微，钱花了不少，命运改变不了

## 一、定义

**人口结构**（Population Structure）指人口在**年龄、性别、城乡、地区**等维度的构成状况。对[[concepts/中国经济|中国经济]]而言，最核心的是**年龄结构**——劳动年龄人口占比下降、老年人口占比上升的"少子老龄化"趋势。

人口结构是决定**潜在[[concepts/经济增长|经济增长]]率、财政可持续性、消费结构、房地产需求**的长期变量，被称为"最慢的宏观变量、最确定的长期趋势"。

---

## 二、政策背景与演进

### 2.1 人口政策演变

```
1970s：计划生育政策实施
       ↓
2013年：单独二孩
       ↓
2016年：全面二孩
       ↓
2021年：三孩政策及配套支持措施
       ↓
当前：生育支持政策体系 + 渐进式延迟退休
```

### 2.2 核心矛盾

| 维度 | 现状与趋势 |
|------|-----------|
| 生育率 | 总和生育率降至较低水平，跌破人口世代更替水平 |
| 老龄化 | 60 岁及以上老年人口占比持续上升 |
| 劳动力 | 劳动年龄人口总量与占比双降 |
| 抚养比 | 老年抚养比快速攀升 |

---

## 三、机制与影响路径

### 3.1 人口结构影响经济的机制

```
少子化 + 老龄化
       ↓
劳动力供给减少 + 养老负担加重
       ↓
潜在增长率下行 + 财政压力上升 + 需求结构变化
```

### 3.2 对各领域的影响

| 领域 | 影响 |
|------|------|
| **经济增长** | 劳动投入减少，倒逼转向全要素生产率驱动（[[新质生产力]]） |
| **财政社保** | 养老金收支压力加大（[[社会保障]]） |
| **消费** | 老年人口消费倾向低，内需结构变化 |
| **房地产** | 长期需求收缩，[[房地产]] 支撑逻辑弱化 |
| **储蓄投资** | 国民储蓄率可能随老龄化下降 |

## 四、关键举措与数据

### 4.1 生育支持

- 实施三孩生育政策及配套支持措施
- 降低生育、养育、教育成本
- 发展普惠托育服务体系

> 东亚经验表明，政策投入对生育率的提振效果有限：日本、韩国长期推行生育激励，生育率仍持续走低。总和生育率一旦落入较低区间，回升难度极大。

### 4.2 养老金改革

- 逐步提高城乡居民基本养老保险基础养老金
- 养老保险基金收支面临长期压力，需通过全国统筹、财政补贴、国有资本划转等渠道平衡
- 延迟退休与养老金并轨是长期改革方向

### 4.3 延迟退休

> "按照自愿、弹性原则，稳妥有序推进渐进式延迟法定退休年龄改革"

- 渐进式延迟法定退休年龄，缓解劳动力与养老金双重压力
- 2035 年前后中国将进入深度老龄化阶段，老年人口占比显著上升

---

## 五、国际比较与启示

| 经济体 | 应对 | 效果 |
|--------|------|------|
| **日本** | 延迟退休、鼓励女性与老年就业、生育激励 | 老龄化最深，经济长期低迷（参见 [[日本财政扩张担忧]]） |
| **韩国** | 大规模生育补贴 | 生育率全球最低之一 |
| **欧洲** | 移民补充 + 福利改革 | 部分国家通过移民缓解 |

> 东亚社会在文化、就业结构上存在系统性生育抑制因素，单纯财政补贴难以扭转，政策重心转向"优化存量"（延迟退休、提高劳动参与率）与"提高人口质量"（人力资本）。

## 六、影响与评价

### 6.1 对[[domains/宏观经济|宏观经济]]的含义

- 潜在增速中枢下移，需以 [[新质生产力]] 对冲劳动力减少
- 财政可持续性承压，与 [[财税改革]]、[[社会保障]] 改革联动
- 消费结构转向养老、医疗、服务

### 6.2 争议与挑战

| 挑战 | 说明 |
|------|------|
| 生育支持效果有限 | 政策投入大、见效慢 |
| 养老金缺口 | 需多渠道筹资，涉及代际分配 |
| 延迟退休争议 | 涉及就业、身体条件、代际公平 |
| 劳动力老化 | 不仅总量减少，结构也老化 |
