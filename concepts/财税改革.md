# 财税改革

> 开源节流、事权上收中央——央地财政关系重塑的核心议程

## 一、定义

**财税改革**（Fiscal and Tax Reform）指中国围绕**财政收入**（税收与非税收入）、**财政支出**（事权与支出责任划分）以及**预算管理**三大主线，对中央与地方政府之间财政分配关系进行的系统性制度改革。

其核心命题是解决两组失衡：

| 失衡类型 | 表现 |
|----------|------|
| **事权与财权失衡** | 事权下放地方、财权集中于中央，地方"小马拉大车" |
| **收入与支出失衡** | 地方承担大量支出责任，但稳定税源不足，依赖土地财政与非税收入 |

财税改革是理解中国地方政府行为、土地财政、隐性债务等一系列问题的基础性制度背景。

---

## 二、政策背景与演进

### 2.1 历史脉络

```
改革开放前：统收统支（中央集权）
       ↓
1980s：财政包干制（地方包干、放权让利）
       ↓
1994年：分税制改革（财力上收中央）
       ↓
2016年：营改增全面推开（地方主体税种弱化）
       ↓
二十届三中全会：新一轮财税改革（开源节流+事权上收）
```

### 2.2 分税制后的"央地失衡"

1994 年 [[分税制]] 改革扭转了财政包干制下"两个比重"（财政收入占 GDP 比重、中央收入占财政总收入比重）过低的局面，把增值税、消费税等大税种划归中央，但**事权与支出责任仍然大量留在地方**。此后二十余年，地方政府长期依靠：

- **土地财政**：土地出让收入成为地方"第二财政"，一度接近地方本级收入的一半
- **隐性举债**：通过城投平台变相融资，累积 [[地方政府隐性债务]]
- **非税收入**：各种收费、罚没、资源有偿使用收入

这一体制在推动基础设施建设和经济增长的同时，也埋下债务风险、土地依赖、区域分割等结构性问题，构成新一轮财税改革的直接背景。

## 三、央地财政体制的基本机制

### 3.1 收入端：税种划分

| 税种 | 归属 | 说明 |
|------|------|------|
| 增值税 | 中央与地方共享 | 国内增值税按比例分享 |
| 企业所得税 | 中央与地方共享 | 按隶属与比例分享 |
| 个人所得税 | 中央与地方共享 | 按比例分享 |
| 消费税 | 中央独享为主 | 改革方向：征收环节后移并下划地方 |
| 土地相关税费 | 地方为主 | 土地财政的主要制度基础 |
| 契税、房产税等 | 地方税 | 规模有限，难以替代土地出让收入 |

### 3.2 支出端：事权与支出责任

- **中央事权**：国防、外交、全国性重大战略
- **地方事权**：教育、医疗、社保、基建、基层运转等
- **共同事权**：多数领域由中央与地方共同承担，但实际支出责任多落在地方

### 3.3 转移支付体系

中央通过 [[转移支付]]（一般性转移支付 + 专项转移支付）对地方进行财力再平衡。改革方向是**提高一般性转移支付比重、清理压缩专项转移支付**，减少"跑部钱进"和资金碎片化。

## 四、二十届三中全会的主要举措

二十届三中全会将财税改革列为重点改革领域，核心逻辑是"**开源 + 节流 + 事权上收**"。

### 4.1 开源：为地方寻找新税源

1. **消费税征收环节后移并下划地方** — 将部分高价值消费品（高档汽车、化妆品、名表等）的消费税由生产环节征收改为批发零售环节征收，并将收入划归地方，形成地方稳定税源
2. **合并三税为地方附加税** — 将城市维护建设税、教育费附加、地方教育附加合并为统一的地方附加税，简化税制
3. **下放非税收入管理权限** — 国有资源有偿使用收入等由地方自主管理
4. **研究数字经济新业态税收制度** — 针对直播带货等新兴业态的税收征管
5. **优化共享税分享比例** — 适度调整增值税、企业所得税、个人所得税的央地分享比例
6. **扩大专项债券支持范围** — 为地方重大项目提供合规融资渠道

### 4.2 节流：规范与压缩支出

1. **预算全覆盖** — 依托行政权力取得的收入全部纳入政府预算管理，压缩体外循环
2. **提高国企上缴收益比例** — 国有资本经营预算中国企上缴利润比例有较大提升空间，充实财政收入
3. **适当加强中央事权** — 提高中央财政支出比例，减轻地方支出负担
4. **禁止违规要求地方配套** — 规范中央项目对地方配套资金的要求

### 4.3 核心逻辑

> 钱归拢统一管理 → 减少地方隐形支出 → 强化国家重大战略任务和基本民生保障

**央地关系变化对比**：

| 会议 | 导向 |
|------|------|
| 十八届三中全会 | "保持现有央地财力格局总体稳定" |
| 二十届三中全会 | 多方面增加地方收入 + 事权上收中央 |

## 五、关键数据与指标

| 指标 | 概况 |
|------|------|
| 土地出让收入占地方收入比重 | 高峰期接近半数，近年承压回落 |
| 国企上缴利润比例 | 处于较低区间，有提升空间 |
| 专项转移支付规模 | 庞杂，改革方向为清理并转向一般性转移支付 |
| 基层"三保" | 保基本民生、保工资、保运转，财政压力直接体现 |

> 具体数字随年份变化较大，此处只作概括性描述；读者应以财政部年度决算为准。

## 六、影响与评价

### 6.1 积极意义

- 缓解地方对土地财政和隐性举债的依赖，从源头上配合 [[化债]] 进程
- 事权上收中央有助于缩小区域间公共服务差距
- 消费税后移与下划为地方培育长期稳定税源

### 6.2 挑战与风险

- 改革涉及央地利益再分配，推进阻力大、博弈复杂
- 地方税源培育需要时间，短期仍存在收支缺口
- 消费税后移可能推高部分商品终端价格，影响消费
- 与 [[收入分配]] 议题交织：税制调整须兼顾公平

### 6.3 与相关改革的联动

财税改革是连接 [[土地财政]]、[[转移支付]]、[[化债]]、[[社会保障]]、[[收入分配]] 的枢纽性制度：财政收入格局决定公共服务供给能力，也决定再分配工具的空间。
