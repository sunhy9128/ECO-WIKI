# 常用技术指标深度

> 跳出"单个指标看盘"，从指标体系的高度理解 — 趋势、动量、量能、支撑压力四大族的原理、配合与陷阱

## 一、为什么需要"指标体系"视角

单个技术指标都只刻画市场的一个侧面：均线看趋势、RSI 看超买超卖、量比看资金热度。**没有任何单一指标是完备的**，实战中的误用多源于"用趋势指标做震荡、用动量指标猜拐点"。

对常用指标做**分类 + 定位 + 组合**的深度理解，比记住每个指标的参数更重要。

---

## 二、指标四大族与常用代表

| 指标族 | 核心问题 | 常用代表 | 适用行情 |
|--------|---------|---------|---------|
| **趋势类** | 方向是什么？ | MA（均线）、MACD、趋势线 | 有趋势行情 |
| **动量类** | 涨跌有多强/是否过度？ | RSI、KDJ、威廉指标 | 震荡/超买超卖识别 |
| **量能类** | 成交是否配合？ | 量比、OBV、换手率 | 验证一切信号的"地基" |
| **支撑压力类** | 关键价位在哪？ | 布林带、斐波那契、筹码峰 | 区间操作 |

### 2.1 趋势类：MA 与 MACD

- **MA（移动平均线）**：用 N 日均价平滑价格，多空排列（多头排列/空头排列）是最直观的趋势状态。
- **MACD**：MA 思路的升级，通过 EMA 差值的聚散判断趋势强弱与拐点，详见 [[MACD 指标]]。
- **局限**：所有均线类指标都**滞后**，趋势越长的均线越滞后。

### 2.2 动量类：RSI 与 KDJ

- **RSI（相对强弱指数）**：衡量一段时间内涨跌幅的相对强弱，用于超买（数值高）超卖（数值低）判断，参见 [[RSI-指标]]。
- **KDJ（随机指标）**：结合收盘价在近期高低区间的位置与动量，短线灵敏度高。
- **局限**：强趋势中"超买可以更超买"，动量指标单独使用易被趋势碾压。

### 2.3 量能类：量比与 OBV

- **量比**：当前每分钟平均成交量与过去若干日平均水平的比值，衡量放量程度，参见 [[量比]]。
- **OBV（能量潮）**：将成交量按涨跌方向累积，验证价格趋势是否被资金确认，参见 [[成交量分析]]。
- **局限**：量能指标是"验证器"而非"发生器"，放量既可推动上涨也可用于出货。

### 2.4 支撑压力类：布林带与筹码

- **布林带**：以均线为中轨、加减若干倍标准差为上下轨，反映价格的波动区间。
- **筹码分布**：统计不同价位的持仓分布，峰区构成支撑/压力。
- **局限**：支撑压力是"概率区域"而非"精确点位"，强趋势中会连续击穿。

## 三、指标的组合方法论

### 3.1 验证式组合（主 + 验证）

```
趋势指标定方向（如 MACD 是否多头）
       ↓
动量指标找位置（如 RSI 是否超买）
       ↓
量能指标做确认（如放量突破是否成立）
       ↓
支撑压力定目标（如筹码峰/布林上轨）
```

典型框架：**"趋势定多空、位置定买卖、量能定确认、压力定目标"**。

### 3.2 共振与背离

- **共振**：多指标同向（如 MACD 金叉 + 放量 + 突破压力位）→ 信号质量高。
- **背离**：价格与指标方向不一致（如价创新高、MACD 未创新高）→ 预警信号，参见 [[MACD 指标]] 背离部分。

### 3.3 多周期配合

- **日线定方向、分时找买点**：大周期过滤、小周期择时。
- **周线防系统性风险**：周线级别的指标状态决定日线信号的可信度。

## 四、常见误用与陷阱

| 误区 | 说明 |
|------|------|
| **参数万能论** | 默认参数不适合所有品种，过度优化参数反而过拟合 |
| **指标堆砌** | 指标越多越矛盾，应"一主两辅"而非"全家桶" |
| **逆势抄底摸顶** | 用动量指标猜拐点，忽视趋势的力量 |
| **忽略量能** | 无量的技术突破多为假突破 |
| **数据噪声** | 技术指标基于历史价格，无法预测突发事件 |

> **核心提醒**：技术指标是"价格的统计归纳"，不是"价格的因果解释"。它们描述"市场过去和当前的状态"，对未来的推断是**概率性**的。任何指标组合都无法消除市场风险，也无法取代基本面分析与仓位管理。

## 五、与技术分析体系的关系

技术指标只是 [[技术分析]] 的一个子集。完整的看图体系还包括：

- **道氏理论**（趋势的哲学基础）与 [[艾略特波浪理论]]（结构划分）
- **量价关系**（资金与价格的关系）
- **市场微观结构**（委托单、成交与做市机制）

指标应与上述工具、以及 A 股的 [[融资融券]]、[[散户行为]] 等市场特征结合使用，才能提高判断的胜率。

---

## 六、小结

**常用技术指标深度**的核心是"分类认知 + 组合使用 + 知晓局限"：

1. 明确每个指标属于哪一族、回答什么问题；
2. 按"趋势→动量→量能→压力"的逻辑组合，而非堆砌；
3. 承认所有指标的滞后性与概率性，不迷信、不万能化。

技术指标是交易的"仪表盘"，而决定成败的永远是仪表盘背后的人。
