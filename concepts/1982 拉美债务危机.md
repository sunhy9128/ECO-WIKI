# 1982 拉美债务危机

> 石油美元回流滋养的盛宴，以美联储加息收场 — 拉美"失去的十年"

## 一、定义

**1982 年拉美债务危机**指 1980 年代初墨西哥、巴西、阿根廷、委内瑞拉等拉美国家因**无法偿还巨额美元外债**而相继爆发的国际债务危机。危机始于 1982 年 8 月墨西哥宣布暂停偿还外债，随后蔓延至整个拉丁美洲，并波及东欧、非洲等其它债务国。

危机标志着二战后"石油美元回流 → 银团贷款 → 发展中国家举债发展"模式的终结，也开启了拉美长达十余年的"失去的十年"（La Década Perdida）。

---

## 二、历史背景与起因

### 2.1 债权方的流动性注入

1970 年代两次石油危机使产油国积累大量美元盈余，这些"石油美元"通过欧洲美元市场回流到国际银行体系。在贷款需求不足、利率偏低的背景下，欧美商业银行大量向拉美、东欧等发展中经济体发放**主权银团贷款**。

### 2.2 债务方的举债逻辑

| 因素 | 说明 |
|------|------|
| **进口替代工业化** | 拉美各国借外债推进工业化与大型项目 |
| **初级产品出口依赖** | 出口收入依赖原油、咖啡、铜等大宗商品 |
| **负实际利率激励** | 1970 年代通胀高企使实际利率为负，举债看似划算 |
| **浮动利率债务** | 大量贷款以伦敦同业拆借利率为基准，利率风险完全暴露 |
| **短借长投** | 债务期限错配，依赖滚动再融资 |

### 2.3 触发因素

- **沃尔克加息（1979-1982）**：美联储为治理[[1970年代滞胀]]大幅加息，美元利率升至历史高位
- **美元大幅升值**：美元走强使以美元计价的债务实际负担加重
- **大宗商品价格回落**：1980 年代初油价回落、初级产品价格走弱，出口收入下降
- **资本流向逆转**：美国高利率吸引全球资本回流美国，拉美资金净流出

```
沃尔克加息 + 美元走强
       ↓
浮动利率债务利息骤增 + 出口收入下降
       ↓
偿债能力恶化
       ↓
外部融资枯竭、再融资中断
       ↓
墨西哥率先暂停偿债 → 全面危机
```

## 三、机制与传导路径

### 3.1 危机机制

| 环节 | 内容 |
|------|------|
| **利率冲击** | 基准利率上升直接推高浮动利率债务的付息成本 |
| **汇率冲击** | 美元升值 → 本币贬值 → 债务本息的本币成本膨胀 |
| **出口冲击** | 大宗商品价格回落 → 创汇能力下降 |
| **融资冲击** | 银行惜贷 → 展期与再融资冻结 → 违约 |
| **蔓延效应** | 国际银行同时收缩对发展中经济体的贷款 → 区域性传染 |

### 3.2 危机中的自我强化循环

```
偿债压力上升
       ↓
银行减少新贷款、要求加速还款
       ↓
外汇储备下降、进口被压缩
       ↓
经济衰退、进口设备与原料短缺
       ↓
出口能力进一步受损
       ↓
偿债能力进一步恶化
```

## 四、关键数据与案例

> 说明：以下为历史事实的概括性表述。

| 案例 | 时间 | 事件 |
|------|------|------|
| **墨西哥** | 1982.8 | 宣布无力偿还外债，成为危机起点 |
| **巴西** | 1982-1983 | 外债规模居拉美前列，随后寻求债务重组 |
| **阿根廷** | 1982-1983 | 福克兰战争后经济与债务双重困境 |
| **委内瑞拉** | 1983 | 石油价格回落叠加外债压力，被迫调整 |

### 4.1 国际应对

| 阶段 | 方案 | 内容 |
|------|------|------|
| **1982-1985** | IMF 主导的"老办法" | 条件性贷款 + 各国紧缩调整，强调债务国自我修复 |
| **1985** | 贝克计划 | 商业银行新增贷款，换取债务国结构性改革 |
| **1989** | 布雷迪计划 | 债务折价重组、以美元债券置换银行贷款，拉美重回国际资本市场 |

## 五、后果与教训

### 5.1 直接后果

- **失去的十年**：拉美经济在 1980 年代长期停滞，人均收入倒退
- **恶性通胀**：多国为筹措资金超发货币，通胀飙升（如巴西、阿根廷、秘鲁）
- **银行体系受损**：国际大银行（美国、欧洲、日本）因拉美敞口遭受重大损失
- **银行监管加强**：推动国际社会对主权贷款集中度与资本充足率的反思
- **华盛顿共识**：危机后拉美转向私有化、贸易自由化与财政纪律

### 5.2 关键教训

| 教训 | 内容 |
|------|------|
| **外债币种错配风险** | 以美元举债 + 本币收入，汇率波动即致命 |
| **浮动利率风险** | 利率是外债最大的不可控变量 |
| **出口单一化脆弱** | 依赖大宗商品创汇的经济体抗冲击能力弱 |
| **资本流动逆转** | 美元周期切换时，国际资本回流速度远快于流入 |
| **结构调整优于硬撑** | 及时重组比拖延违约代价更小 |
