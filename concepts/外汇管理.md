# 外汇管理

> 外汇管理是汇率稳定、资本流动与货币政策独立性之间的"调节阀"。中国在"经常项目可兑换、资本项目渐进开放"的框架下，以外汇管理为工具管理跨境资金流动与汇率预期，构成其货币政策体系的关键一环。

## 一、定义

**外汇管理**指一国货币当局对外汇收支、买卖、汇兑与跨境转移，以及汇率形成机制所实施的管理与调控。广义的外汇管理涵盖结售汇制度、外汇额度与审批、资本项目管控、外汇储备运用与汇率干预等，其目标通常包括维持汇率稳定、防范跨境资本冲击、保障国际收支平衡与金融安全。

## 二、背景与制度框架

### 2.1 中国外汇管理体制的演进

| 阶段 | 内容 |
|------|------|
| **1979 前** | 高度集中的外汇统收统支体制，外汇由国家统一分配 |
| **1979-1993** | 外汇留成与调剂市场并存，双轨汇率 |
| **1994** | 汇率并轨，实行银行结售汇制，建立全国统一外汇市场 |
| **1996** | 实现经常项目可兑换（接受 IMF 第八条款） |
| **2001 后** | 加入 WTO 后贸易与资本流动扩大，外汇占款成为货币投放重要渠道 |
| **2005** | 汇改参考一篮子货币，转向有管理的浮动 |
| **2015 后** | [[8.11 汇改]]完善中间价机制，加强跨境资金流动宏观审慎管理 |

### 2.2 管理框架的核心原则

- **经常项目可兑换**：与贸易、服务、劳务相关的对外支付可自由购付汇。
- **资本项目渐进开放**：直接投资逐步放开，证券投资与跨境借贷通过合格机构（QDII/QFII、沪港通、深港通等）有序开放。
- **审慎管理**：以"宏观审慎 + 微观合规"双支柱，监测与调节跨境资金流动。

## 三、机制与工具

### 3.1 主要管理工具

| 工具 | 内容 |
|------|------|
| **结售汇制度** | 企业外汇收入按规定结汇，购汇需真实合规背景 |
| **额度与登记管理** | 居民个人购汇限额、企业跨境融资额度与登记 |
| **资本项目管控** | 对外投资、外债、证券投资的准入与额度管理 |
| **汇率管理** | 通过中间价、逆周期因子、市场干预引导汇率预期 |
| **央行干预** | 动用外汇储备进行冲销式/非冲销式干预（参见[[冲销式干预]]） |
| **宏观审慎** | 跨境融资杠杆率、外汇风险准备金等逆周期调节工具 |

### 3.2 传导路径

```
资本流入/流出压力
       ↓
跨境资金流动监测与预警
       ↓
汇率中间价引导 + 外汇市场干预
       ↓
宏观审慎工具（风险准备金、额度调节）
       ↓
汇率保持"有管理的浮动"，避免无序波动
       ↓
货币政策独立性得以维护（配合资本管制）
```

## 四、关键数据与案例

- **外汇储备规模**：中国外汇储备长期位居全球第一，是稳定汇率与应对资本流动冲击的核心"弹药"（参见[[外汇储备]]）。
- **8.11 汇改**：2015 年完善人民币兑美元中间价报价机制，加大市场供求权重，引发贬值预期与资本外流，随后加强资本流动管理（参见[[8.11 汇改]]）。
- **离岸-在岸联动**：人民币在岸（CNY）与离岸（CNH）市场相互影响，外汇管理通过收紧离岸流动性、稳定价差来管理预期（参见[[离岸人民币]]）。
- **沪港通/深港通**：在资本项目渐进开放框架下提供可控的双向投资通道，为外资配置人民币资产打开窗口（参见[[沪港通]]、[[深港通]]）。
- **潘功胜等政策角色**：外汇管理政策由央行与国家外汇管理局主导执行，历任局长对汇率与资本流动表态常成为市场信号（参见[[潘功胜]]、[[外管局]]）。

## 五、后果与影响

### 5.1 积极作用

- **汇率稳定**：抑制过度投机，避免汇率无序波动冲击实体经济。
- **金融安全**：防范跨境资本大进大出，维护金融与货币政策的稳定性。
- **改革缓冲**：为汇率市场化与资本项目开放争取渐进改革的"时间窗口"。

### 5.2 成本与争议

- **效率损耗**：行政审批与合规成本上升，部分影响市场效率与资源配置。
- **信号扭曲**：汇率中的"非市场化力量"使价格信号失真，影响股汇联动分析的解释力（参见[[汇率非市场化]]）。
- **套利与规避**：管制强度与套利行为相互博弈，跨境"热钱"通过贸易、服务等渠道规避监管（参见[[热钱]]）。

### 5.3 趋势

- 长期方向是**市场化、国际化与便利化**：扩大资本项目可兑换、完善汇率形成机制、提升跨境资金流动便利度，同时以宏观审慎工具对冲开放风险。
