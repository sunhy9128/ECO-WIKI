# 金融安全

> 金融是国家重要的核心竞争力，金融安全是国家安全的重要组成部分

## 一、定义

**金融安全**（Financial Security）指一国金融体系能够**抵御内外冲击、保持基本稳定运行、支撑实体经济持续发展**的状态。其反面是金融危机——金融体系功能瘫痪、资产价格崩溃、支付清算中断。

金融安全的覆盖面远大于"金融机构稳健经营"，它包含四个层次：

| 层次 | 内涵 |
|------|------|
| **微观安全** | 单个金融机构稳健，无重大风险事件 |
| **中观安全** | 金融市场平稳运行，重要基础设施无故障 |
| **宏观安全** | 不爆发系统性金融危机，货币与汇率稳定 |
| **国家战略安全** | 金融不受外部势力操控，跨境风险可控 |

## 二、政策背景与演进

### 2.1 中国金融安全观的形成

- **2017 年**：全国金融工作会议提出"金融安全是国家安全的重要组成部分"，确立"服务实体经济、防控金融风险、深化金融改革"三大任务
- **2018 年**：设立国务院金融稳定发展委员会，强化统筹监管
- **二十届三中全会**：将防范化解金融风险与金融监管体制改革列为重点，强调"守住不发生系统性金融风险的底线"
- **金融法立法**：提出制定统一金融法，把所有金融活动纳入监管

### 2.2 风险来源

| 风险源 | 说明 |
|--------|------|
| **房地产风险** | 银行信贷与土地财政深度绑定，房价波动冲击资产负债表 |
| **地方政府债务** | 隐性债务规模大，与金融体系高度关联 |
| **影子银行** | 表外业务与通道业务积累期限错配与信用风险 |
| **外部冲击** | 美联储加息、资本外流、汇率贬值压力 |
| **技术风险** | 金融科技、网络攻击、数据安全 |
| **地缘政治** | 金融制裁、支付体系武器化 |

## 三、维护金融安全的机制

### 3.1 宏观审慎管理

中央银行通过宏观审慎政策工具（资本缓冲、杠杆率约束、逆周期调控等）防范系统性风险累积，参见 [[系统性风险]]、[[逆周期资本缓冲]]。

### 3.2 微观监管与风险处置

- **审慎监管**：资本充足率、拨备覆盖率等监管指标（参见 [[资本充足率]]）
- **风险处置**：[[存款保险]]、[[最后贷款人]]、接管与重组机制
- **金融消费者保护**：防止非法集资与金融欺诈

### 3.3 跨境与开放安全

在金融开放背景下，通过 [[资本管制]]、[[外汇管制]]、[[外汇储备]] 管理维持外部平衡，防止大规模资本流动冲击（参见 [[热钱]]、[[美元周期]]）。同时完善 [[跨境资金登记]] 与反洗钱体系。

### 3.4 国家战略层面

- **支付体系安全**：建设独立自主的跨境支付渠道（如 [[CIPS]]、[[mBridge]]），对冲 [[SWIFT]] 制裁风险（参见 [[金融制裁]]、[[金融武器化]]）
- **数据与网络安全**：保障金融数据主权（参见 [[数据安全]]）
- **法律工具**：[[国家安全法]]、[[反外国制裁法]]、[[阻断法令]] 等提供法律支撑

## 四、关键举措与领域

### 4.1 三大攻坚战

近年金融风险处置聚焦三大领域：

| 领域 | 处置举措 |
|------|----------|
| **影子银行** | 资管新规压缩通道业务、规范表外融资 |
| **房地产** | 保交楼、房地产融资白名单、风险房企处置 |
| **地方政府债务** | [[化债]]、特殊再融资债券、平台转型 |

### 4.2 防范化解的系统性安排

- **守住底线**：不发生系统性金融风险
- **处置原则**：谁家孩子谁家抱——压实地方与股东责任
- **市场化法治化**：风险处置按市场规则与法律程序推进
- **最后防线**：央行最后贷款人职能与存款保险基金

### 4.3 金融安全与其他领域的联动

金融安全与 [[金融体制改革]]、[[财税改革]]、[[房地产]]、[[化债]]、[[人民币国际化]] 深度关联：改革是化解风险的治本之策，安全是改革推进的前提条件。

## 五、影响与评价

### 5.1 中国维护金融安全的路径特点

| 特点 | 说明 |
|------|------|
| 强监管 | 集中统一的监管架构，穿透式监管 |
| 渐进化解 | 以时间换空间，避免一次性硬出清 |
| 内外有别 | 开放有节奏，资本账户渐进放开 |
| 底线思维 | 明确不发生系统性风险的底线 |

### 5.2 挑战与争议

- 强监管可能抑制金融创新与市场活力
- 隐性担保与刚性兑付尚未完全打破，道德风险仍存
- 房地产与地方债务风险处置难度大、周期长
- 外部制裁与地缘博弈给金融安全带来新考验
