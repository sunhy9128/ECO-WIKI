# 价格机制

> 市场的"看不见的手" — 价格如何在不经中央指令的情况下协调亿万分散的经济决策

## 一、概述

### 1.1 定义

**价格机制**（Price Mechanism）是指通过价格的**形成与变动**来引导资源配置、协调供求、激励行为的一整套市场运行方式。它回答经济学的基本问题——**生产什么、如何生产、为谁生产**——且不需要任何中央计划者，依靠分散的价格信号即可完成协调。

### 1.2 价格机制的三重功能

| 功能 | 内涵 | 对应问题 |
|------|------|----------|
| **信息传递** | 价格汇总并传递供需信息，买卖双方据以调整行为 | 生产什么 |
| **激励与约束** | 高价格激励供给、抑制需求；低价格反之 | 如何生产 |
| **收入分配** | 价格决定交易双方的成本与收益分配 | 为谁生产 |

### 1.3 与计划定价的区别

- **市场定价**：价格由供求双方在交易中自发形成，反映稀缺程度（见 [[供需均衡]]）；
- **计划定价/管制价格**：价格由政府或行政力量决定，可能偏离真实稀缺程度（见 [[价格双轨制]]、[[非市场化力量]]）；
- 价格机制是否有效运转，是"市场经济"与"命令经济"的核心分野之一（见 [[计划经济转型]]）。

## 二、理论机制：价格如何协调经济

### 2.1 供求均衡与价格发现

```
供过于求 → 价格下降 → 生产者减产、消费者增加购买 → 供求趋近
供不应求 → 价格上升 → 生产者增产、消费者减少购买 → 供求趋近
        ↓
均衡价格（出清价格）形成
```

均衡价格同时完成**市场出清**与**资源配置**双重任务：资源流向愿意支付最高价格的用途，即稀缺资源被配置到价值最高的地方（见 [[稀缺性]]、[[资源配置]]）。

### 2.2 弹性与价格反应

价格机制的效率取决于供需双方对价格的**反应程度**：

- 需求价格弹性大 → 价格小幅变动即可显著改变需求量（见 [[弹性]]）；
- 供给调整存在时滞（如农业生产周期）→ 价格可能围绕均衡持续波动，形成蛛网式循环（见 [[蛛网模型]]）；
- 短期弹性与长期弹性的差异，决定了价格机制调节的节奏与形态。

### 2.3 相对价格与资源配置

真正决定资源配置的不是**物价总水平**，而是**相对价格**（一种商品相对于另一种商品的价格）：

```
相对价格变动（如油价相对电价上升）
        ↓
企业调整要素投入结构（节能、替代能源）
消费者调整消费组合
        ↓
资源跨行业、跨产品重新配置
```

相对价格变动引导生产要素流向生产率更高、社会需求更迫切的部门，这是价格机制实现"动态效率"的途径。

### 2.4 价格信号与信息不对称

价格是分散信息的**凝缩器**：每个参与者只需关注价格，而无须掌握全球或全国的完整信息。但当存在信息不对称（如劣质品驱逐优质品）时，价格信号可能失真（见 [[信息不对称]]、[[逆向选择]]），这是价格机制失灵的重要来源。

## 三、价格机制的现实形态

### 3.1 完全竞争到不完全竞争

价格机制发挥作用的前提是充分竞争，但现实中市场结构各异：

| 市场结构 | 特征 | 价格决定 |
|----------|------|----------|
| 完全竞争 | 众多买卖者、同质产品 | 市场决定，单个主体是价格接受者 |
| 垄断竞争 | 产品有差异 | 价格 + 差异化竞争 |
| 寡头 | 少数大企业 | 策略互动、价格刚性 |
| 垄断 | 单一供给者 | 垄断定价、可能偏离社会最优 |

在不完全竞争下，价格机制仍起作用，但效率受损，需要竞争政策介入（见 [[市场竞争]]、[[反垄断法]]）。

### 3.2 价格机制与宏观调控

- 宏观经济层面，价格机制同时承担**价格水平稳定**（反通胀）与**相对价格调整**（结构调整）两类职能；
- 货币政策通过利率、汇率等"广义价格"影响总需求与通胀预期（见 [[通胀目标制]]、[[利率市场化]]）；
- 政府通常在价格机制失灵或社会公平受损时进行有限干预（如粮价保护、民生价格管制），而非取代市场（见 [[市场失灵]]）。

### 3.3 中国的价格改革实践

- 从计划价格到市场价格的转轨是中国改革的核心主线之一（见 [[中国改革]]、[[渐进式改革]]）；
- 价格双轨制时期"计划内低价 + 计划外高价"并存，体现了改革过渡期的特殊形态（见 [[价格双轨制]]）；
- 要素价格（利率、[[汇率]]、能源）市场化程度仍是观察改革深度的重要维度（见 [[利率市场化]]、[[汇率非市场化]]）。

## 四、应用与局限

### 4.1 价格机制的边界

价格机制并非在所有领域都高效，典型失灵情形包括：

- **外部性**：价格未能反映社会成本或收益（污染、研发外溢）（见 [[市场失灵与外部性]]）；
- **公共物品**：非排他、非竞争性物品无法由市场价格有效供给（见 [[公共物品]]）；
- **分配公平**：价格机制按要素贡献分配，可能造成贫富差距（见 [[收入分配]]）；
- **宏观不稳定**：价格刚性、预期变化可能造成总需求剧烈波动，需要宏观政策熨平。

### 4.2 价格信号失真的常见来源

| 来源 | 表现 |
|------|------|
| 行政管制 | 定价偏离稀缺程度 |
| 垄断与合谋 | 价格被操纵抬高 |
| 信息不对称 | 价格无法反映真实质量 |
| 投机与泡沫 | 价格大幅偏离基本面 |
| 市场微观结构缺陷 | 交易机制导致定价扭曲 |

### 4.3 政策启示

- 宏观政策应以**不扭曲价格信号**为原则，尽量采用总量性、市场化工具；
- 对失灵领域，政府干预应"补位"而非"替代"，并随条件变化逐步退出；
- 价格机制的健全程度，是衡量市场化改革与经济效率的关键标尺。
