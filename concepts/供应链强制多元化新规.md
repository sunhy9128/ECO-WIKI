# 供应链强制多元化新规

> 欧盟首次以行政法规将"去单一来源国依赖"上升为强制合规要求 — 对华"去风险"的法律化

## 一、定义与概述

**供应链强制多元化新规**指欧盟推出的供应链管控新规，要求欧盟关键制造业的单一国家采购比例设定硬性上限，并必须维持多个国别的供应商结构。这是欧盟首次以行政法规形式将"去单一来源国依赖"从企业自愿行为上升为**强制性合规要求**，本质上是对华"脱钩断链"政策的法律化，是欧盟经济安全战略的核心组成部分。

### 1.1 核心条款

| 条款 | 内容 |
|------|------|
| **适用行业** | 化工、机械、新能源车等关键制造业 |
| **单一国家采购上限** | 约 30%–40% |
| **供应商数量门槛** | 至少 3 个不同国别的供应商 |
| **约束性质** | 行政法规强制合规 |
| **政策目标** | 降低对单一来源国的供应链依赖 |

### 1.2 与相关概念的关系

- [[供应链多元化]]：本规定所属的政策框架
- [[欧盟]]：规则的制定主体
- [[中欧经贸关系]]：规则影响的核心领域
- [[外国补贴条例(FSR)]] / [[数字服务法(DSA)]]：欧盟经济安全工具组合

## 二、背景

### 2.1 政策背景

新冠疫情暴露出全球供应链的脆弱性，俄乌冲突与中美博弈进一步强化了经济安全的优先性。欧盟提出"经济安全战略"与"去风险化（de-risking）"路线，将供应链韧性、关键技术与产业竞争力纳入政策议程，供应链强制多元化新规即为这一战略的落地工具。

### 2.2 对华背景

在中国对欧盟部分关键商品出口占据较高份额的背景下，欧盟将"单一来源国依赖"视为战略脆弱点。该规则与同期欧盟缓和与美经贸关系、强化与华经贸紧张形成**政策对冲**，是 2026 年 5 月欧委会闭门会议推出的对华贸易工具包的重要组成部分。

## 三、机制与作用

### 3.1 运作机制

```
识别关键制造业与单一来源依赖
       ↓
设定采购比例上限与供应商数量门槛
       ↓
企业合规审查与供应链调整
       ↓
违规调查与处罚
       ↓
供应商结构重组（多元化）
```

### 3.2 主要作用

| 作用 | 说明 |
|------|------|
| **法律强制** | 将"去单一依赖"从倡议变为义务 |
| **倒逼重组** | 促使跨国企业调整采购来源与区域布局 |
| **政策信号** | 明确欧盟经济安全的优先方向 |
| **谈判筹码** | 构成欧盟对华经贸谈判的制度工具 |

## 四、关键事件与数据

### 4.1 关键节点

- **欧盟经济安全战略提出**：供应链韧性成为核心议题
- **2026 年 5 月 29 日欧委会闭门会议**：正式敲定对华贸易围堵方案，供应链强制多元化新规是其组成部分
- **配套工具联动**：与[[钢铁进口保护法案]]、[[外国补贴条例(FSR)]]、《数字服务法》(DSA) 等形成组合（详见 [[欧盟要与中国打贸易战？]]）

### 4.2 规则要点

- 化工、机械、新能源车等行业首当其冲
- 单一国家采购比例上限约 30%–40%
- 必须至少拥有 3 个不同国别供应商
- 具体实施细则与过渡安排有待后续法规明确

## 五、影响

### 5.1 对中国出口的影响

- 中国在欧盟关键制造业中的份额面临强制压缩压力
- 出口企业需加快海外产能布局或寻求第三方转口路径
- 长期看倒逼中国出口结构升级与多元化市场开拓

### 5.2 对跨国企业的影响

- 合规成本上升，供应链管理复杂度显著增加
- 采购来源被迫分散，规模经济与成本优势受侵蚀
- "中国+1"乃至"中国+N"策略加速落地

### 5.3 对欧盟的影响

- 提升供应链韧性，但可能推高采购成本与通胀压力
- 若转供能力不足，将削弱本土制造业竞争力
- 规则执行中面临成员国利益与法治约束的平衡难题

### 5.4 对全球供应链的影响

- 全球供应链进一步区域化、阵营化（见 [[阵营化趋势]]）
- 关键产业的"备份产能"竞争加剧
- 经济安全考量对自由贸易规则形成持续侵蚀
