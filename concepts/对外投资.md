# 对外投资

> 中国企业与居民"走出去"的核心渠道 — 资本、技术与市场在全球范围内的再配置

## 一、定义

**对外投资**（Outbound Investment）指一国居民（企业、机构、个人）将资本投向境外，获取资产所有权、经营管理权或收益权的经济活动。狭义上常指**对外直接投资**（Outbound Foreign Direct Investment，OFDI），即境内投资者在国外设立企业、参与经营并拥有控制权的投资；广义上还包括对外证券投资、对外贷款、对外工程承包与劳务合作等。

### 1.1 与相关概念的区别

| 概念 | 含义 | 与对外投资的关系 |
|------|------|----------------|
| **对外直接投资（OFDI）** | 对境外企业拥有经营控制权的投资 | 对外投资的核心组成部分 |
| **对外证券投资** | 购买境外股票、债券等金融资产 | 属于对外投资，但一般不涉及控制权 |
| **外商直接投资（FDI）** | 境外资金进入本国 | 方向相反，共同构成跨境资本双向流动 |
| **再投资** | 以境外经营利润继续投资 | 对外投资的延续形式（参见 [[再投资]]） |

## 二、背景

### 2.1 从"引进来"到"走出去"

改革开放初期中国以吸引外资为主，资本项目呈"宽进严出"格局。2000 年前后"走出去"战略正式提出，对外投资进入加速期。2001 年入世后，中国企业全球布局需求上升，对外投资规模快速增长，中国逐步从资本净流入大国转变为资本双向流动大国。

### 2.2 政策框架的形成

对外投资涉及[[外汇管理]]、产业政策与国家安全三重约束，形成了以**发展改革部门（项目核准/备案）＋商务部门（对外投资备案登记）**为主、外汇部门（资金汇出）配合的多头管理体系（参见 [[国务院关于对外投资的规定]]、[[对外投资安全审查]]）。

## 三、机制与作用

### 3.1 投资动机

| 动机 | 说明 |
|------|------|
| **市场寻求型** | 开拓海外市场、绕开贸易壁垒 |
| **资源寻求型** | 获取能源、矿产、农产品等战略资源 |
| **技术寻求型** | 通过并购获取品牌、技术与研发能力 |
| **效率寻求型** | 利用海外低成本要素、优化全球布局 |

### 3.2 对外投资的宏观经济作用

- **国际收支**：对外投资形成资本与金融账户流出，与贸易顺差（参见 [[双顺差]]）共同影响[[国际收支]]结构
- **外汇储备**：资本流出消耗外汇，与[[外汇储备]]的积累形成对冲
- **产业转移**：推动国内产业向价值链高端攀升，实现[[产业升级]]
- **人民币国际化**：以人民币计价结算的对外投资为[[人民币国际化]]提供实体场景
- **供应链布局**：在[[共建一带一路]]框架下形成海外产能网络

## 四、政策与监管体系

### 4.1 核准与备案

- **敏感类目**（涉敏感国别、敏感行业）实行核准制
- **非敏感类目**实行备案制
- 主要依据：[[对外关系法]]、[[对外投资安全审查]]、[[技术出口管理]]相关制度

### 4.2 资金与外汇管理

- 对外投资资金汇出需遵守外汇管理规定（参见 [[外汇管理]]、[[外汇管制]]）
- 属于"开正门、堵偏门"监管思路的**正门**：合法合规的对外投资应保障顺畅（参见 [[开正门堵偏门]]）
- 违规通过地下钱庄、虚假贸易等方式转移资金则属于**堵偏门**对象

### 4.3 分类管理

| 投资主体 | 主要监管要点 |
|---------|------------|
| **企业** | 核准/备案、真实性审核、安全审查 |
| **金融机构** | 以 QDII 等方式开展境外证券投资 |
| **居民个人** | 受限严格，主要经合规渠道（参见 [[居民个人对外投资]]） |

## 五、关键事件与数据（概括性）

- 中国对外直接投资存量已居世界前列，覆盖全球大多数国家和地区
- "一带一路"沿线投资占比显著提升，能源、交通、制造业为集中投向领域
- 部分时期出现投资过热与"非理性投资"，监管相应收紧，强化真实性、合规性审核
- 近年跨国并购更趋审慎，政策取向从规模扩张转向提质增效与风险防控

## 六、影响与风险

### 6.1 正面影响

- 提升中国企业的全球资源配置能力与国际竞争力
- 缓解贸易顺差压力、优化国际收支结构
- 促进东道国基础设施与产能建设，深化互利合作

### 6.2 风险与挑战

| 风险 | 说明 |
|------|------|
| **政治风险** | 东道国政局变动、政策收缩、地缘博弈（参见 [[地缘政治]]） |
| **债务风险** | 过度杠杆导致海外项目财务压力 |
| **汇率风险** | 本外币汇率波动侵蚀投资回报（参见 [[汇率损失]]） |
| **监管风险** | 反垄断、安全审查、制裁合规（参见 [[金融制裁]]、[[二级制裁]]） |
| **资金外逃** | 以对外投资名义变相转移资产的监管套利风险 |
