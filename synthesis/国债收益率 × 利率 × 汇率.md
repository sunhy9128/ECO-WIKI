# 国债收益率 × 利率 × 汇率

## 连接何在

[[entities/美债收益率|美债收益率]] 页把收益率拆成"短端=政策利率预期、长端=增长+通胀+期限溢价"，[[entities/美元指数|美元指数]] 页则记录了 DXY 的构成与 2026-07 跌破 100 的干预背景；[[concepts/利率平价理论|利率平价理论]] 页给出了利率-汇率联动的无套利公式，[[concepts/汇率超调模型|汇率超调模型]] 解释了为什么汇率会过度反应。但单看任何一页，都看不到一个关键事实：**这三者不是三个独立变量，而是同一个"美元资产定价"问题的三个投影面**。国债收益率是美元资产的"价格"，利率是它的"锚"，汇率是它的"对外标价"——三者被资本流动这条管道焊死在一起。

2026-08-19 美国财政部长贝森特宣布将长端流动性支持回购上限翻倍至 $4B，提供了一个绝佳的"自然实验"：当政策主动压低长端收益率时，调整压力不会消失，而是沿着这条联动管道**转移到美元汇率上**。市场给这个现象起了名字——"美元贬值交易"（debasement trade）。本页回答的核心问题是：**为什么压低长端收益率会削弱美元？这条传导链的每一环是什么？** ^[inferred]

需要与既有页面划清分工：[[concepts/利率平价理论]] 讲的是利率差的**无套利定价**（CIP/UIP 公式），[[concepts/汇率传导机制]] 讲的是汇率变动如何**反作用于**国内物价与贸易，[[concepts/汇率超调模型]] 讲的是汇率对冲击的**动态调整路径**。本页不重复这些机制学细节，而是把它们**串成一条从"长端收益率"到"美元汇率"的完整传导链**，并用 2026-08 的真实事件做实证校验。对读者而言，这页的收获是：理解"为什么美联储/财政部压长端收益率，最终会以美元贬值收场"。

## 共现场景

### 场景一：利率平价——收益率差直接定价汇率

[[concepts/利率平价理论|利率平价理论]] 提供了最基础的联动公式。抛补利率平价（CIP）下，远期汇率由两国利差决定：

```
F = S × (1 + r_US) / (1 + r_EZ)
```

高利率货币远期贴水。无抛补利率平价（UIP）下，**预期汇率变动 ≈ 利差**：当美国长端收益率相对欧元区/日本上升，资本流入美元资产，美元即期升值；反之则贬值。这是"收益率→汇率"最直接的通道。

**关键推论**：当美国长端收益率被**人为压低**（如回购），而欧元区/日本收益率不变，利差收窄 → 美元资产的相对吸引力下降 → 资本流出 → 美元贬值。这正是 2026-08 发生的事：回购压低长端后，EUR/USD 走强至 $1.1668（近3月峰值）、GBP/USD 至 $1.3639（近6月峰值），DXY 跌破 99。

### 场景二：实际利率差——资本流动的真正引擎

[[concepts/实际利率框架|实际利率框架]] 指出，真正驱动资本流动的是**实际利率**（名义利率 − 通胀预期），而非名义利率。黄金定价的核心就是实际利率。当长端名义收益率被压低而通胀预期不变，**实际利率下降** → 持有美元资产的真实回报缩水 → 资本外流 + 黄金上涨。

2026-08 的实证：回购压低长端后，黄金 +3%、比特币 +13%——这正是"实际利率下降 → 无息资产（黄金/比特币）相对吸引力上升"的教科书反应。黄金与美元呈跷跷板，实际利率是中间变量。

### 场景三：期限溢价——长端收益率的"财政"成分

[[entities/收益率曲线|国债收益率曲线]] 页引入了期限溢价概念。长端收益率 = 短期利率预期均值 + 期限溢价。期限溢价反映投资者持有长债所要求的**额外补偿**，与财政可持续性、供给、通胀风险高度相关。

2026 年的关键变化是**期限溢价抬升**（10年期期限溢价升至 1.02%）：美国债务逼近 $40T、7月赤字 $4320亿（+48%）、AI 资本开支挤出、海外需求走弱（日本 6月减持 $264亿）。当市场对财政可持续性失去信心，期限溢价上升 → 长端收益率上行 → 但这不是"经济强"的信号，而是"财政风险溢价"——它同样会通过实际利率通道削弱美元，只是方向相反地推高收益率。

**这是本页最重要的洞察**：长端收益率上行（财政风险驱动）和长端收益率下行（政策压制）**都会削弱美元**。前者通过"风险溢价→资本外逃"，后者通过"实际利率下降→资本流出"。美元的双向脆弱性，根源在于财政主导（fiscal dominance）——市场不再相信美国能控制赤字。

### 场景四：汇率超调——政策冲击的动态放大

[[concepts/汇率超调模型|汇率超调模型]]（Dornbusch）解释了为什么汇率对政策冲击会**过度反应**：商品价格黏性，而汇率和利率瞬时调整。当回购压低长端收益率，汇率不会温和贬值，而是**超调**——先大幅贬值，再缓慢回归。

2026-08 的 DXY 单日跌幅（3月以来最大）正是超调的表现。市场对"财政部压收益率"这一政策信号的解读，放大了实际利差变化的影响。

## 传导链总结

```
财政部长债回购（$4B/次）
    ↓ 压低长端收益率（10年 4.75%→4.643%，30年 5.31%→5.199%）
    ↓ 实际利率下降（名义↓，通胀预期不变）
    ↓ 美元资产相对吸引力下降
    ↓ 资本流出 + 黄金/比特币上涨（+3%/+13%）
    ↓ 美元贬值（DXY 跌破99，EUR/GBP 走强）
    ↓ 触发"美元贬值交易"叙事（debasement trade）
```

## 2026-08 事件实证

### 政策动作

- **2026-08-19**：贝森特宣布长端流动性支持回购单次上限从 $2B 翻倍至 $4B，覆盖 10-20 年期和 20-30 年期板块，2026-09-09 生效至 11-04 再融资季度
- **背景**：8-17 30年期收益率升至 5.31%（2007-06 以来新高），10年期站上 4.7%；全球债市联动抛售
- **机制**：回购资金来自发行新短债（再融资，非印钞，不扩大货币供应，区别于 QE）；2025 年规模约占未偿国债 0.6%

### 市场反应

| 资产 | 反应 |
|------|------|
| 30年美债收益率 | 5.31% → 5.199% |
| 10年美债收益率 | 4.75% → 4.643% |
| DXY | 跌破 99，录得 3月以来最大单日跌幅，周跌 0.8% |
| EUR/USD | 走强至 $1.1668（近3月峰值） |
| GBP/USD | 走强至 $1.3639（近6月峰值） |
| 黄金 | +3% |
| 比特币 | +13%，冲 $70K 两个月新高 |

### 市场解读

- **Deutsche Bank（George Saravelos）**：将回购类比美联储 2011-12 Operation Twist（卖短买长压平曲线），称回购+鼓励外国央行用 Fed repo 便利而非卖美债是"软性金融压抑"（soft-form financial repression）
- **Scotiabank（Shaun Osborne）**："要么更高收益率，要么美元让步"
- **Robin Brooks（Brookings，前高盛外汇策略师）**：$4B/次回购相对 $31T 债务杯水车薪，投资者意识到长债供给必然增长而华盛顿无意解决赤字，可能打开类似日元式大幅贬值之门
- **CIBC（Sarah Ying）**：这是"mini"版美元压力（弱于 2025-04 Liberation Day）
- **政治动机**：中期选举前压低长端收益率/房贷利率利好特朗普政府

## 推演：长债回购对长债收益率、美元汇率、美元指数的影响

### 短期（1-3个月，2026 Q4）

- **长债收益率**：回购直接压低 10-30 年期收益率，但幅度有限（$4B/次相对 $31T 债务杯水车薪）。预计 10年期在 4.5-4.8% 区间震荡，30年期在 5.0-5.3%。若财政赤字继续恶化，期限溢价可能重新抬升，抵消回购效果
- **美元汇率**：DXY 偏软，预计在 96-100 区间。欧元/英镑相对走强。若美联储（沃什）配合"短端降息托底"，美元进一步承压
- **美元指数**：跌破 100 后缺乏反弹动能，市场对"财政主导"的定价使 DXY 中枢下移

### 中期（6-12个月，2027）

- **核心风险**：回购被市场视为"治标不治本"——它压低收益率但不解决 $2T 赤字。若市场对财政可持续性失去信心，可能触发**日元式贬值螺旋**（Robin Brooks 警告）：收益率被压制 → 资本外流 → 美元贬值 → 进口通胀 → 实际利率进一步下降 → 更多资本外流
- **黄金/比特币**：作为 debasement trade 的对冲资产，中期看涨
- **美元指数**：若贬值螺旋形成，DXY 可能下探 92（2026 年预测区间下沿）

### 长期（1-3年）

- **结构性判断**：财政主导（fiscal dominance）是 2026 全球利率的关键因素（MSCI 2026-01）。只要美国不解决赤字，长端收益率和美元就处于"两难"：要么收益率上行（财政风险溢价），要么美元贬值（政策压制转移压力）
- **与历史类比**：Operation Twist（2011-12）压平曲线后，美元在 2012-2014 走弱；日本 1990s 的收益率压制最终导致日元长期贬值。美国若重蹈覆辙，美元霸权将面临结构性侵蚀（见 [[concepts/美元霸权]]）

## 深化分析

### 深化一：量化回购对期限溢价的影响

用 FRED 10年期期限溢价（THREEFYTP10，Kim-Wright 模型）逐日追踪回购前后的变化：

| 日期 | 10年期期限溢价 | 事件 |
|------|--------------|------|
| 2026-08-17 | 0.8536% | 30年收益率冲高至 5.31% |
| 2026-08-18 | 0.8549% | 回购宣布前夜 |
| **2026-08-19** | **0.8378%** | **贝森特宣布回购上限翻倍（-1.7bp）** |
| 2026-08-20 | 0.8478% | 收益率回落 |
| 2026-08-21 | 0.8682% | 回升至宣布前水平之上 |

**关键结论**：回购对期限溢价的压制是**短暂且有限**的——宣布当天仅 -1.7bp，两天后即回升至 0.8682%（高于宣布前）。原因在于规模：$4B/次回购相对 $31T 债务杯水车薪。对比历史弹性——美联储研究（Bonis/Ihrig/Wei）估计 SOMA 每减少 $100B 国债，10年期期限溢价约 +4~5bp；回购是反向操作，但 $4B 的规模连 1bp 的弹性都难以撬动。

**更深一层**：回购压低的是**名义收益率**（通过需求侧买盘），而非**期限溢价**（财政风险成分）。期限溢价在回购后不降反升，说明市场对财政可持续性的担忧**并未因回购而缓解**——这正是"财政主导"的定价：政策可以暂时压住名义收益率，但压不住市场对赤字的恐惧。期限溢价从 2024-11 转正（2011 以来首次）、2026-01 升至 0.70%+、2026-08 仍在 0.82-0.87% 高位，是财政主导的结构性证据。

### 深化二：2025-04 Liberation Day vs 2026-08 长债回购

| 维度 | 2025-04 Liberation Day | 2026-08 长债回购 |
|------|----------------------|------------------|
| **触发** | 对等关税（有效关税率 5%→25%） | 长债回购上限翻倍至 $4B |
| **DXY** | 跌破 98（2022-03 以来新低），年内 -10% | 跌破 99（未破 98），周跌 0.8% |
| **黄金** | 突破 $3400，2025 全年创 $4000 新高 | +3% |
| **驱动** | 贸易/滞胀/关税冲击 | 财政主导/收益率压制 |
| **性质** | **外部**贸易冲击 | **内部**财政主导 |
| **CIBC 定性** | 强 | "mini"版 |

**关键差异**：Liberation Day 是**外部贸易冲击**——关税 → 滞胀担忧 → 美元资产抛售，属于"美国例外论"受质疑的**急性**事件，且随关税谈判缓和而部分逆转（2025 下半年美股/美元反弹）。2026-08 是**内部财政主导**——政策主动压低收益率 → 贬值交易，属于"财政可持续性"受质疑的**慢性**事件，更结构性、更持久。

**为什么 2026-08 是"mini"版**：①DXY 只跌破 99 未破 98（2025-04 低点）；②黄金仅 +3%（vs 2025-04 突破历史新高）；③回购规模小（$4B/次），市场尚未形成恐慌性抛售。但 CIBC 的"mini"定性也意味着：**若财政主导持续，2026-08 可能是更大贬值的起点而非终点**——Robin Brooks 的"日元式贬值螺旋"警告正指向这一点。

### 深化三：2026-09-09 回购生效后的观察框架

回购 2026-09-09 生效至 11-04 再融资季度。设定以下观察指标以验证传导链：

| 观察指标 | 数据源 | 验证逻辑 |
|---------|--------|---------|
| 10年期期限溢价 | FRED THREEFYTP10 / ACM | 若持续回落 → 回购有效；若回升 → 财政担忧主导 |
| 10年/30年收益率 | FRED DGS10/DGS30 | 是否守住 4.5%/5.0% 关键位 |
| DXY | ICE | 是否跌破 98（2025-04 低点）→ 贬值螺旋信号 |
| 黄金/比特币 | 现货 | debasement trade 是否持续 |
| 拍卖投标倍数 | 财政部 | 5-13 的 2.303 低点是否改善（需求恢复信号） |
| 外国央行 Fed repo 便利使用 | 纽约联储 | Deutsche Bank"软性金融压抑"是否兑现 |

**关键分叉**：若回购生效后期限溢价回落 + 收益率守住 + DXY 企稳 → 回购"成功"（短期稳定市场）；若期限溢价回升 + DXY 破 98 → 财政主导深化，贬值螺旋启动。前者是"治标"，后者是"财政主导失控"。

### 深化四：软性金融压抑是否构成对美元霸权的结构性威胁

Deutsche Bank 的"软性金融压抑"（soft-form financial repression）指：回购压低收益率 + 鼓励外国央行用 Fed repo 便利而非卖美债，本质是**用政策手段把调整成本转嫁给储户与债权人**。这是否威胁美元霸权？

**三条侵蚀路径**：
1. **收益率压制** → 实际利率下降 → 资本外流（[[concepts/实际利率框架]]）
2. **通胀容忍** → 通胀税 → 债权人/储户受损（[[concepts/美元贬值交易]]）
3. **汇率贬值** → 储备货币信用动摇（[[concepts/美元霸权]]）

**但短期有惯性**：美元霸权有网络外部性（石油美元、储备份额、交易媒介），不会快速崩塌。软性金融压抑是**慢性侵蚀**而非急性崩塌——更接近日本 1990s 的长期贬值，而非拉美式恶性通胀。

**结构性判断**：软性金融压抑本身不立即摧毁美元霸权，但它**侵蚀美元霸权的信用基础**。当市场反复看到"财政部压收益率→美元贬值"的模式，储备货币持有者会逐步分散配置（黄金、欧元、比特币）。这是**量变到质变**的过程——单次回购是"mini"事件，但若成为常态，将累积为结构性威胁。这正是 [[synthesis/财政主导|财政主导]] 页的核心论点：财政主导是美元霸权从内部瓦解的路径。
