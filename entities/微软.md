# 微软

> 全球历史最悠久、规模最大的软件公司之一，已从 PC 时代的软件霸主转型为"云 + AI"基础设施公司。

## 定位

- **微软公司**（Microsoft Corporation）1975 年由比尔·盖茨与保罗·艾伦创立，总部位于美国华盛顿州雷德蒙德。
- 公司在 PC 时代以 Windows 操作系统与 Office 办公套件确立霸主地位，定义了"软件 + 硬件 + 开发者生态"的行业范式。
- 现任 CEO 萨蒂亚·纳德拉（Satya Nadella）2014 年上任，确立"移动为先、云为先"战略，将公司重心转向云服务与人工智能。
- 2020 年代中期，微软是全球市值最高的公司之一，长期与[[苹果]]、[[英伟达]]、[[亚马逊]]争夺市值榜首位置。

## 业务与财务

### 智能云（Intelligent Cloud）

- Azure 云服务是公司增长与利润的主要引擎，全球公有云市场份额仅次于亚马逊 AWS。
- 覆盖 IaaS、PaaS、SaaS 全栈，在企业客户、混合云与政企市场具备明显优势。
- 与 OpenAI 深度绑定，Azure 为大模型训练与推理提供算力，是"AI 算力"叙事的核心受益者。

### 生产力与商业流程（Productivity and Business Processes）

- Office 365 / Microsoft 365 通过订阅制实现经常性收入，Office 在企业办公领域近乎刚需。
- 旗下拥有 LinkedIn（职场社交）、Dynamics（企业 ERP/CRM）等业务。
- 将 Copilot 系列 AI 助手全面植入 Word、Excel、Outlook、Teams 等产品，推动"AI 办公"普及。

### 个人计算（More Personal Computing）

- Windows 操作系统仍占据 PC 市场主导份额，是公司现金牛业务。
- Xbox 游戏主机与 Game Pass 订阅服务，与[[索尼]]PlayStation、任天堂并列为三大主机阵营。
- Surface 设备、必应（Bing）搜索与 Edge 浏览器构成硬件与搜索入口，AI 化的必应曾在 2023 年引发搜索市场关注。

### 财务概况

- 年营收数千亿美元规模，云业务贡献主要增量，整体毛利率与净利润率处于科技巨头前列。
- 账上现金充裕，持续通过并购扩充能力边界（如领英、GitHub、动视暴雪）。
- 市值长期位列全球前三，是[[英伟达]]、[[苹果]]等公司在"万亿市值俱乐部"中的常驻成员。

## 竞争格局

- **云计算**：与[[亚马逊]]（AWS）、谷歌云竞争，在企业级客户关系、混合云生态与 AI 算力整合上具备差异化优势。
- **操作系统与办公**：Windows 与 Office 在企业级市场近乎垄断，但面临移动端 iOS/安卓生态与谷歌 Workspace 的挑战。
- **游戏**：Xbox 与[[索尼]]、任天堂竞争，收购动视暴雪后手握《使命召唤》等头部 IP，内容实力大增。
- **AI**：与 OpenAI 的同盟使其在基础大模型上领先，同时与谷歌 DeepMind、Meta、Anthropic 及[[英伟达]]生态存在竞合关系。

## 产品与生态演变

- **Windows 时代（1985–2010）**：Windows 与 Office 组成的"Wintel"联盟定义了 PC 生态，企业级市场近乎标配，形成路径依赖与事实垄断。
- **云转型（2014–2020）**：Azure 从"追赶者"成长为全球第二大云平台，Office 订阅化（Microsoft 365）与"商业云"打法带来持续性收入。
- **AI 时代（2023 至今）**：Copilot 全面进入 Windows、Office、GitHub、Bing 与安全产品线；Azure AI 承载 OpenAI 模型推理，公司从"软件公司"进一步转向"AI 基础设施公司"。

## 开源与开发者生态

- 微软曾在 1990 年代视开源为威胁，2014 年后转向拥抱开源：收购 GitHub、向 Linux 提供 Azure 支持、开源 .NET 与 VS Code。
- GitHub 是全球最大的代码托管平台，是微软连接开发者生态与 AI 编程（Copilot）的战略入口。
- VS Code 成为全球使用率最高的代码编辑器之一，体现"以开发者为中心"的生态策略。

## 争议与监管

- **反垄断历史**：1998 年美国司法部诉微软捆绑浏览器案，是 20 世纪科技反垄断的标志性判例，虽未拆分公司但约束了其行为。
- **欧盟处罚**：微软多次因捆绑 IE、不正当竞争被欧盟处以巨额罚款，是布鲁塞尔监管科技巨头的常客。
- **AI 监管**：与 OpenAI 的合作深度引发欧美反垄断与安全监管关注，其投资结构与治理安排持续接受审查。
- **隐私与云合规**：云数据主权、跨境数据流动与政府数据访问等议题，使微软在全球多市场面临合规压力。

## 关键事件

- **1975 年**成立，1985 年发布 Windows 1.0，随后凭借 Windows 95 奠定 PC 操作系统霸主地位。
- **1990 年代**与网景（Netscape）爆发浏览器大战，因 Windows 捆绑 IE 于 1998 年被美国司法部提起反垄断诉讼，成为[[反垄断法]]史上最著名的案例之一。
- **2000 年代**错失互联网与移动端先机，Windows Phone、必应等业务长期处于追赶状态，被业界称为"迷失的十年"。
- **2014 年**纳德拉接任 CEO，战略转向"云为先"，砍掉手机硬件业务，转向拥抱开源与跨平台（GitHub、Linux on Azure）。
- **2018 年**市值首度突破万亿美元，成为继苹果之后第二家进入该俱乐部的美国公司。
- **2023 年**完成对动视暴雪（Activision Blizzard）约 690 亿美元的收购，为游戏行业史上最大交易之一。
- **2023 年起**与 OpenAI 深度合作，将 GPT 能力全面注入 Windows、Office、GitHub 等产品，股价随之大幅重估。

## 影响

- 定义了 PC 时代"操作系统 + 应用 + 开发者生态"的软件产业范式，Windows 与 Office 深度嵌入全球商业运转。
- 率先完成从软件公司向云公司的转型，是"第二次上市浪潮"中科技巨头换挡的标杆案例。
- 通过与 OpenAI 的绑定成为全球 AI 基础设施竞赛的关键玩家，推动"算力即权力"的产业叙事。
- 其 1998 年反垄断历程深刻影响了全球科技监管的规则与思路。
