# 中国船舶

> 全球规模最大的造船集团 — 军民融合的高端制造旗舰

## Basic Information
- Type: central-enterprise / 国防工业央企
- Alias: CSSC（China State Shipbuilding Corporation）
- 隶属：国务院国资委监管的中央企业
- 地位：中国乃至全球规模最大的船舶制造企业

## Description

中国船舶集团有限公司（简称中国船舶，CSSC）是中央直接管理的国有重要骨干企业，是我国船舶工业与海洋装备领域的旗舰集团，也是全球最大的造船企业。集团业务覆盖**军船与民船建造、海洋工程、动力机电、船舶配套与金融服务**等全产业链，在支撑海军装备建设的同时，主导中国在全球船舶与海工市场的份额，是[[国防军工]]体系与高端制造的关键力量。

---

## 一、背景

### 1.1 历史沿革

中国船舶由原中船集团与中船重工两大集团于 2019 年合并重组而来。合并前两大集团分别以造船与科研院所见长，重组后形成覆盖设计、科研、建造、配套的完整产业链，整合了国内主要的船舶总装厂、研究所与核心配套企业，实现了船舶工业资源的系统性集中。

### 1.2 战略地位

- 海军装备（水面舰艇、潜艇、两栖装备）的主要承建主体
- 全球商船建造市场的份额领先者
- 海洋工程、深海装备与新能源船舶的技术主力

## 二、机制与作用

### 2.1 产业布局

| 板块 | 主要方向 |
|------|---------|
| **军船** | 驱逐舰、护卫舰、潜艇、登陆装备 |
| **民船** | 集装箱船、油轮、散货船、LNG 船、汽车运输船 |
| **海工** | 海洋平台、深海装备、风电安装船 |
| **动力机电** | 船舶动力、低速机、配套设备 |
| **修理与金融** | 船舶修理、租赁与金融服务 |

### 2.2 运作机制

- **总装厂+研究所+配套**一体化：覆盖从研发设计到总装交付全链条
- **军民融合**：军用技术与民船建造共用产能与供应链
- **周期运营**：造船行业强周期属性，订单与船价随全球贸易与运力周期波动
- **绿色转型**：向 LNG、甲醇、氨燃料与电动船舶等新船型延伸

### 2.3 主要作用

- 保障海军装备自主建造能力（见 [[国防军工]]）
- 占据全球商船建造与交付的重要份额
- 拉动钢铁、机电、装备制造等上下游产业链

---

## 三、关键事件与数据

### 3.1 关键节点

- **两船合并（2019 年）**：中船集团与中船重工重组，形成全球最大造船集团
- **高附加值船型突破**：大型 LNG 船、豪华邮轮等高壁垒船型国产化推进
- **新能源船舶布局**：绿色动力船型订单占比提升
- **军民融合深化**：军工资产证券化与央企改革持续推进

### 3.2 行业特征

| 特征 | 说明 |
|------|------|
| **强周期** | 订单、船价随全球运力与贸易周期波动 |
| **全球竞争** | 与韩国、日本造船业形成三强格局 |
| **高壁垒** | 高附加值船型技术门槛高 |
| **绿色转型** | 环保新规驱动船队更新与船型升级 |

## 四、影响

### 4.1 对国防安全

- 保障海军装备的自主建造与持续更新能力
- 为远洋作战与两栖投送提供装备基础

### 4.2 对全球造船格局

- 中国造船在全球三大指标（完工、新接订单、手持订单）中占据领先地位
- 在 LNG 船、汽车运输船等高附加值领域份额持续提升
- 与韩国、日本造船业的竞争格局动态演变

### 4.3 对经济与资本市场

- 造船是典型的外向型高端制造，受全球贸易、航运景气与绿色转型驱动
- 上市公司构成军工与高端制造板块的重要组成部分
- 央企改革、资产整合与订单景气提供主题催化
