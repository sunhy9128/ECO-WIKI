# 安倍晋三

## Basic Information
- Type: person（日本第 90/96-98 任首相）
- 出生：1954-09-21
- 遇刺：2022-07-08（奈良，枪击身亡）
- 任职：首相（2006-09—2007-09 首任；2012-12—2020-09 二任，为日本史上最长任期首相）
- 外祖父：**岸信介**（1957-1960 首相，日美安保条约修订者——见 [[日本安保斗争]]）
- 祖父：安倍宽（战前反军国主义议员）；父：安倍晋太郎（外相）

## Description

安倍经济学（Abenomics）的提出者与总设计师。2012.12 二度组阁后推出三支箭框架（QQE 超宽松 + 扩张财政 + 结构改革），以「摆脱通缩」为竞选纲领。其执政特征：

1. **预期管理大师**：大选前承诺 2% 通胀目标+「unlimited」宽松，选举前一个月市场已提前定价（日经 +12%、日元 -5%）；威胁修订《日本银行法》施压央行（2013.04 政府代表以「观察员」身份列席日银政策会议）。
2. **政策时间表的选举驱动**：优先 2013.07 参议院选举——先推受欢迎的 QQE、搁置争议安保；第三支箭细节（如网上售药豁免）被选举选票直接改写。
3. **修辞与结果背离**：Passive Revolution 论文称其 "populist posturing"（民粹姿态）——用「打破旧利益集团」修辞收买支持，但分配结果反噬无产者（实际工资下跌、财富向有产者集中）。
4. **安保与经济双轨**：安倍经济学（同意面）+ 安保法制改革（强制面）构成不可分割的霸权重建整体——外祖父岸信介的安保遗产的当代延续。
5. **遇刺与遗产**：2022.07.08 遇刺身亡；2024.03.19 日银退出负利率+YCC，安倍经济学正式宣告结束。
