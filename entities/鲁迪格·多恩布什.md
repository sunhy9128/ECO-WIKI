# 鲁迪格·多恩布什

## Basic Information
- Type: person（德国裔美国经济学家）
- 生卒：1942-07-08 — 2002-07-25
- 任职：MIT 经济学教授（国际经济学）
- 代表作：《[[domains/宏观经济|宏观经济]]学》（与 Fischer/Startz 合著，标准教材）；"Expectations and Exchange Rate Dynamics"（1976，[[汇率超调模型]]，多恩布什模型）
- 学生/合作者：Sebastian Edwards（拉美民粹研究）

## Description

**[[concepts/经济民粹主义|经济民粹主义]]研究的奠基人**。1991 年与 Sebastian Edwards 合著《The Macroeconomics of Populism》（NBER w8295），系统研究拉美（[[阿根廷]]、巴西、智利、秘鲁）民粹实验，提出经济民粹主义的经典定义与四阶段模型：

- **定义**：强调增长与收入再分配、淡化通胀与赤字融资风险、假设经济主体顺从非市场政策。
- **四阶段**：初始不满 → 无约束扩张 → 瓶颈通胀 → 正统稳定化（穷人受伤最重）。
- **核心机制**：资本可逃逸、劳动被困；民粹实验最终伤害宣称要帮助的穷人。

其「汇率超调」理论（1976）也是理解日元 2012-2024 巨幅波动（86→161.96）的经典框架——名义汇率在政策冲击下会过度调整，随后缓慢回归。
