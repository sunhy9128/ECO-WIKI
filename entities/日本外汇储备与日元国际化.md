# 日本外汇储备与日元国际化

## 概述

日本外汇储备的核心问题：**干预日元汇率所需资金高度依赖卖出持有的美债**，这一约束构成日元干预有效性的结构性瓶颈。

## 关键数据（截至2026年5月）

- **日本持有美国国债**：**11431.4亿美元**（韩国持有1322.7亿美元）
- **5月当月减持**：66.75亿美元（对应4月28日-5月27日11.7349万亿日元干预）
- **干预资金筹措**：日本没有其它办法筹措干预资金，只能卖出美债

## 干预资金-美债-利差的反身性循环

```
日本卖出美债筹措干预资金
  → 美债利率上行（2026-07-31 2/10/30年 +5/+7/+6BP 至 4.28%/4.75%/5.27%）
  → 拉大美日利差
  → 日元套利收益扩大 → 日元进一步承压
  → 需要更多干预 → 卖出更多美债（恶性循环）
```

**核心矛盾**：日本既是日元（被干预货币）的发行方，又是美债（干预资金来源）的主要持有方之一——干预手段与干预目标在结构上互相冲突，参见[[外汇干预有效性]]。

## 日元国际化现状（简）

- 日元是重要国际货币但非主导货币，干预依赖美元资产（美债）而非自身储备流动性
- 日元贬值的大方向由美日利差主导，储备资产结构（重仓美债）放大了干预的利差反噬
