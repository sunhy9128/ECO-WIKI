# 中国电科

> 中国电子信息与国防信息化领域的骨干央企 — 军队信息化的"神经系统"

## Basic Information
- Type: central-enterprise / 国防工业央企
- Alias: CETC（China Electronics Technology Group Corporation）
- 隶属：国务院国资委监管的中央企业

## Description

中国电子科技集团有限公司（简称中国电科，CETC）是中央直接管理的国有重要骨干企业，主要从事电子信息技术与产品的研发、制造与服务，是我国**电子信息产业与国防信息化建设**的核心力量。在军工央企体系中，中国电科与[[中国船舶]]、[[兵器工业]]等并列，是覆盖雷达、通信、电子对抗、网络信息体系等电子信息装备的骨干集团，同时深度参与国民经济信息化与数字中国建设。

---

## 一、背景

### 1.1 历史沿革

中国电科组建于 2002 年，由原信息产业部直属的多家电子科研院所重组而来，此后历经整合，形成了以电子信息为主业的集团公司架构。其前身单位长期承担国防电子装备与核心信息技术的研制任务，是"两弹一星"等重大工程电子信息配套的重要力量。

### 1.2 战略地位

- 军队信息化与电子战装备的主要供应商
- 国家网络安全与信息安全领域的骨干力量
- 半导体、软件、大数据等数字经济关键领域的国家队

---

## 二、机制与作用

### 2.1 产业布局

| 板块 | 主要方向 |
|------|---------|
| **军工电子** | 雷达、通信、电子对抗、网络信息体系 |
| **网信安全** | 密码、网络安全、数据安全 |
| **半导体** | 集成电路设计制造、第三代半导体 |
| **软件与数字** | 政务数字化、行业信息化 |
| **装备制造** | 电子装备系统集成与配套 |

### 2.2 运作机制

- **院所+企业**架构：以研究所为研发主体，公司化运作承载产业化
- **型号任务牵引**：承担军队电子装备型号研制与批产
- **军民两用**：军用电子技术向民用信息化、安全产业延伸
- **自主可控**：核心芯片、软件、系统的国产化攻关

### 2.3 主要作用

- 保障国防电子信息装备自主供给与作战能力
- 支撑国家网络与数据安全体系（见 [[数据安全]]、[[网络安全监管]]）
- 推动数字产业化与产业数字化，服务数字经济战略

## 三、关键事件与数据

### 3.1 关键节点

- **集团组建与重组**：多轮整合形成电子信息主业集团
- **军工型号批量列装**：雷达、电子对抗等装备支撑国防现代化
- **网络安全与数据安全布局**：在关键基础设施防护中承担重要角色
- **半导体与自主可控攻坚**：参与核心芯片、器件的国产替代（见 [[国产替代]]）

### 3.2 行业特征

| 特征 | 说明 |
|------|------|
| **军工属性** | 订单与型号任务驱动 |
| **技术密集** | 研发投入大、技术门槛高 |
| **平台广泛** | 下属上市公司与科研院所众多 |
| **改革看点** | 资产整合、院所改制、混改预期 |

## 四、影响

### 4.1 对国防安全

- 提升军队信息化与电子战能力

- 带动电子信息产业链上下游发展
- 在数据安全、网络安全等领域形成产业牵引（见 [[跨境数据流动]]）

- 下属上市公司构成军工电子与信创板块的重要组成部分
- 集团资产整合与改革预期提供主题催化
