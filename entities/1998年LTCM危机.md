# 1998年LTCM危机

## Basic Information
- Type: event
- 时间：1998 年 8-9 月
- 主体：[[长期资本管理公司]]（Long-Term Capital Management，LTCM）
- 结果：美联储组织的银团注资接管，避免无序清算

## Description

**1998 年 LTCM 危机** 是美国对冲基金长期资本管理公司（LTCM）因高杠杆套利策略巨亏、濒临破产，最终在美联储组织下由华尔街机构注资接管的事件，被视为**高杠杆与系统性风险**的经典案例。

LTCM 由所罗门兄弟前副总裁约翰·梅里韦瑟（John Meriwether）创立，合伙团队包括多位诺贝尔经济学奖得主与顶尖交易员，以"用科学模型管理金融风险"著称，成立初期业绩辉煌。详见 [[1998年LTCM危机]]。

### 策略与杠杆

- **核心策略**：收敛套利（Convergence Arbitrage）——买入相对低估的债券、卖出相对高估的债券，赚取利差收敛的收益，参见 [[利差交易]]
- **高杠杆**：以极小的资本金撬动数十倍名义头寸，依赖融资与回购，参见 [[杠杆]]
- **模型假设**：基于历史统计关系与低相关性假设，未充分预留尾部风险

### 危机经过

- **1998 年 8 月**：[[1998 俄罗斯卢布危机]] 触发俄罗斯主权债务违约，市场避险情绪急剧升温
- 全球投资者抛售风险资产、涌向安全资产，**利差不收敛反而急剧走阔**
- LTCM 的统计套利头寸全线亏损，叠加高杠杆，损失在短时间内急剧放大
- 资产抛售与被迫平仓形成**负反馈螺旋**，威胁其融资对手方

### 时间线

| 时间 | 事件 |
|------|------|
| **1994** | LTCM 成立，梅里韦瑟携诺奖得主团队入场 |
| **1994-1997** | 收敛套利策略持续高盈利，规模快速扩张 |
| **1998 年上半年** | 亚洲金融危机余波中利差走阔，出现首次显著亏损 |
| **1998 年 8 月** | 俄罗斯违约，全球避险，LTCM 巨亏并遭追加保证金 |

| **1998 年底** | LTCM 被接管清算，头寸逐步平仓 |

### 美联储救助

- 因 LTCM 头寸庞大、对手方众多，其无序破产被认为将引发**系统性风险**，参见 [[系统性风险]]
- 1998 年 9 月，美联储召集华尔街主要机构，由 14 家银行共同注资约 36 亿美元接管 LTCM
- 救助并非直接动用公共资金，而是通过**协调银团注资**完成，见 [[最后贷款人]]

### 危机启示

- **模型局限**：诺贝尔奖级别的量化模型也无法覆盖极端尾部事件——"黑天鹅"不可完全用历史统计捕捉
- **[[流动性幻觉]]**：高杠杆策略的盈利建立在市场正常运转的假设上，一旦流动性枯竭，账面亏损即为实际亏损
- **止损纪律**：规模过大使头寸难以在不冲击市场的情况下退出，被迫持有亏损头寸
- **"大到不能倒"**：私人机构因系统性关联获得事实上的救助，成为后来道德风险争论的样本
- **央行角色**：美联储以协调者而非出资者身份介入，为"[[最后贷款人]]"框架提供参考

# LTCM危机

## 核心定义

LTCM（长期资本管理公司）危机是1998年发生的一场几乎引发全球金融系统崩溃的对冲基金危机。LTCM由诺贝尔经济学奖得主（罗伯特·默顿、迈伦·斯科尔斯）和顶级交易员创立，通过复杂的数学模型和高杠杆进行债券套利交易。

## 关键要点

- **核心策略**：收敛交易（Convergence Trading），基于类似债券价格偏离最终回归正常水平的假设
- **杠杆率**：约25倍，权益资本约47亿美元，表内外总资产超过1000亿美元
- **导火索**：1998年8月俄罗斯政府宣布卢布贬值并债务违约
- **致命损失**：8月单月亏损超过40亿美元，9月23日净资产仅剩4亿美元
- **美联储干预**：1998年9月23日，14家华尔街主要金融机构联合注资36.25亿美元救助
- **核心教训**：模型风险（历史数据不能预测极端事件）、杠杆危害、高杠杆放大损失、流动性风险在极端市场下无法平仓
