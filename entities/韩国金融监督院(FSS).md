# 韩国金融监督院(FSS)

## Basic Information
- Type: organization（金融监管机构）
- 全称：Financial Supervisory Service（금융감독원）
- 成立时间：1999 年 1 月
- 所在地：首尔
- 上级机构：韩国金融委员会（FSC）

## Description

**韩国金融监督院（FSS）**是韩国综合性的金融检查与监督机构，依据 1997 年《金融监督机构设立法》组建，1999 年 1 月正式成立。它统一负责对银行、证券、保险、非银行金融机构的**现场检查与监督**，是韩国金融监管体系的执行主体。

韩国金融监管采用"政策制定与执行分离"的双层结构：**金融委员会（FSC）**负责金融政策与法规的制定，**金融监督院（FSS）**负责具体检查、处罚与消费者保护。这一架构是[[1997亚洲金融危机]]后韩国金融改革的直接产物（参见 [[韩国央行(BOK)]]、[[韩国]]）。

## 背景与沿革

### 1997 年亚洲金融危机：改革的催化剂
危机暴露了韩国分业监管碎片化、金融机构风险控制薄弱的缺陷。接受 [[IMF]] 援助后，韩国推进金融体系重组，将原先分散的银行、证券、保险监管职能整合，于 1998 年设立金融监督委员会（FSC），1999 年设立金融监督院（FSS），形成"政策—执行"双轨体系（参见 [[亚洲金融危机]]、[[金融自由化]]）。

### 1999 年至今：职能扩展
- 统一检查银行、证券、保险、非银行金融机构
- 承担金融消费者保护、金融纠纷调解职责
- 参与宏观审慎监管与金融稳定评估（参见 [[系统性风险]]、[[金融稳定]]）
- 对资本市场异常交易、市场操纵进行调查与处罚

### 2008 年后：监管强化
全球金融危机后，FSS 强化了对金融控股集团、衍生品与系统重要性机构的监管，并参与[[巴塞尔协议III]]等国际标准在韩国的落地。

### 2020 年代：市场监督的新焦点
近年来 FSS 在股市做空、异常波动、上市公司披露质量等领域的检查力度明显加大，例如对做空交易与大规模卖压的调查，对[[韩国KOSPI]]与投资者信心产生直接影响（参见 [[做空机制]]、[[金融安全]]）。

## 职能与作用

| 职能 | 内容 |
|------|------|
| 现场检查 | 对金融机构进行定期与专项检查 |
| 违规处罚 | 对违规机构与个人进行行政处分与罚款 |
| 消费者保护 | 受理金融投诉、调解纠纷 |
| 市场监督 | 监督证券与资本市场交易行为 |
| 金融稳定 | 配合宏观审慎政策，监测系统性风险（参见 [[系统性风险]]、[[银行风险]]） |
| 信息披露 | 监督上市公司披露质量与会计合规 |

## 与韩国央行的分工

| 维度 | 韩国央行（BOK） | 金融监督院（FSS） |
|------|----------------|------------------|
| 定位 | 货币政策 + 宏观稳定 | 微观审慎 + 现场监督 |
| 侧重 | 利率、通胀、金融稳定 | 机构检查、处罚、消费者保护 |
| 工具 | 政策利率、流动性工具 | 检查权、处罚权、整改令 |
| 联动 | 与 FSS 共享金融风险信息 | 执行 FSC 政策并反馈风险线索 |

两者通过金融稳定协调机制联动，共同维护韩国金融体系安全（参见 [[金融安全]]、[[央行独立性]]）。

## 影响

- **对韩国金融体系**：FSS 的统一监管提升了韩国金融机构的风险管理与合规水平，是 1997 危机后重建金融信任的核心支柱
- **对资本市场**：对做空与市场操纵的监管直接影响[[韩国KOSPI]]、[[韩国综合指数]]的短期波动与长期信心
- **对消费者**：金融纠纷调解与消费者保护职能改善了金融服务的公平性
- **对国际金融**：作为新兴市场监管标杆之一，其监管实践被亚洲金融危机后各国改革所参照
