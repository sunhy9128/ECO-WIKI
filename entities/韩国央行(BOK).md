# 韩国央行(BOK)

## Basic Information
- Type: organization（[[[[央行]]]]）
- 全称：Bank of Korea（한국은행，韩国银行）
- 成立时间：1950 年 6 月
- 所在地：首尔
- 行长：由韩国总统任命，任期内受政治干预较少

## Description

**韩国央行（BOK）**是韩国的中央银行，依据《韩国银行法》设立，负责货币政策的制定与执行、[[金融稳定]]、发行货币与外汇管理等职能。其最重要的政策目标是**维持物价稳定**，2001 年起实行[[通胀目标制]]。

韩国央行与[[韩国金融监督院(FSS)]]共同构成韩国金融监管与货币政策的双轨体系：前者负责货币政策与宏观金融稳定，后者负责金融机构的具体检查与监督。亚洲金融危机后，韩国央行独立性显著增强，但仍通过货币政策委员会与政府进行政策协调。

## 背景与沿革

### 1948—1950：建行背景
1948 年大韩民国政府成立后，为统一货币体系、结束战时混乱的货币发行，于 1950 年设立韩国央行，是亚洲较早建立的中央银行之一（参见 [[1948货币改革]]）。

### 1997 年亚洲金融危机
危机暴露出韩国金融体系的外债与银行体系脆弱性，韩国接受国际货币基金组织（[[IMF]]）援助并推进结构性改革：增强央行独立性、建立统一的金融监管框架（由此催生[[韩国金融监督院(FSS)]]）、推动银行重组与市场化改革（参见 [[1997亚洲金融危机]]、[[1997亚洲金融危机]]）。

### 2001 年：引入通胀目标制
韩国央行正式采用通胀目标制，货币政策从"货币量目标"转向"利率目标"，增强政策透明度与可预期性。

### 2008 年全球金融危机
危机期间韩国央行大幅降息并向市场注入流动性，配合政府财政刺激，帮助韩国经济较快企稳（参见 [[2008全球金融危机]]）。

### 2021—2026：加息周期与政策转向
2021 年起为应对通胀与美元加息周期，韩国央行进入加息通道，韩元汇率与韩国股市随之波动（参见 [[2022-2024 美联储紧缩周期]]、[[股牛汇弱]]）。此后随通胀回落与增长压力，政策逐步转向宽松。

## 职能与作用

| 职能 | 内容 |
|------|------|
| 货币政策 | 通过政策利率引导市场利率，锚定通胀目标 |
| 金融稳定 | 宏观审慎工具、金融稳定报告、系统重要性机构监测 |
| 货币发行 | 发行韩元纸币与硬币（参见 [[韩元]]） |
| 外汇与储备 | 管理韩国外汇储备，必要时干预汇市（参见 [[央行入市干预]]） |
| 支付清算 | 维护支付系统平稳运行 |
| 金融数据与研究 | 编制经济与金融统计，提供政策研究支持 |

## 货币政策框架与工具

韩国央行以政策利率为核心工具，辅以公开市场操作与宏观审慎工具：

| 工具 | 说明 |
|------|------|
| 政策利率（基准利率） | 通过设定基准利率引导市场利率（参见 [[货币政策工具]]、[[利率走廊]]） |
| 公开市场操作 | 通过回购、债券买卖调节银行体系流动性（参见 [[公开市场操作]]、[[正回购]]） |
| 存款准备金率 | 调节货币乘数与信贷扩张（参见 [[存款准备金率]]、[[货币乘数]]） |
| 宏观审慎工具 | 逆周期资本缓冲、LTV 限制等，抑制金融风险累积（参见 [[逆周期资本缓冲]]） |
| 前瞻指引 | 通过政策沟通引导市场预期（参见 [[前瞻指引]]、[[货币政策传导机制]]） |

### 政策决策机制

- **货币政策委员会**：由行长、副行长及相关委员组成，定期议息
- **决策依据**：通胀目标、增长与就业、金融稳定、外部环境（美元周期、全球资本流动）
- **会议纪要**：公布政策声明与会议纪要，增强透明度

## 治理结构与独立性

- 1997 年亚洲金融危机后，韩国修订《韩国银行法》，显著增强央行**政策独立性**（参见 [[央行独立性]]、[[货币政策独立性]]）
- 行长经国会同意后由总统任命，任期内不得被任意解职
- 央行不直接向政府财政透支，与[[财政部]]式政府债务融资隔离
- 韩国央行与[[韩国金融监督院(FSS)]]通过金融稳定协调机制共享信息，形成"货币当局 + 监管当局"的分工格局

## 关键数据与表现（示意）

- 政策利率：随经济周期在加息与降息之间切换，具体水平以官方公布为准
- 韩元汇率：美元周期主导下波动显著，贬值期推升输入性通胀压力（参见 [[输入型通胀]]、[[美元周期]]）
- 增长与通胀：作为[[出口导向型经济体]]，韩国通胀受全球大宗商品与汇率影响较大

> 说明：以上数据随时期变化，本页不固化具体数值，以机制性描述为主。

## 影响

- **对韩国经济**：货币政策通过利率影响投资、消费与出口景气，是韩国宏观经济的核心调节器
- **对金融市场**：政策利率与韩元汇率直接影响[[韩国综合指数(KOSPI)]]、[[韩国综合指数(KOSPI)]]与债券市场
- **对区域与国际**：作为发达经济体央行，其政策与美联储、[[日本银行]]联动，影响亚太资本流动
- **对外资**：央行信誉与政策透明度是外资配置韩国资产的重要考量

## 描述

韩国央行(Bank of Korea, BOK, 한국은행)是韩国的中央银行,总部位于首尔,负责制定与执行货币政策、维护金融稳定、发行韩元。

### 政策框架

| 维度 | 内容 |
|---|---|
| 框架 | **通胀目标制**(Inflation Targeting) |
| 法律基础 | 《韩国银行法》第六条第一款 |
| 通胀目标 | **2%** |
| 目标设定时间 | 自 2019 年起 |
| 复盘周期 | 每两年会同政府复盘 |

### 2026-05-28 议息会议

| 项目 | 内容 |
|---|---|
| 基准利率 | **2.5%**(维持不变) |
| 支持本次加息委员 | **2 位**(+25BP) |
| 认为后续将加息委员 | **3 位**(居多数) |
| 政策核心矛盾 | 稳增长 → **防通胀** |

### 委员表态三大阵营

**(一)支持不加息的委员(主流,但偏鹰)**

理由:
- 半导体高景气可以对冲中东地缘冲击
- 中东不确定性高,不宜仓促调整
- 维持现有利率的通胀风险 > 加息抑制增长的风险
- 政策核心矛盾已由"稳增长"转向"防通胀"

**(二)支持加息 25BP 的委员(2 位)**

理由:
- 经济增速超过潜在增速
- 韩元贬值 + 油价 → 通胀压力持续累积
- 中长期家庭债务等金融失衡风险
- 配套建议:出口税收定向扶持 / 盈余财政偿债 / 保障低收入家庭
