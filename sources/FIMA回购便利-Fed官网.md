# FIMA 回购便利 - Fed 官网

## 来源
- 原始页面: [Foreign and International Monetary Authorities (FIMA) [[回购市场]] Facility](https://www.federalreserve.gov/monetarypolicy/fima-repo-facility.htm)
- 收录日期: 2026-08-06
- 性质: 美联储官方一手源

## 核心内容

本文档记录**外国与国际货币当局回购便利（[[FIMA回购便利]]）**的官方信息，是理解美联储"全球美元流动性后盾"的另一支柱（与[[美元互换网络]]互补）。

### 设施定义

美联储为**外国与国际货币当局**设立的回购协议便利。通过为 FIMA 账户持有者提供临时的美元流动性后盾，帮助应对**全球美元融资市场压力**——这种压力可能反过来影响美国国内的金融市场状况。^[extracted]

### 运作机制

- **FIMA 账户持有者** = 在**纽约联储**持有账户的中央银行及其他国际货币当局
- 操作：经批准的账户持有者把其在美联储持有的**美国国债**暂时换为美元
- 换得的美元可提供给其辖区内的机构
- 定价：按**后盾利率（backstop rate）**，即高于市场的惩罚性利率
- 定位：对**持有美债的外国官方机构**，是"在公开市场出售美债之外"的**替代性临时美元来源**

### 时间线

| 时间 | 事件 |
|------|------|
| 2020.3.31 | 临时 FIMA repo 便利设立 |
| 2020.7.29 | 与临时互换线一起延至 2021.3.31 |
| 2020.12.16 | 延至 2021.9.30 |
| 2021.7.28 | **转为常设设施**（与 C6 常设化同日） |

## 关键声明与来源标记

- 本质：把"外国央行手中的美债"变为"可抵押的美元流动性"，避免央行被迫抛售美债（extracted）
- 与互换线的分工：互换线覆盖**选定央行**（C6 永久 + 临时线），FIMA repo 面向**所有在纽联储开户的 FIMA 持有者**（extracted）
- 意义：FIMA repo 是互换网络的**普惠化补充**——无互换线的央行也能获得美元流动性（inferred，官方未用"普惠"一词但机制如此）

## 局限

- 官方页未给出 FIMA repo 的实际使用峰值（2020 年峰值约 $420 亿为常识性量化，inferred）
- 覆盖仍限于"在纽联储有账户"的机构，且需持有美债作为抵押——与 [[Original Sin（原罪）]] 的币种错配议题间接相关
