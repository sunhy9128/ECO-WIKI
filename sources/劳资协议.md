# 劳资协议 - Summary

## 核心内容

**劳资协议**（Collective Bargaining Agreement）是指雇主（企业或雇主组织）与劳动者代表（工会）之间，就工资水平、工时制度、工作条件、解雇保护、福利待遇等事项经集体谈判达成的书面约定。它是现代劳动力市场调节工资的核心制度安排，在[[domains/宏观经济|宏观经济]]学中构成"工资决定机制"的重要环节。

## 关键维度

### 1. 谈判层级

| 层级 | 形式 | 典型地区 |
|------|------|---------|
| **企业层面** | 企业与本企业工会谈判 | [[美国]]、[[日本]]（春斗为主） |
| **行业层面** | 行业工会与雇主联合会谈判 | [[德国]]、北欧 |
| **全国/中央层面** | 全国工会与政府/雇主对话 | [[法国]]、部分东亚经济体 |

### 2. 工资决定的宏观影响

- **工资-物价螺旋**（[[1970年代滞胀]]的典型机制）：劳资协议确定的工资涨幅若持续高于生产率增长，将通过成本推动传导至物价，形成"工资上涨 → 物价上涨 → 再次要求加薪"的正反馈。
- **通胀预期锚定**：工资协议中的涨幅预期是央行判断核心通胀黏性的关键变量。
- **产出缺口与就业**：过高的协议工资可能抑制企业用工需求，推高结构性失业。

### 3. 与金融市场的关联

| 渠道 | 说明 |
|------|------|
| **债券市场** | 工资协议大幅上调 → 通胀预期上行 → 长端利率承压 |
| **汇率** | 工资成本上升削弱出口竞争力，影响[[concepts/经常账户|经常账户]]与货币币值 |
| **企业盈利** | 劳动成本占比高的行业（制造业、服务业）利润率受直接挤压 |
| **[[央行政策]]** | 春斗等工资谈判结果常作为日央行等评估货币政策的重要参考 |

## 关键要点

1. 劳资协议是工资刚性（价格黏性）的重要制度来源，解释为何工资调整滞后于宏观经济冲击。
2. 在低通胀环境下，劳资协议往往难以推动工资上涨；而高通胀期则可能加速工资-物价螺旋。
3. 对制造业跨国企业（如三星电子等电子、半导体企业），各国劳资协议的差异直接影响其全球成本结构与工厂选址。
4. 结构性改革中，劳动市场灵活化（削弱工会议价权）与劳动者保护之间的平衡，是持续的政策争论点。
