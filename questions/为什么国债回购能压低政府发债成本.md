# 国债回购为何能压低政府发债成本

**一句话回答**：财政部回购国债 → 二级市场价格上涨 → 存量收益率被动下跌 → 一级市场新发债参照二级市场定价 → 新债收益率随之走低 → 政府融资成本下降。但这条传导链是**短期的、被动的**——长端收益率最终并非由央行利率单独锚定，而是由「短端政策利率预期 + 期限溢价（财政风险成分）」共同决定。^[inferred]

---

## 传导链

```
财政部回购国债（二级市场买入存量）
    ↓ 增加需求 → 二级市场价格↑
    ↓ 价格与收益率反向 → 存量收益率被动下跌
    ↓ 一级市场定价锚定二级市场（见 [[concepts/一级市场与二级市场]]）
    ↓ 新发债收益率下跌
    ↓ 政府发债成本降低
```

wiki[[concepts/国债回购]]正面项确认"压低长端收益率，降低政府融资成本"是回购的官方目标之一。一级/二级定价传导的机制在 [[concepts/一级市场与二级市场]] 有更尖锐表述：**二级市场存量定价反过来绑架一级市场发行**——美联储 QE 正是通过存量购买决定所有债券定价。

## 反向对照：加息与存量债券

央行加息时链条反向成立（[[concepts/债市定价逻辑]]）：

```
央行加息 → 新发国债票息↑ → 存量旧债票息不变、相对吸引力↓
    → 二级市场抛售旧债 → 旧债价格下跌 → 旧债收益率被动抬升
    → 新发债参照二级市场定价 → 票息跟随上行
```

久期放大此效应：久期越长对利率越敏感（久期 7 年的债，收益率上升 1%，价格下跌约 7%），长期旧债在加息时价格下跌更剧烈。

## 短端 vs 长端：最终锚不同

"国债收益率 ≈ 无风险利率，最终受美联储加息/降息主导"——**只在短端成立**：

| 期限段 | 主导变量 | 回购影响 | 最终锚 |
|--------|----------|----------|--------|
| **短端** | 美联储政策利率 | 小 | 央行利率（直接） |
| **长端** | 短端利率预期均值 + 期限溢价 | 直接（但有限） | 政策利率预期 + **财政主导**（独立） |

- 长端收益率上行（财政风险驱动）和下行（政策压制）**都会削弱美元**——前者经"风险溢价→资本外逃"，后者经"实际利率下降→资本流出"（见 [[synthesis/国债收益率 × 利率 × 汇率]]）。
- 2026-08 实证：回购宣布日 10 年期期限溢价仅 -1.7bp，两日后回升至 0.8682%（高于宣布前）——回购压低的是名义收益率，**压不住期限溢价**，因为期限溢价是市场对赤字的恐惧，不是央行能锚定的。

## 无风险利率的近似条件

严格说，国债收益率 ≈ 无风险利率（Rf）有前提（[[concepts/风险溢价与无风险利率]]）：

- **3 个月国库券** ≈ 纯 Rf（国际通用基准）
- **10 年期国债** = Rf + 期限溢价（DCF 估值常用但已含额外成分）
- 总收益 = Rf + 股权风险溢价 + 期限溢价 + 信用利差 + 通胀风险溢价 + 流动性溢价

当财政可持续性恶化，期限溢价膨胀，国债收益率上行不再代表"无风险回报高"，而是**财政风险溢价在定价**——这正是"为什么压收益率会削弱美元"的深层机制。

## 结论

- 回购压发债成本：**对，但短期且间接**（经二级市场 → 一级市场定价传导）。
- 收益率最终回归央行利率：**短端对，长端不对**——长端的独立变量是财政主导（fiscal dominance），这是 [[synthesis/财政主导]] 的核心论点：只要美国不解决赤字，长端收益率与美元就处于"要么收益率上行（财政风险溢价）、要么美元贬值（政策压制转移压力）"的两难。
